第 16 章 · 加速技术全景

蒸馏模型、加速 LoRA、BlockCache/TeaCache——四层加速手段的原理、效果与代价

一、先理解时间花在哪

视频生成的时间 ≈ 步数 × 每步耗时。每步耗时由模型大小、分辨率、帧数决定。所有加速技术都在动这两个乘数，可归为四层：

层级技术原理一句话加速比画质代价
① 换模型蒸馏版（V4 加速模型等）大模型教小步数模型，直接少走路2~4×轻微，细节偏软
② 挂 LoRALightning / Turbo LoRA小补丁让原模型学会少步出图2~4×轻微
③ 缓存复用BlockCache / TeaCache相邻步变化小就跳过重复计算1.2~2×近似有损
④ 算子优化SageAttention 等注意力计算换更快算法1.2~1.5×几乎无损

四层可以叠加（如蒸馏模型 + 缓存），但画质代价也会叠加。建议一次只加一层，跑同一条片子对比。

二、蒸馏模型（第 ① 层）

蒸馏（distillation）是让"老师模型"（20~40 步）生成大量样本，训练"学生模型"用 4~8 步达到相近效果。你装的 H3 默认 8 步配置本身就是蒸馏产物；社区的 V4 加速版把它进一步压到更少步数。

  • 何时用：批量出片、分镜探索阶段的速度优先场景。
  • 何时不用：成片级高潮镜头——步数少在复杂运动上细节发软，宁可等。
  • 获取：社区整合包/夸克网盘分发为主，注意核对底座版本与节点兼容性。

三、加速 LoRA（第 ② 层）

加速 LoRA 是蒸馏思想的轻量化形态：不改底座模型，只挂一个几十 MB 的小补丁，让原模型学会"4~8 步出片"。图像侧的 Qwen-Image-Lightning、视频侧 Wan/LTX 系的 Lightning LoRA 都是这一路。

💡 LoRA 加速的使用姿势

在加载器后串一个 LoraLoaderModelOnly 节点，挂上加速 LoRA，然后把步数降到 LoRA 标注的甜区（通常 4~8 步）、CFG 降到 1.0~1.5。最常见的错误是挂了加速 LoRA 却还用 20 步——反而过拟合出 artifacts。加速 LoRA 和低步数是绑定销售的。

注意：风格 LoRA（改变画风）和加速 LoRA（减少步数）是两类东西，可以同时挂，但各自职责不同。第 21 章讲风格/角色 LoRA。

四、缓存复用：BlockCache / TeaCache（第 ③ 层）

扩散采样的相邻步骤之间，模型各层（block）的输出变化通常很小。缓存类技术检测"变化够不够小"，够小就直接复用上一步的计算结果，跳过整层计算：

  • BlockCache（T8 版）：针对 H3 的 F1B0 方案——先算第 0 层判断稳定性，稳定则跳过第 1~49 层。关键参数 residual_diff_threshold（默认 0.12，调高更快但更糙）、连续命中上限 2 次防漂移。作者实测约 1.2×。
  • TeaCache：另一路"时间步嵌入相似度"判定的缓存方案，适配多种视频模型，加速比通常 1.5~2×。
⚠️ 缓存是近似算法

缓存类技术不保证同 seed 结果一致，本质是"用微小画质换时间"。互斥：BlockCache 不能和 EasyCache/LazyCache 等其他缓存补丁同时挂。建议：草稿期开缓存，最终成片关掉跑原生。

五、算子优化（第 ④ 层）

SageAttention 用更高效的注意力核函数替换默认实现，对画质几乎无损，属于"白捡的加速"。在 ComfyUI 启动参数加 --use-sage-attention 即可（需先在嵌入环境安装 sageattention 包）。50 系显卡（Blackwell）兼容性已成熟，你的 5060 Ti 可用。

六、决策建议（16GB 单卡）

  1. 默认态：官方 8 步蒸馏配置 + SageAttention。这是性价比基线。
  2. 赶工/批量：叠加 TeaCache 或换 V4 加速模型，接受轻微画质损失。
  3. 成片镜头：回到原生 8~16 步，关缓存。重要镜头值得等。
  4. 永远不要：为了省时间降分辨率出片再超分救——超分能救清晰度，救不回构图细节（第 18 章讲超分的正确用途）。
📖 实例：5 秒镜头的时间账（16GB 级显卡实测量级）

原生 8 步：约 30 分钟 → +SageAttention：约 24 分钟 → +TeaCache：约 15 分钟 → 换 V4 加速模型：约 8~10 分钟。一部 10 镜头的片子，全速配置能把过夜任务压缩到两小时内——但成片建议只对草稿镜头用全速，高潮镜头回归原生。

五补、SageAttention 安装实操

  1. 装包：用 ComfyUI 便携版的内嵌 Python 安装：
    python_embeded\python.exe -m pip install sageattention
  2. 加启动参数：编辑 run_nvidia_gpu.bat，在主程序参数末尾追加 --use-sage-attention
  3. 验证：启动日志出现 sage attention 相关字样，且同任务耗时下降约 15~25% 即生效
  4. 回退预案：个别模型在 sage 注意力下出现色偏，删掉启动参数即可还原——它是无损可逆的

六补、步数-质量曲线：加步的边际收益

"8 步加到 16 步值不值"取决于镜头内容，实测规律（H3 蒸馏配置）：

步数相对耗时画质表现适用
60.75×运动细节发糊，仅构图评审可用草稿
81.0×（基准）标准出片质量大多数镜头
121.5×面部/纹理细节可感知提升面部镜头
162.0×提升趋缓，顶点镜头专用高潮特写
24+3×+肉眼几乎无差异不推荐

结论：8 → 12 是性价比最高的一档跃升；超过 16 步的投入基本打水漂。加步预算只给面部重责镜头。
