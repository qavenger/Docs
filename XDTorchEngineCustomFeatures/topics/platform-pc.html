🖥️ PC / Windows / D3D

DX11/DX12 兼容、驱动与 Windows 平台行为

一句话概括：把 PC 端的「跑不起来 / 跑一半崩 / 玩家看不懂错误」三大类问题做了工程化处理：DX12/DX11 自动互切、启动自检、故障弹窗引导、显存可追踪。

1. DX 版本兼容与崩溃回退

  • XD_PC_SWITCH_DX_VERSION_AFTER_CRASH：读 GameUserSettings.ini [D3DRHIPreference] 的 bCrashedOnD3D12/11 决定首选 RHI；本次运行崩溃后被标记，下次启动自动切换另一个版本（DX12⇄DX11）。写标志由 FWindowsPlatformMisc::LogD3D12Failed/LogD3D11Failed 完成。
  • XD_PC_FALLBACK_TO_DX11_WHEN_DX12_CRASH（及 _MINIMAL）：DX12 崩溃时回退 DX11 的实现（完整版含上报，精简版仅切换）。
  • XD_PC_STARTING_PROTECTION_WITH_FORCE_DX12：玩家用 -dx12 命令行强制启动、或多 RHI 冲突/设备不支持时，保护性回退 DX11 而不是 Fatal。
  • 注意：以上逻辑在编辑器/非 Shipping 下直接 return，只对发行包生效。

2. DX12 自检与诊断

  • XD_PC_D3D12RHI_ADDITIONAL_COMPATIBILITY_TEST：增强设备创建流程的日志与显存统计（LogMemoryInfo、TerminateOnOutOfMemory），启动阶段多一道兼容性自检。
  • XD_PC_D3D12_ISSUE_REPORT：暴露 RHIGetD3D12IssueEventDelegate 委托，把 DX12 设备/驱动问题上报给项目侧（崩溃平台）。
  • XD_PC_D3DRHI_OUTPUT_VERBOSE_LOG：D3D11/D3D12 校验失败时输出完整参数（可用 CVar 单独开启）。
  • XD_PC_GRAPHICS_DRIVER_VERSION_WARNING：检测驱动版本过旧，弹窗提示升级（CVar r.DisableDriverWarningPopupMsgBox 可关）。
  • XD_BUG_FIX_RHI_CRASH_INDICATION_FLAG：加原子标志判断“崩溃是否发生在 RHI 命令执行中”，显著提高崩溃归因准确率。
  • XD_EXT_DEBUG_RENDERING_FUNC：非 Shipping 下给渲染资源加调试名称，便于 RenderDoc 抓帧。

3. 显存与 OOM

  • XD_OPT_PC_D3D11_DEFAULT_USE_D24：D3D11 默认使用 24 位深度缓冲（CVar r.D3D11.Depth24Bit），在 4K/高分辨率下省显存、规避 OOM。
  • XD_PC_RECORD_D3D11_RENDERING_RESOURCE_ALLOCATION：FVRAMAllocationRecorder 持续记录 D3D11 资源分配；控制台命令 XD.Engine.DumpRecordedD3D11VRAMAllocation 导出，用于定位显存泄漏/超标。
  • XD_EXT_OOM_POP_UP_TIPS_WINDOWS：内存/显存不足时弹窗引导玩家降低画质，并标记 GIsOOMCrashed 以便上报区分。
  • XD_EXT_DX_ERROR_POP_UP_TIPS_WINDOWS、XD_EXT_DLL_MISSING_ERROR_POP_UP_TIPS_WINDOWS：DX API 错误、DLL 缺失的玩家可读弹窗。
  • XD_MISC_WINDOWS_FORCE_EXIT_WITH_CRASH：需要留存崩溃现场时强制以崩溃方式退出。

4. 多显示器、分辨率与 DPI

  • XD_TOOL_GET_MONITOR_INFO_FROM_ADAPTER / XD_TOOL_GET_RESOLUTIONS_FROM_SPECIFIED_MONITOR_ID：把显示器与 GPU 适配器正确对应，并获取指定显示器的全屏分辨率列表（RHI 层新增 FAttachedMonitorInfoRHI/FScreenResolutionRHI，D3D11/D3D12 分别实现）。
  • XD_MISC_ENABLE_DPI_AWARE_WHIT_PROCESS_PER_MONITOR_DPI_AWARE：进程级 Per-Monitor DPI 感知，多屏不同缩放时不再手动 SetWindowPos。
  • XD_PC_SCREENRESOLUTION_SETTING_FOR_LIMITED_MONITOR：受限显示器（小屏/特殊分辨率）下的分辨率设置处理；该宏在引擎 Source 内未检索到消费点，属项目层接口。
  • XD_PC_MISC_GET_HW_CURSORS：PC 获取/切换硬件光标（游戏内鼠标样式）。

5. MuMu 模拟器与抓帧

  • XD_BUG_FIX_MUMU_GL_BACK_BUFFER_SAMPLE：修复 MuMu 模拟器无法进行 GL BackBuffer 采样（离屏渲染）的问题。
  • XD_RENDERING_PC_HANDLE_GRAPHICS_INSIGHTS_TOOL_ATTACHED（默认 0）：挂载 RenderDoc/PIX 等抓帧工具时的特殊处理。
  • 模拟器的输入映射、键鼠/手柄支持、分辨率与 ini 叠加等宏属于 Android 平台专题，见 Android / iOS / Mac。

6. 其它 PC 专项

  • XD_RENDERING_PC_DX11_SUPPORT_RHI_THREAD（默认 0）：为 DX11 打开 RHI 线程（CVar r.DX11.RHIThread）；默认关闭，需充分验证后再开。
  • XD_RENDERING_PC_HANDLE_GRAPHICS_INSIGHTS_TOOL_ATTACHED（默认 0）：挂载 RenderDoc/PIX 等抓帧工具时的特殊处理；XD_EXT_DEBUG_RENDERING_FUNC 则在非 Shipping 下给资源加调试名。
  • XD_EXT_PC_D3D11RHI_VERIFY_SRV：CreateShaderResourceView 失败时的补充日志；引擎 Source 内未发现消费点，可能由上层/工具链使用。
  • XD_EXT_PLATFORM_UNWANTED_BEHAVIORS_TAKEOVER 与 XD_REPORT_ALL_REQUEST_EXIT_EVENT_AS_ERROR：接管平台弹窗/退出行为，并在强制退出前 Flush 全部日志。

7. 注意事项

  • DX 切换依赖把标志写入并 Flush GGameUserSettingsIni；若玩家删除 ini 或使用便携版目录，回退状态会丢失。
  • 弹窗引导只在 !UE_BUILD_SHIPPING 之外的路径做判断，发行包才生效；测试时注意构建类型。
  • 显存记录工具会带来一定开销，仅在排查版本启用。

引擎侵入等级

L3 深度侵入核心结构/生命周期/序列化，慎入

迁移处置

接入点引擎只留 Hook，逻辑在插件
移植代码保留，适配后移植
保留引擎深度绑定，暂留并登记 Feature Card
