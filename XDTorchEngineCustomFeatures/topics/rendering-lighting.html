💡 光照、阴影与材质

阴影/光照、ToonLit 材质、Bloom 与后处理

一句话概括：这块包含三部分：光照/阴影的精细控制与移动端一致性、ToonLit 卡通材质体系（火炬之光画面风格的核心）、以及 Bloom/LUT/DLSS/GTAO 等后处理定制。

1. 光照与阴影

  • XD_RENDERING_PC_PER_LIGHT_PER_OBJECT_SHADOW_PROJECTION_CONTROL：为光源与投射阴影的物体分别增加开关，控制「某光源是否对某物体投影」，用于角色打光/过场的精细控制。
  • XD_PC_RENDERING_SUPPORT_HIDE_SECONDARY_DIRECTIONAL_LIGHTS_DEFERRED_SHADOWMASK：被隐藏的次要平行光仍写入 Deferred ShadowMask，保持其阴影遮蔽不跳变。
  • XD_MOBILE_RENDERING_POINT_LIGHT_DISABLE_DYNAMIC_SHADOW：移动端（ES3.1 及以下）点光源不再投射动态阴影，PC/移动效果一致，同时省下阴影 Pass。
  • XD_RENDERING_FORCE_STATIC_MESH_SHARE_LIGHT_MAP：强制所有 LOD 共享 LOD0 的 Lightmap（bForceLODsShareLightmap），光照图体积与烘焙时间大幅下降。
  • XD_RENDERING_LIGHTMAP_BIAS：暴露 Lightmap Bias（WorldSettings 级），微调采样偏移解决漏光/黑边。
  • XD_TOOL_SUPPORT_NO_BAKED_LIGHTMAP_DIRECTIONALITY_GLOBALLY_MOBILE：移动端全局关闭 Lightmap 方向性（r.DisableBakedLightMapDirectonality），烘培贴图由 RGBA 变 RGB(A)，包体显著减小。
  • XD_OPT_STATIC_POINT_LIGHT_SET_HIDDEN_IN_GAME：静态点光源可 HiddenInGame 且保留烘焙照明，减少运行时动态光源列表。
  • XD_RENDERING_LIGHTMASS_DISABLE_BackfacingHitsFraction（默认 0）：关闭 UE4.24 新增的背面命中比例处理（该特性让植被偏暗）。
  • XD_OPTIMIZATION_SHADOWS_FORCE_LOD（默认 0）：阴影 Pass 用低 LOD 骨骼网格。
  • XD_EXT_ADJUST_FOG_INTENSITY_RANGE：放宽雾强度可设置范围。
  • XD_RENDERING_ALLOW_TRANSLUCENCY_OBJ_CAST_CSM_SHADOW：允许半透明物体向级联阴影投射（注意它构建期依赖 CustomUnlit 系列宏）。
  • 稳定性：XD_BUG_FIX_WRONG_SHADOW_PROJECTION_DEPTH_IN_PC（独立 ShadowProjectionDepthPassMeshProcessor）、XD_BUG_FIX_MIC_DOES_NOT_CAST_DYNAMIC_SHADOW_AS_MASKED、XD_BUG_FIX_VOLUME_LIGHTMAP_ADD_TO_SCENE_CRASH、XD_BUG_FIX_REMOVE_INCORRECT_TRANSITION_FROM_VOLUME_LIGHTMAP、XD_BUG_FIX_ILCDATA（间接光照缓存空数据保护）。

2. ToonLit 卡通材质体系

  • XD_RENDERING_TOON_LIT_SHADING_MODEL：在着色模型列表中新增 ToonLit 卡通光照模型，材质编辑器、材质编译器、渲染器与所有 Shader（Clustered Deferred / Mobile 等）全部打通，是火炬之光卡通渲染的核心。
  • XD_RENDERING_TOON_LIT_ADD_RAMP_TEXTURE：引擎级 Ramp（渐变）贴图 remap——材质无需自己采样即可获得统一的色阶过渡。
  • XD_RENDERING_CUSTOM_GI：材质新增 MP_CustomGI/MP_GIScale 自定义 GI 通道，编辑器、HLSL 翻译器、材质烘焙导出全链路支持；卡通渲染里可手工控制环境光贡献。
  • XD_RENDERING_OPAQUE_UNLIT_DISABLE_FOG：Opaque Unlit 材质可单独关闭雾效，避免远景雾把天空盒/特效染灰（TORCHLIGHT-240925）。
  • XD_OPT_MATERIAL_NO_DYNAMIC_POINTLIGHT：材质可声明不参与动态点光计算，降低大量点光源场景开销。
  • XD_RENDERING_MATERIAL_CUSTOM_NODE_INPUT_ADD_FULL_PRECISION_SETTING / XD_HIGHP_CUSTOM_NODE_OUTPUT：Custom 节点支持 UseFullPrecision（highp），移动端需要精度的计算（世界坐标等）不再被 mediump 削掉。
  • 材质工作流：XD_MISC_NO_SHADER_COMPILER_WHEN_MATERIAL_UPDATED（改材质不立刻编译 Shader，为策划省时间）、XD_EXT_MAT_INSTANCE_EDITOR_PRINT_MOBILE_INSTRUCTION、XD_EXT_LOG_COMPILE_ISSUE_MATERIAL_NAMES、XD_HELP_PRINT_MAT_FUNCTION_NAME_WITH_REMOVED_MATERIAL_EXPRESSION、XD_EXT_ALLOW_USE_ORIGIN_PROXY_MATERIAL、XD_EXT_APPLYPARAMS_FOR_SPECIFIC_MAT_INDEX、XD_TOOL_DEBUG_MATERIAL_AUTOMATICALLY_SET_USAGE_IN_EDITOR。

3. 后处理

  • XD_BLOOM_CLAMP：Bloom 降采样阶段限制输入亮度，抑制高亮素材造成的全屏泛光。
  • XD_RENDERING_ADJUST_BLOOM_MIN_RGB_VALUE：限制 Bloom 取样的最小 RGB（与粒子亮度调节配合，控制特效过曝上限）。
  • XD_TOOL_ADDITIVE_BLEND_MATERIAL_ADD_ALPHA_COLOR_MULTIPLIER：为 Additive 混合材质提供 View.AdditiveColorMultiplier/AdditiveAlphaMultiplier 全局乘数。
  • XD_OPT_CACHE_TONEMAP_LUT_TEXTURE：缓存 Color Grading LUT 的计算结果，避免每帧重复生成。
  • XD_PC_DLSS_SUPER_SAMPLING：DLSS 超采样集成（额外降采样 Pass + 上采样），把内部分辨率结果交给 DLSS。
  • XD_CASCADE_RADIANCE：级联辐射度体系——新增 EMeshPass::CascadeRadianceCustomDepth 与 CascadeRadianceCustomDepth.cpp，对标记物体渲染自定义深度，再在指定深度区间做辐射叠加，用于体积光/光柱/雾气。注意代码仅 PLATFORM_WINDOWS 生效。
  • XD_BUG_FIX_GTAO：修复 PC GTAO 环境光遮蔽问题（源自 UE5.7，TORCHLIGHT-239877）。

4. 注意事项

  • Shader 联动最重：ToonLit / Ramp / CustomGI / 雾效开关都会改变材质编译结果，改宏后必须清 DDC 重编 Shader；材质质量档（Quality Level）也要同步验证。
  • 移动端一致性：XD_MOBILE_RENDERING_POINT_LIGHT_DISABLE_DYNAMIC_SHADOW 与 XD_OPT_STATIC_POINT_LIGHT_SET_HIDDEN_IN_GAME 都是为了 PC/移动效果一致，改动前确认双端对比。
  • 平台限制：CascadeRadiance 仅 Windows；DLSS 需要对应显卡与插件支持。
  • Lightmap 两个宏成对使用：共享 LOD0 Lightmap 与全局关闭方向性一起用，收益最大（贴图减半 + 烘焙时间下降）。
