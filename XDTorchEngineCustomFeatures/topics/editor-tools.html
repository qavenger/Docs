🛠️ 编辑器与资源工具

资源校验、源码管理、Dump 与调试工具

一句话概括：把「美术/策划会在编辑器里踩的坑」和「CI 会漏的问题」都变成可检查、可自动修复、可导出的工程能力：资源校验、MapCheck、源码管理、纹理压缩、序列化升级与一批诊断 Dump。

1. 资源与材质校验

  • XD_HELP_PRINT_BAD_ASSET_FILE_NAME：加载到损坏/非法资产时打印文件名（LinkerLoad），快速定位是哪张图/哪个材质坏了。
  • XD_HELP_PRINT_MAT_FUNCTION_NAME_WITH_REMOVED_MATERIAL_EXPRESSION：打印包含已删除材质表达式的材质函数名，提示需要重新保存——这是「材质莫名编译失败」的常见原因。
  • XD_TOOL_SOLVE_UNMATCHED_OVERRIDDEN_MAT_WITH_STATIC_MESH_MATERIALS + XD_MISC_MAP_CHECK_ADJUST_STATIC_MESH_ACTOR_SAME_POSITION_METHOD：MapCheck 时自动修正与静态网格材质不匹配的 Override，并检查位置重叠的静态网格 Actor（UE4-3559）。
  • XD_TOOL_NOTIFY_WRONG_MATERIAL_USAGE：材质错误用法上报，供检查工具收集。
  • XD_TOOL_WARNING_COMPONENTS_THAT_NEED_TO_BE_REBUILT_LIGHTING：Cook 结束时 Dump 缺少预计算光照的组件。
  • XD_SKELMESH_CHECK_DDC_KEY_MISS_MATCH_TOOL：骨骼网格 DDC Key 不匹配检测。
  • XD_MISC_EXTENDED_KISMET2_LIB：蓝图工具函数扩展（如保持相对位置在世界中心创建蓝图）。
  • XD_SERIALIZE_UPGRADE_FIXUP_STATIC_MESH_NONUSED_PROPERTY：序列化升级补齐静态网格废弃属性，避免老资源升级后数据缺失。

2. 源码管理与提交流程

  • XD_EXT_ADD_SOURCE_CONTROL_CONTENT_FILES_FILTER_CHECKBOX：Submit 窗口新增「过滤临时文件」复选框，避免误提交。
  • XD_FE_P4_SUBMITTER_TOOL：Perforce 设置面板支持 PyP4Submitter 路径（自定义提交工具）。
  • XD_PRE_CHECKIN_EVENT_SEND：CheckIn 前广播 OnCheckinPackages(bool&, files)，外部可拦截/校验。
  • XD_BUG_FIX_P4_SOURCE_CONTROL_PATH_CASE_SENSITIVITY：P4 fstat 缓存 Key 大小写敏感修复（该宏在引擎 Source 内未检索到使用点，可能与 P4 插件版本有关）。
  • XD_MISC_DISABLE_UECHECK_FOR_AUDIO_ANIMNOTIFY：屏蔽 Wwise Audio AnimNotify 的 UECheck 依赖校验（本树内未见使用点，Wwise 插件侧消费）。

3. 纹理压缩与纹理管线

  • XD_MISC_COMPRESS_TEXTURES_WITH_ASTCENC_3_3：ASTC 纹理改用 ASTCENC 3.3 压缩。注意：切换该宏必须同步递增 TextureFormatASTC.cpp 的 BASE_ASTC_FORMAT_VERSION，否则旧纹理不会重新压缩。
  • XD_BUG_FIX_BC7_TEX_COMPRESSION：修复 BC7 ISPC 压缩器总用 mode7 导致 Alpha 通道被污染。
  • XD_TOOL_LOG_ANDROID_ETC2_TEXTURE_FILE_NAME：ETC2 压缩崩溃时打印纹理文件名。
  • XD_TOOL_LOG_COOK_TEXTURE_GROUP_SETTINGS：Cook 时打印纹理组 LOD 设置，便于核对打包体积。

4. 诊断与 Dump 工具

  • XD_TOOL_DUMP_XD_CONSOLE_VARIABLES：注册 DumpConsoleCommands_XD 命令，专列所有 xd.* 控制台变量及当前值（UBT 强制要求该宏为 1）。
  • XD_TOOL_DUMP_DETAIL_OPEN_PACKAGE_FAIL_REASON：打开包失败时输出详细原因。
  • XD_TOOL_DEBUG_LEVEL_LOADING_STOP：关卡加载停止相关调试。
  • XD_TOOL_VISUALIZE_LIGHTMAP_MIPS（默认 0）：按 Mip 给 Lightmap 上纯色，验证 Mip 使用情况（配合移动端关闭 Lightmap 方向性）。
  • XD_TOOL_PIXEL_PICKING_ROLE（默认 0）：角色像素拾取，可通过蓝图调用（截图/校准工具使用）。
  • XD_TOOL_STAT_GL_PROGRAM_MEM_SIZE：stat Shaders 显示 GL Program 显存。
  • XD_TOOL_HIGH_RES_SHOT_SUPPORT_CAPTURE_UI：HighResShot 支持把 UI 一起截进去（宣传截图常用）。
  • XD_TOOL_EXPORT_MATERIAL_ANALYZER_RESULT：材质分析结果导出 JSON（引擎 Source 内未检索到消费点，可能由编辑器插件调用）。
  • XD_TOOL_ADD_SAVE_DELEGATES_FOR_EDITOR：资产保存前后广播委托（UBT 强制为 1，是其它保存期逻辑的基础设施）。
  • XD_TOOL_DEBUG_MONOLITHIC_INFO：#pragma message 打印编译路径，代码已被 #if 0 屏蔽，属历史遗留。

5. 编辑器行为修复

  • XD_BUG_FIX_PREVIEW_CAMERA_SHAKE_WHEN_MOVE_LOCKED_ACTOR：移动锁定 Actor 时预览相机抖动。
  • XD_BUG_FIX_EDITOR_PREVIEW_FEATURE_LEVEL_NOT_MATCH_UI：预览特性等级与 UI 显示不一致（UE4-529）。
  • XD_BUG_FIX_WRONG_MAT_EDITOR_VIEWPORT_SIZE_WHEN_NOT_TONEMAP_FILM：材质编辑器视口尺寸错误。
  • XD_BUG_FIX_EDITOR_POSTPROCESS_STILL_RUN_IN_GAME_MODE：ShaderDrawDebug 等编辑器后处理在 Game 模式仍运行。
  • XD_BUG_FIX_MATERIAL_PARAM_COLLECTION_MULTI_SELECTION_CRASH：多选 MPC 崩溃（UE4-3494）。
  • XD_BUG_FIX_EDITOR_TRANSACTION_BUFFER_NULLPTR：GEditor->Trans 空指针。
  • XD_FIX_BUG_FReferencerFinder_GetAllReferencers_Crash、XD_FIX_UNINITIALIZED_bIsUObjectWrapper、XD_BUG_FIX_SpriteCategoryVisibility_OUT_OF_INDEX、XD_BUG_FIX_PAPER2D_COMMANDLET_IMPORT_ISSUE：引用查找器崩溃、GraphPin 未初始化、Sprite 分类数组越界、SpriteSheet 导入崩溃。
  • XD_EXT_EDITOR_BEHAVIOR_REWORK、XD_EXT_BROADCAST_CUSTOM_OBJECT_DUPLICATION_METHOD、XD_MISC_EDITOR_PREVIEW_SUPPORT_CUSTOM_DEPTH（默认 0）：编辑器交互重做、对象复制广播、预览支持 CustomDepth。

6. 注意事项

  • XD_TOOL_DUMP_XD_CONSOLE_VARIABLES 与 XD_TOOL_ADD_SAVE_DELEGATES_FOR_EDITOR 是 UBT 强制为 1 的基础设施宏，不要关闭。
  • ASTC 宏切换必须同步版本号，否则会出现「改了压缩器但包体没变」的假象。
  • 部分工具宏默认 0，属于「按需打开」——启用后记得回归性能（Pixel Picking、Lightmap Mip 可视化会影响渲染输出）。
