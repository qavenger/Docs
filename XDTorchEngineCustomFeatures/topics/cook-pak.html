📦 Cook / Pak / DDC / 热更

打包、增量 Cook、Pak 挂载与热更资源链路

一句话概括：围绕「确定性 Cook → 增量打包 → 预挂载热更」这条流水线做了完整改造：Cook 更快更稳、两次 Cook 产物可复现、Pak 可迭代复用、资源可按赛季热更与本地化管理。

1. 流水线全景

  1. Cook 阶段：Cherry-Pick 精简 cook、内存/停顿诊断、SaveQueue 卡死修复与限流、迭代 Cook 删除修复、Ini cook 黑名单。
  2. 确定性 / DDC 阶段：消除 Material ShaderMap、MapBuildData、静态网格 UV、ubulk 等产物中的不确定因素，配合 -XDDumpCookedMD5 与 CheckCookDeterministic.py 做校验。
  3. Pak 阶段：异步压缩调优、复用上次压缩结果的迭代打包（Iterative Pak）、任务耗时报告。
  4. 运行期 Pak：按 mount_<season>.json 预挂载、挂载失败委托、失败熔断不预挂载、可选自定义加密。
  5. 热更 / 版本 / 本地化：XD_TORCHLIGHT_SEASON 贯穿 PSO/PBC/ShaderLib/预挂载配置；本地化包缓存刷新、Package Localization Key GUID、媒体本地化路径。

2. Pak 生成与迭代打包

  • XD_OPT_CREATE_PAK_WORKS：打开自定义异步压缩策略，一次性预投递 1024 个压缩任务，使压缩充分并行（Developer/PakFileUtilities/PakFileUtilities.cpp）。
  • XD_OPT_ITERATIVE_PAK：核心优化。复用上一次 Pak 的压缩结果，只重新压缩变化的文件，并带 SHA1 校验。
  • 迭代打包相关命令行：-XDShouldIterativePak、-XDIterativePak_PakFilesDir=、-XDIterativePak_PakDiffFile=、-XDIterativePak_DoubleCheckHash、-XDIterativePak_Verbose。
  • XD_MISC_DUMP_COOKED_MD5：Cook 时把 DevelopmentAssetRegistry.bin 中的 Hash 导出到 AutomationTool 目录，迭代打包时直接用（否则要重新算全量 MD5，会吃掉大部分收益）。
  • XD_OPT_PAK_FAST_WRITE（默认 0）：大缓冲 + 异步写 Pak；作者注释「Mac 上写出错、收益有限」故关闭。
  • XD_TOOL_REPORT_PAK_TASK_TIMES：输出 <pak>_report.json 记录各任务耗时。

3. 运行期 Pak 挂载与容错

  • XD_PRE_MOUNT_PAK：引擎初始化时按 mount_<SEASON>.json（PRE_MOUNT_PAK_DIR）解析并预先挂载热更 Pak，可指定最小版本；配合 Project ShaderLib 预挂载。
  • XD_MISC_ADD_PAK_MOUNT_FAIL_DELEGATE + XD_MISC_PAK_FAIL_NO_PREMOUNT：挂载失败时广播委托，并把预挂载信号量拉高，禁止后续预挂载，交由项目热补丁模块做完整性校验与修复。
  • XD_MISC_NOTIFY_USER_ON_PAK_FATAL_ERROR：Pak 致命错误前输出用户可读的引导日志（Windows 还会弹窗）。
  • XD_MISC_PAK_FILE_ENCRY：替换 Pak Magic 并增加自定义加密版本位，防止 Pak 被随意解包。

4. Cook 主流程优化

  • XD_OPT_COOK_ENABLE_CHERRY_PICK：按清单（-XDCherryPickManifest= 或 ini）只 Cook 指定种子包，配合 XDLivePatch 做小型热更包。
  • XD_OPT_COOK_MAX_MEMORY_USAGE（默认 0）：周期统计内存并强制 Flush Shader 编译，压低 Cook 峰值内存。
  • XD_MISC_COOK_STALL_DIAGNOSTICS / XD_TOOL_REPORT_COOK_TASK_TIMES：Cook 停顿采样与层级计时，定位「时间都去哪了」。
  • XD_MISC_COOK_SAVE_QUEUE_FIX + XD_FIX_BUG_Infinite_Wait_When_Cook_Platform_Data：把卡在 pending CookedPlatformData 的包移入 stalled 队列延后处理，修复 Cook 卡死。
  • XD_MISC_COOK_SAVE_QUEUE_LOAD_THROTTLE：Mac/Windows 上 SaveQueue 超过阈值时软限流加载，避免内存与队列互相拖垮。
  • XD_MSIC_INI_COOK_BLACKLIST：记录 ini 读写历史，Cook 时按 ini 黑名单剔除无关配置，避免「改个 ini 就全量重 Cook」。
  • XD_BUG_FIX_ITERATIVE_COOK_DELETE_PACKAGE_NOT_COMPLETE、XD_MISC_*COOK_PACKAGE_NEVER_END*、XD_MISC_SAVE_PACKAGE_MOVE_FAILURE_ERR_CODE：迭代 Cook 删除遗漏、计数卡死、保存失败错误码等细节修复。
  • XD_OPT_COOK_MAC_PARALLEL_USAGE：Mac 上 Shader 编译与纹理压缩双 Worker 并行。

5. DDC 与 Cook 确定性

这一组宏解决的是「同样的输入，两次 Cook 得到不同产物」——这是热更差分、增量打包、资源 MD5 比对的前提。

  • XD_BUG_FIX_GENERATE_DETERMINED_MATSM_DDC：材质 ShaderMap DDC 确定化（含空 MaterialExpression 告警）。
  • XD_BUG_FIX_GENERATE_DETERMINED_MAP_BUILD_DATA_COOKING_RESULTS：MapBuildData 结果确定化（CleanupWorldInternal 增加 bWorldChanged）。
  • XD_BUG_FIX_GENERATE_DETERMINED_STATIC_MESH_TEXCOORDS：修正导入时 Lightmap UV 索引越界写入 DDC 的问题。
  • XD_BUG_FIX_KEEP_SAME_UBULK_FILE_WHEN_CHECK_COOK_DETERMINISTIC：diff cook 传入 SavePackageContext，保证 ubulk 稳定。
  • XD_BUG_FIX_COOK_DETERMINED_PSO + XD_BUG_FIX_BUILD_PSO_WITH_SHADER_HASH：stable.upipelinecache 确定化。
  • XD_BUG_FIX_IOS_GENERATE_STABLE_SHADER_OUTPUTHASHES：iOS/Metal Shader output hash 稳定。
  • XD_BUG_FIX_GENERATE_LANDSCAPE_MOBILE_DATA_WHEN_SAVING：保存地形时生成 MobileData，避免重 Cook 产生差异。
  • XD_TOOL_COOK_DETERMINISTIC_CHECK + Tools/CheckCookDeterministic.py：两次 Cook 的 AssetRegistry 对比校验。
  • XD_SKELMESH_CHECK_DDC_KEY_MISS_MATCH_TOOL、XD_BUG_FIX_WRONG_LOD_VERTICES_NUM_DDC：骨骼网格 DDC Key 一致性检查。
  • XD_FORCE_SATATICMESH_LOD_STREAM_BULK / XD_FORCE_ANIMATION_STREAM_BULK（默认 0）：把静态网格 LOD 渲染数据、动画数据拆入 ubulk 以降低常驻内存，开启会显著改变 I/O 结构，需评估。

6. 热更、赛季与本地化

  • XD_TORCHLIGHT_SEASON（当前 16）：一切版本/清理逻辑的枢纽——预挂载配置名、ShaderLib 头版本、PSO/PBC 缓存版本。每赛季手动递增，即自动清理旧缓存。
  • XD_MISC_CLEAN_OBSOLETE_PSO_CACHE_AND_PROGRAM_CACHE：未配置 game version 时用赛季号，换季即失效旧 upipelinecache/PBC。
  • XD_TORCHLIGHT_UPDATE_LOCALIZED_PACKAGE_CACHE：暴露本地化包缓存刷新委托，解决异步加载时本地化资源找不到的问题。
  • XD_PACKAGE_LOCALIZATION_KEY_GUID_MANUAL_SET：支持手动为 UPackage 本地化 Key 指定稳定 GUID，避免每次 Cook 生成不同 Key。
  • XD_MEADIA_FILE_LOCALIZED_PATH：媒体文件支持 Content/L10N/<Culture>/ 本地化路径查找。
  • XD_TORCHLIGHT_IGNORE_PAK_CHUNK_FIX：Pak Chunk 归属判定时忽略 Cook ini 的干扰（通过 XD_OnShouldIgnorePackageFromPakChunk 委托可进一步排除包）。
  • XD_EXT_USE_PRIORITY_WHEN_PACKAGING：按 PrimaryAssetLabel.Priority 决定 Chunk 覆盖关系；注意项目已禁用 -labelpriority 命令行。

8. 注意事项

  • 确定性宏多是「告警 + 纠正」：要根治问题需按提示重新保存相关资产（材质、静态网格、骨骼网格）。
  • 迭代打包收益依赖 MD5 导出：UAT cook 时忘记传 -XDDumpCookedMD5，加速效果会大打折扣。
  • 外部依赖：Cherry-Pick 与 XD_OPT_SHADER_LIB_SRIP 需要 XDLivePatch 插件；Wwise 两个宏在本引擎树内无消费点，由 Wwise 插件实现。
  • 平台限制：SaveQueue 限流仅 Mac/Windows；Pak 弹窗仅 Windows；XD_OPT_PAK_FAST_WRITE 因 Mac 问题默认关闭。
