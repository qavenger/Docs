🎨 渲染管线与排序

BasePass、模板、渲染优先级、半透明与 OIT

一句话概括：UE4 的渲染顺序由引擎按「材质类型 + 距离」统一决定，项目很难干预。心动定制把「顺序」与「深度/模板/颜色写入」开放给材质与 MeshBatch，并新增 TAA 后半透明与扭曲半透明两条管线，解决特效层次、渲染穿插、特殊遮罩三类问题。

1. 材质级模板测试（NativeStencil）

  • XD_RENDERING_NATIVESTENCIL_SUPPORT_MATERIAL：在材质实例属性中暴露模板参数——bOverride_StencilTestMode/StencilValue/DisableDepth、EStencilCompareOpMode、bDisableDepthTest；移动端在 MobileBasePass 的 SetDrawRenderState<> 中落地，PC 端由下面的宏扩展。
  • XD_PC_RENDERING_NATIVESTENCIL_SUPPORT_MATERIAL：PC 上把模板能力扩展到 Pre-Depth Pass（可写）、BasePass 与半透明 Pass（只测不写），通过 GetDepthStencilStateForDepthPassMaterialWithStencil<>() / SetDepthStencilStateForBasePass() 实现。
  • XD_RENDERING_DEFERRED_DISABLE_STENCIL_WRITE_IN_BASEPASS：PC Deferred 下模板写入只在 Pre-Depth 发生，BasePass 只读，省一次带宽并避免重复写入。

⚠ 典型用途：角色描边、UI 遮罩、只显示某区域、多层特效叠加；改这些宏需要清理 DDC 重编 Shader。

2. 渲染顺序（Priority）

  • XD_RENDERING_BASEPASS_RENDERING_PRIORITY：不透明/Mask 材质与图元可设置 RenderPriority，排序键中从 depth 位里让出 2 bit 存放优先级；排序模式由 CVar xd.r.BasePassSortPriorityMode 选择「按材质 / 按图元」。
  • XD_RENDERING_PER_MESHBATCH_TRANSLUCENTPASS_RENDERING_PRIORITY：半透明排序粒度从 Primitive 细化到 MeshBatch（First/SecondPerBatchTranslucentPriority），优先级钳到 8 bit，目前主要支持移动端渲染器。
  • XD_RENDERING_AUTO_GENERATE_PER_MESHBATCH_TRANSLUCENTPASS_RENDERING_PRIORITY：按 Emitter 顺序自动为粒子生成半透明优先级，特效美术无需手工排序。

3. 深度/颜色写入的特殊材质

  • XD_RENDERING_BASEPASS_OPAQUE_REVERSE_BLEND_NO_DEPTH_WRITE：Opaque 材质支持 SrcFactor=Zero, DstFactor=One 且关闭深度写入（bEnableOpaqueReverseBlend），用于“只擦除/只覆盖颜色”的特殊材质。
  • XD_RENDERING_DISABLE_COLOR_WRITE + XD_RENDERING_PC_DISABLE_COLOR_WRITE：材质可勾选不写颜色（CW_NONE），PC 端在延迟路径下这类材质不会进入 BasePass 命令，Pre-Depth 也参与处理。用于纯遮挡体、模板写入器。

4. 半透明管线：TAA 后合成与扭曲

  • XD_TRANSLUCENCY_AFTER_TAA：新增 TPT_TranslucencyAfterTAA 半透明 Pass 与对应 MeshPass；材质可指定在 TAA 之后合成，解决 TAA 与半透明特效（尤其是叠加型特效）的闪烁、拖影。
  • XD_DISTORT_TRANSLUCENCY：新增 TPT_DistortTranslucency 与独立 DistortionPass，热浪/水波/空间扭曲类效果可控且可排序；移动端可用 r.Mobile.DisableDistortion 默认关闭。

5. OIT（顺序无关透明）

  • XD_OIT_SORTKEY：新增 OITSortKey.h/.cpp 与 OITSortKeyManager，为静态网格/骨骼网格/组件逐帧计算排序键（按分组 anchor 重排）；对需要拆背面的 Mesh 追加 ReverseCulling + 第二半透明优先级的批次。用于解决毛发/披风/多层半透明穿插闪烁。

6. 其它渲染管线改动

  • XD_SCENECAPTURE_SHARED_DEPTHTEXTURE：SceneCapture 可复用主视图深度纹理（映射到自身投影），显著降低小地图/后视镜/抓拍等二次视图的开销。
  • XD_RENDERING_FORCE_FEATURE_GATHER4：强制启用硬件 Gather4 采样，加速 PCF 阴影过滤。
  • XD_OPTIMIZATION_DONT_WAIT_QUERY_RESULT_WHEN_HW_OC_DISABLED：r.AllowOcclusionQueries=0 时不再等待查询结果，减少无谓同步。
  • XD_OPTIMIZATION_RESET_OCCLUSION_HISTORY_MEMORY：换关卡时重置遮挡剔除历史，避免错误剔除与内存滞留。
  • XD_EXTRA_GBUFFER：仅声明、无引用的预留宏；XD_OPT_TRANSLUCENCY_DEPTH_PREPASS 同为声明未启用。
  • 稳定性修复：XD_BUG_FIX_USE_CUSTOM_DEPTH_OF_CURRENT_RENDERER、XD_TRY_FIX_BUG_CUSTOM_DEPTH_RT_VALIDATION_ERROR、XD_BUG_FIX_DrawCallCategoryName_INVALID_POINTER、XD_BUG_FIX_ADD_LOG_DEBUG_PARAMETER_COLLECTION_NOT_FOUND、XD_BUG_FIX_UNDRAWN_CANVASRT_SRV、XD_BUG_FIX_VALUE_OF_ALPHA_WHEN_GENERATING_MIPMAP。

7. 注意事项

  • Build 依赖：PC 模板扩展依赖材质模板宏；自动粒子排序依赖 Per-MeshBatch 优先级宏（UBT 会报错）。
  • Shader 重编：新增半透明 Pass 会改动 EMeshPass 枚举与排序布局（NumBits），修改后必须清 DDC。
  • 性能取舍：Per-MeshBatch 优先级与 OIT 排序键都有每帧 CPU 成本，开放给美术使用时要控制规模（特效优先级只在前 8 bit 内，注意钳制）。
