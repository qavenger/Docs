📱 移动端渲染优化

GLES/Vulkan 移动管线的性能与效果开关

一句话概括：移动端渲染不做「另起炉灶」，而是在 UE4 移动管线上逐项省带宽、省 Pass、省采样：Bloom/Tonemap/Depth/ShadowMask/反射捕获/遮挡剔除，每一项都有 CVar 或宏可开关。

1. 移动端 BasePass 与图元提交

  • XD_OPT_DONT_UPDATE_PRIMITIVE_UBO_WHEN_PARAMS_NOT_CHANGE：对比 PrimitiveShaderParameters，内容未变就不上传 UBO，降低移动端驱动调用开销。
  • XD_OPT_MOBILE_USE_COARSE_STATIC_SHADOW_MASK_TEXTURE：先用粗粒度静态阴影遮罩判断，完全受光/完全阴影的像素跳过逐像素 ShadowMask 采样。
  • XD_OPTIMIZATION_MOVABLE_DIRECTIONAL_LIGHT_PERMUTATION：控制是否为 Mobile 可移动平行光编译 Shader 排列（不用就不编）。
  • XD_OPTIMIZATION_PPMATERIAL_USE_IN_BASEPASS：控制后处理材质是否参与 Mobile BasePass 排列编译。
  • XD_OPT_MOBILE_LANDSCAPE_POINT_LIGHTING（默认 0）：地形点光源的 VS/PS 协同裁剪。

2. 后处理：Bloom / Tonemap / Upscale

  • XD_OPT_FAST_BLOOM：移动端 Bloom 快速路径（重排降采样与采样结构）。
  • XD_OPT_MOBILE_BLOOM_SETUP_PASS_MERGE_SAMPLES（默认 0）：Bloom Setup Pass 合并采样以减少带宽。
  • XD_OPT_CACHE_TONEMAP_LUT_TEXTURE：缓存 Tonemap LUT 结果（CVar r.EnableLUTCache）。
  • XD_OPT_MOBILE_UPSCALE_PASS_DISABLE_WHEN_SIZE_DIFF_LITTLE：Tonemap 输出与 BackBuffer 尺寸接近时跳过 Upscale。
  • XD_OPT_MOBILE_DISABLE_DISTORTION_BY_DEFAULT：新增 r.Mobile.DisableDistortion，移动端默认关闭扭曲，避免额外 Pass。

3. 深度与显存（Memoryless）

  • XD_RENDERING_MOBILE_IOS_DEPTH_FETCH：iOS 从深度 RT 采样深度，MSAA + DOF 场景的必需项（UBT 强制为 1，关闭会崩溃）。
  • XD_RENDERING_MOBILE_ANDROID_FORCE_DEPTH_FETCH + XD_OPT_ANDROID_GL_FORCE_REMOVE_DEPTH_RESOLVE_PASS：Android 直接采样深度并去掉多余的 Depth Resolve Pass。
  • XD_BUG_FIX_DEPTH_TEXTURE_SHOULD_NOT_MEMORYLESS_WHEN_PP_ACCESS：后处理需要读深度时禁用 Memoryless。
  • XD_BUG_FIX_MOBILE_CUSTOM_DEPTH_FALLBACK_DEVICE_Z、XD_BUG_FIX_EMULATOR_DEPTH：自定义深度无效值与模拟器 DXT 平台的深度处理适配。
  • XD_BUG_FIX_QUANTIZE_WINDOW_SIZE：iOS 窗口/视图尺寸取整以匹配 SceneColorMobile，消除 Tonemap 前后的缩放（UE4-2524）。

4. 反射、遮挡与画质档位

  • XD_RENDERING_MOBILE_USE_SPECIFIED_REFLECTION_CAPTURE：组件/场景可指定使用的反射捕获，避免移动端只按距离取最近捕获导致反射跳变。
  • XD_RENDERING_MOBILE_ENHANCE_REFLECTION_CATPURE（默认 0）：关闭 HQ 反射时，为球面反射捕获增加距离钳制与局部反射向量。
  • XD_OPT_MOBILE_CONTROLL_HARDWARD_OCCLUSION_CULLING：项目设置新增移动端硬件遮挡剔除开关，避免被 PC 设置误影响。
  • XD_RENDERING_LANDSCAPE_LOD_BIAS / XD_OPT_MOBILE_LANDSCAPE_NO_LOD_MORPH：地形 LOD 档位与 LOD 形变开关。
  • XD_BUG_FIX_RUNTIME_TEXTURE_LODBIAS、XD_MISC_MOBILE_USE_MIN_LOD_SIMULATE_LOD_BIAS：按设备档位设置纹理 LOD Bias，GLES 用 MIN_LOD 模拟。
  • XD_BUG_FIX_MOBILE_RENDER_THREAD_SWAP_BUFFER_INTERVAL_ERROR：修复帧率 >60 时渲染线程多等一个 VSync。
  • XD_FIX_BUG_MOBILE_SCENE_CAPTURE_TONE_CURVE_HDR_CRASH：移动预览 + FinalToneCurveHDR 抓拍的崩溃修复。

5. 注意事项

  • 移动端优化大多提供 CVar（r.Mobile.*、r.EnableLUTCache、r.LandscapeLODBias 等），宏开启不代表线上默认生效，画质档位在 DeviceProfile 中配置。
  • 部分宏默认 0（地形点光、Bloom 合并采样），是「有收益但需真机验证」的候选优化，改动后重点回归低端机。
  • Depth Fetch 相关宏与移动端 Memoryless RenderTarget 强相关，涉及 iOS 时务必保持 XD_RENDERING_MOBILE_IOS_DEPTH_FETCH=1。

引擎改动方式

L0 无需改引擎纯工程/插件/配置即可（对应「可工程化」）
L0 引擎内补丁需改引擎源码，但不必新增扩展点（对应「引擎内实现」）
L1 仅加接入点引擎只需暴露 Delegate / Interface / CVar 等扩展点
L2 结构性改动枚举 slot / 新 Pass / schema 字段
L3 深度侵入核心结构/生命周期/序列化，慎入
