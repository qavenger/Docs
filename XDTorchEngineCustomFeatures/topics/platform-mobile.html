📲 Android / iOS / Mac

移动与 Apple 平台 RHI、设备兼容与模拟器

一句话概括：移动端围绕「机型太多、驱动太杂」做了三层兜底：启动自检与降级（Vulkan↔OpenGL）、崩溃/日志可用性保障（iOS 丢日志、Metal 断言）、以及大量机型专项修复。

1. Android：RHI 自检与降级

  • XD_EXT_ANDROID_VULKAN_ENHENCED_SELF_CHECK：启动时增强 Vulkan 自检——枚举 instance 扩展/层、读取 driver 信息，历史上失败过的配置直接判定 NotSupported，避免反复崩溃。
  • XD_EXT_ANDROID_ALLOW_OPENGL_FALLBACK_TO_VULKAN：把 OpenGLFailed 状态持久化到 GameUserSettings，OpenGL 崩溃后允许回退/切换到 Vulkan（反之同理）。
  • XD_EXT_PLATFORM_UNWANTED_BEHAVIORS_TAKEOVER：Shipping 下接管平台弹框与退出请求；Vulkan 侧对应 XD_VK_FATAL_LOG_BEHAVIOR_TAKEOVER。
  • XD_MISC_SUPPORT_GOOGLE_PACKAGE_SUBMIT：适配 Google Play 提包（Android 12+ 的 android:exported 等）。
  • XD_FIX_BUG_ANDROID_X64_COMPILE_ERRORS：Android x86_64 平台编译链接修复。
  • XD_MISC_ANDROID_EXIT_WITH_ABORT_METHOD：主动退出改用 abort，让 Backtrace 能抓到信号并记录日志。

2. Android：Vulkan / OpenGL 专项修复

  • XD_BUG_FIX_VKACQUIRENEXTIMAGE_TIMEOUT / _TESTING：vkAcquireNextImageKHR 返回 VK_TIMEOUT 时按超时处理（旧驱动常见），测试用宏务必保持 0。
  • XD_BUG_FIX_VKACQUIRENEXTIMAGE_SWAPCHAIN：修复交换链未初始化时的空指针异常。
  • XD_BUG_FIX_VK_DEFRAG_CRITICAL_SECTION：Vulkan 内存分配器碎片整理补上临界区，避免多线程竞争。
  • XD_BUG_FIX_VULKAN_TILE_FAST_CLEAR_ARTIFACT：部分机型（如 Mate20）Tile Fast Clear 花屏的规避。
  • XD_MISC_VULKANGPU_TIMESTAMP_QUERY（默认 0）：高通芯片手机的 Vulkan GPU 时间戳查询，用于真机性能分析。
  • XD_MISC_MOBILE_USE_MIN_LOD_SIMULATE_LOD_BIAS：GLES 不支持纹理 LOD Bias，用 GL_TEXTURE_MIN_LOD 模拟。
  • XD_MISC_LOG_OPENGL_FUNCTION_CALL_TRACE（默认 0）：包装所有 GL 调用用于调试。
  • XD_BUG_FIX_ANDROID_glGetString_Crash、XD_FIX_BUG_ANDROID_MOUNT_OBB_FAIL、XD_BUG_FIX_ANDROID_LOG_CANNOT_GENERATE、XD_BUG_FIX_ANDROID_WAIT_FOR_SAFE_ZONE_WAS_UPDATED_BEFORE_CHANGING_ORIENTATION：驱动查询崩溃、OBB 挂载崩溃、日志无法生成、切横竖屏安全区等工程问题修复。

3. iOS / Mac / Metal

  • XD_MISC_IOS_REQUEST_EXIT_BY_FORCE：iOS 使用 _Exit(0) 直接结束进程（避免退出流程卡死）。
  • XD_MISC_APPLE_HOME_INDICATOR_NO_AUTO_HIDDEN：关闭 Home Indicator 自动隐藏（游戏场景不希望它出现/消失）。
  • XD_BUGFIX_IOS_LOSTLOG / XD_BUGFIX_IOS_LOSTLOG_ISSUE：修复 iOS Test 构建丢日志；_ISSUE 为专项调试宏（默认 0，勿提交为 1）。
  • XD_BUG_FIX_IOS_FATAL_ERROR_DONT_PRINT_MSG_AND_CALLSTACK：iOS 致命错误信息与调用栈写入日志文件。
  • XD_BUG_FIX_METAL_VERTEX_BUFFER_VIEW_VALIDATION_ERROR：Xcode Metal Validation 开启时的顶点缓冲校验报错修复。
  • XD_BUG_FIX_METAL_CRASH_FLUSH_LOG：Metal 断言触发时先 Flush 日志。
  • XD_BUG_FIX_MSAA_CRASH_ON_MAC：Mac MSAA 崩溃（同步 UE-427 官方修复）。
  • XD_BUG_FIX_SYNC_RELEASE_RHI_RESOURCE：释放 MetalUniformBuffer 的崩溃修复（同步 RHI 资源释放）。
  • XD_BUG_FIX_IOS_MALLOC_BINNED_NANO_MEMORY_CORRUPTION：iOS MallocBinned nano 区域内存越界写修复。
  • XD_BUG_FIX_IOS_NOTIFICATION_FREEZES_GAME、XD_BUG_FIX_IOS_TEXT_INPUT_CRASH、XD_AVF_NO_PREROLL、XD_BUG_FIX_AVF_TASK_QUEUE、XD_BUG_FIX_IOS_AUDIO_CHECK_FAILURE：通知卡死、中文输入崩溃、AVF 播放器回调/线程问题。

4. 工具链与构建

  • XD_MISC_XCODE_SUPPORT_15：支持 Xcode 15 构建。
  • XD_MISC_XCODE27_SCENELIFE_CYCLE：为较新 Apple SDK 输出 UIKit Scene Manifest 与 SceneDelegate 钩子。
  • XD_MISC_SOLVE_MAC_PLATFORM_VFORK_COMPILE_WARNING：vfork 弃用警告修复（UE4-3084）。
  • XD_FIX_BUG_MAC_CREATE_MENU_SHOULD_IN_MAIN_THREAD：Mac 菜单创建回到主线程。
  • XD_RENDERING_METAL_HALF（默认 0）：Metal 平台 half 精度相关开关。
  • XD_MISC_TURN_OFF_IOS_GLOBAL_NEW_DELETE_OPERATOR：当前代码为 #if 0 关闭状态。
  • XD_OPT_IOS_CONFIG_CREATE_DEBUG_METAL_LIB：允许在 Shipping/Test 构建跳过 Metal 源码 zip 步骤。

5. 模拟器（PC 上跑移动包）

  • XD_EMULATOR_EXTRA_INI：模拟器启动时叠加 Emulator 目录的 ini，方便为模拟器单独调画质/输入。
  • XD_RENDERING_EMULATOR_SUPPORT_HIGH_RES_DXT（+ _DEBUG）：模拟器包使用高分辨率纹理（Emulator 专用 LodBias），保证模拟器画质用于 QA/直播。
  • XD_MISC_ANDROID_EMULATOR_USE_NATIVE_RESOLUTION：模拟器使用原生分辨率。
  • XD_RENDERING_EMULATOR_CONTROL_MOUSE_ICON_VISIBILITY：控制模拟器鼠标光标显隐。
  • XD_BUG_FIX_MUMU_GL_BACK_BUFFER_SAMPLE（PC 专题页）与 XD_BUG_FIX_DISABLE_PROGRAM_BINARY_IN_MUMU_EMULATOR（PSO 专题页）：MuMu 模拟器的 GL/PBC 专项修复。

6. 移动端输入与屏幕

  • XD_MISC_GET_RAW_TOUCH_POSITIONS：暴露原始触点坐标（SWidget/PlayerInput/PlayerController 全链路），解决 UI 缩放后的触点偏移问题（UE4-4557）。
  • XD_MISC_ANDROID_RESCALE_THE_MOBILE_BACK_BUFFER / XD_MISC_IOS_RESCALE_THE_MOBILE_BACK_BUFFER（均默认 0）：按窄边缩放 BackBuffer，可由 CVar 覆盖。
  • XD_EXT_ADD_ANDROID_GET_SCREEN_SIZE_INTERFACE：Android 新增 GetScreenSize() 返回真实屏幕尺寸。
  • XD_MISC_ADD_SetDeviceOrientation_Method：游戏侧可主动控制设备方向。
  • XD_MISC_ADD_GRANT_PERMISSION_STAGE_BEFORE_GET_USER_IFNO：获取用户信息前先走权限申请（合规）。
  • XD_MISC_STRICT_DS_CONTROLLER_SELECT：Android 上严格识别 DS4/DualSense 手柄。

7. 注意事项

  • UBT 强制项：XD_RENDERING_MOBILE_IOS_DEPTH_FETCH 被 CheckDependencies 要求必须为 1，关闭会导致 iOS 在 MSAA+DOF 下崩溃。
  • Vulkan/OpenGL 的降级状态写进 GameUserSettings；清理玩家配置目录后回退记录会丢失。
  • 模拟器专用修复（MuMu/PBC/BackBuffer）只影响 QA 环境，正式机型不受影响，但相关宏不建议关闭。

标签说明

颜色规则：覆盖度=红绿灯 · 工程化=蓝色系 · 侵入=紫色系 · 处置=中性灰。
分级方式：工程化/侵入用「实心 → 底色 → 描边 → 虚线」四级形态表示程度递进（实心最强）。

UE5 覆盖度

UE5 已覆盖UE5.8 原生等价，可直接删除
部分覆盖UE5 有同类能力，只迁差异部分
未覆盖UE5 没有该能力，需迁移或补丁
待确认证据不足，迁移前需人工确认

落地位置（工程化可行性）

可工程化放项目/插件/配置即可，不动引擎
需接入点引擎留少量 Hook，逻辑在工程侧
引擎内实现必须改引擎核心
—处置=删除的行不适用（已删除/不迁移）

引擎改动方式

L0 无需改引擎纯工程/插件/配置即可（对应「可工程化」）
L0 引擎内补丁需改引擎源码，但不必新增扩展点（对应「引擎内实现」）
L1 仅加接入点引擎只需暴露 Delegate / Interface / CVar 等扩展点
L2 结构性改动枚举 slot / 新 Pass / schema 字段
L3 深度侵入核心结构/生命周期/序列化，慎入

迁移处置

删除UE5 已覆盖，直接删
常开补丁确认的 bugfix，作为 fork 常开补丁
配置化改为 CVar / ini / DeviceProfile / 命令行
插件化迁到项目模块 / 编辑器插件
接入点引擎只留 Hook，逻辑在插件
移植代码保留，适配后移植
保留引擎深度绑定，暂留并登记 Feature Card
