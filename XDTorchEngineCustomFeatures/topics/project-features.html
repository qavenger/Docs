🔥 火炬之光项目特性

XD_TORCHLIGHT_* 项目级定制

一句话概括：XD_TORCHLIGHT_* 是项目组（而非引擎组）维护的特性开关：UI 工作流、物理动画、地形、DLSS、热更赛季号与一批引擎行为微调。它们默认值即项目现状，多数由策划/美术工作流决定。

1. 赛季与热更

  • XD_TORCHLIGHT_SEASON（当前 16）：赛季号，是热更体系的枢纽——预挂载配置 mount_<season>.json、ShaderLib 头版本、PSO/PBC 缓存版本都引用它。每赛季手动递增即可自动清理旧缓存。
  • XD_TORCHLIGHT_IGNORE_PAK_CHUNK_FIX：Pak Chunk 划分时忽略 Cook ini 干扰，修正 Chunk 归属。
  • XD_TORCHLIGHT_UPDATE_LOCALIZED_PACKAGE_CACHE：暴露本地化包缓存刷新委托，保证异步加载能命中本地化资源。
  • XD_FORCE_SATATICMESH_LOD_STREAM_BULK / XD_FORCE_ANIMATION_STREAM_BULK（默认 0）：把静态网格 LOD 渲染数据/动画数据拆入 ubulk 流式文件，降低常驻内存；开启会显著改变 I/O 结构。

2. 渲染与画质

  • XD_CSM_SHADOW_OPT：级联阴影（CSM）优化，配合移动端点光动态阴影关闭保证双端一致。
  • XD_TORCHLIGHT_USE_DLSS：项目级 DLSS 开关（与 XD_PC_DLSS_SUPER_SAMPLING 配合）。
  • XD_MATERIAL_DYNAMIC_SWITCH + XD_MATERIAL_SELECTOR_SWITCH_NUM（7）：动态材质开关与材质 Selector 的最大节点数——用少量材质 + 运行时切换替代大量材质变体，直接减少 Shader 编译与包体。
  • XD_TORCHLIGHT_LANDSCAPE_GENERATE_MID_BY_DEFAULT（默认 0）：地形默认生成动态材质实例。

3. UI 工作流（PSD / 蓝湖 / HDUI）

  • XD_TORCHLIGHT_WIDGET_ADD_PSID：控件保存 PSD2UMG 同步的原始 Photoshop 节点 ID（PsId/SkipAdjust/PSDDelta，仅编辑器），便于 UI 迭代时把引擎控件与 PSD 图层对应起来。
  • XD_TORCHLIGHT_WIDGETBLUEPRINTEDITOR_PASTEWIDGET_LANHU_RULE：从蓝湖复制粘贴 UI 代码时按规则校正资源对象。
  • XD_TORCHLIGHT_UMG_AUTOWRAP：UMG 设计器自动换行命令与布局调整逻辑。
  • XD_TORCHLIGHT_MARGIN_HDUI_SCALE：HDUI 九宫格边距按缩放系数换算。
  • XD_TORCHLIGHT_SASSETPICKER_IGNORE_HDUI_ASSETS：资源选择器过滤 hdui 目录资源。
  • XD_TORCHLIGHT_WIDGET_CUSTOMIZE_TITLE_BAR、XD_TORCHLIGHT_WIDGET_NEW_INTERFACE、XD_TORCHLIGHT_SLISTPANEL_ADD_ELISTITEMALIGNMENT_EVENLUFIXWIDE、XD_TORCHLIGHT_FOCUS_TO_GAMEVIEWPORT_ON_COMMIT、XD_TORCHLIGHT_RELEASE_INSTANCEDECORATORS_IN_URICHTEXTBLOCK：标题栏、控件接口、列表排列、文本提交焦点、富文本装饰器释放。
  • XD_TL_SlateVectorArtData_AddNewCreateMethod：SlateVectorArtData 运行时重建方法。

4. 动画、物理与导入

  • XD_TORCHLIGHT_PHYSICSANIM_ADJUST：物理动画调整（骨骼物理混合/模拟参数），适配角色物理表现。
  • XD_TORCHLIGHT_IMPORTSCENECONVERT_FORCEFRONTXAXIS：导入场景转换强制 +X 为正面朝向，统一美术资源方向。
  • XD_TORCHLIGHT_TASK_GRAPH_EXT：TaskGraph 扩展，供项目并行任务使用。
  • XD_TORCHLIGHT_RUNTIME_DEVICE_PROFILE：运行时切换 DeviceProfile（按设备/画质档位动态调整分辨率与特效等级）。
  • XD_TORCHLIGHT_DISABLE_IDLE_TIMER：禁用引擎空闲计时器。
  • XD_TORCHLIGHT_GAMEVIEWPORT_ALLOW_OVERRIDE_COMMAND_HANDLE：允许项目重写 GameViewportClient 的命令处理。

5. 前端与提交工具

  • XD_FE_P4_SUBMITTER_TOOL：P4 Submitter 工具（Perforce 提交流程辅助）。
  • XD_PRE_CHECKIN_EVENT_SEND：提交前事件发送，可接 CI/检查流程。

6. 注意事项

  • 赛季号必须人工维护：忘了递增会导致旧 PSO/PBC/预挂载配置继续生效，热更后表现为「改了没效果」或「缓存冲突」。
  • XD_TORCHLIGHT_SLISTPANEL_ADD_ELISTITEMALIGNMENT_EVENLUFIXWIDE 仅作为改动标记：相关代码在 SListPanel.cpp 中无 #if 保护、直接生效；且其名称拼写与代码注释里的 EVENLYFIXSIZE 不一致，检索时留意。
  • XD_TORCHLIGHT_USE_DLSS 在引擎 Source 内无使用点，实际由 XD_PC_DLSS_SUPER_SAMPLING 的项目侧配置消费。
  • uubulk 拆分（XD_FORCE_*_STREAM_BULK）默认关闭，属于「内存不够时再开」的调节阀。
