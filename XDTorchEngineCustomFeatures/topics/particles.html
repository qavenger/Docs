✨ 粒子与特效

实例化、快速组件、内存池、Tick 调度与工具链

一句话概括：粒子是这套引擎改动量最大的系统（56 个宏）。整体思路是：组件分层（普通/哑元/快速）+ 实例化合批 + 内存池 + 异步数据填充 + 精细 Tick 调度，再配一整套编辑器工具与数据修复。

1. 组件体系：普通 / 哑元 / 快速三种形态

  • XD_OPT_PARTICLE_COMPONENT_INTERFACE：把 UParticleSystemComponent 抽象出基类 UBaseParticleSystemComponent 与纯虚接口 IParticleComponentInterface（EParticleComponentType{PCT_Normal, PCT_Fast}），上层管理代码统一通过接口调用真实 API。
  • XD_OPT_DUMMY_PARTICLE_SYSTEM_COMPONENT：ConvertToDummyComponent() 把不再需要渲染的粒子组件转为哑元——关闭渲染、释放 EmitterInstances，只保留占位。适合大量“平时不播、偶尔触发”的挂点。
  • XD_OPT_FAST_PARTICLE_SYSTEM_COMPONENT：UFastParticleSystemComponent 让渲染线程接管部分粒子重计算，避免帧末 GT→RT 的整包拷贝；由 CVar fx.FPSC.Enable 控制，默认 0 且编辑器内禁用，属于“打开需真机验证”的高收益优化。
  • XD_OPT_SUPPORT_DIRECT_CONTROLL_PARTICLE_FUNCTIONS：提供绕过组件生命周期、直接 spawn/destroy/改 Transform 的粒子 API，便于大规模特效管理器使用。

2. 实例化与内存池（性能核心）

  • XD_OPT_PARTICLE_INSTANCING：把多个 PSC 的同类 Emitter 合并为一次实例化渲染/模拟（InstancedParticleManager + 粒子顶点工厂改造 + Shader 侧实例数据）。配套 XD_TOOL_GENERATE_PARTICLE_ID 生成标识、XD_OPT_PARTICLE_INSTANCING_DEBUG 导出集合、XD_OPT_PARTICLE_INSTANCING_DISABLE_ON_MAC_EDITOR 规避 Mac 编辑器问题。
  • XD_OPT_LOCK_FREE_PARTICLE_MEMORY_POOL：粒子无锁内存池，用于 EmitterInstance Resize 与 GT→RT 数据传输。
  • XD_OPT_PARTICLE_FAST_POOLS_ADD_EXTRA_CONTROLL：小内存快池增加按特效类型的精细控制（如仅 Ribbon 使用快池），并有调试宏 ..._PRINT_DEBUG_LOGS（Shipping 自动置 0）。
  • XD_OPT_PARTICLE_ParticleDynamicData_MEMORY_FAST_POOL：FParticleDynamicData 分配走快池。
  • XD_OPT_PARTICLE_COMPONENT_INTERFACE / XD_OPT_DUMMY_...：见上节。

3. 多线程与异步数据填充

  • XD_OPT_PARTICLE_INSTANCE_MULTI_THREAD_FILL_DATA：多线程填充实例数据（CVar GFXAllowParallelFillParticleDatas）。
  • XD_OPT_PARTICLE_GET_DYNAMIC_MESH_ELEMENTS_USING_ASYNC：粒子与实例化粒子通过 FMeshElementCollector::AddHeavyTask 异步收集 MeshElement（Sprite/Mesh/Trail 各有 CVar 开关）。
  • XD_OPT_PARTICLE_UPDATE_DATA_COMMAND_USING_ASYNC：ParticleUpdateDataCommand 异步提交。
  • XD_OPT_FAST_PARTICLE_SYSTEM_COMPONENT：让 RT 接管部分计算，从根上减少跨线程数据量。

4. Tick 调度与可见性裁剪

  • XD_OPT_PRIMITIVE_FRUSTUM_CULLING_WITH_EXTENT_BOUNDING_BOXES：给图元提供多个包围盒，GT 端做视锥剔除，结果驱动“停顿不可见循环粒子/降低不可见粒子数据量”。
  • XD_OPT_PARTICLE_CONTROLL_PAUSE_OR_NOT：粒子资产新增 bPauseWhenNoVisible，不可见时暂停。
  • XD_OPTIMIZATION_FORCE_PARTICLE_SKIP_TICK / XD_OPTIMIZATION_ALLOW_PARTICLE_USE_CUSTOM_TICK_FREQUENCY：强制跳过 Tick、不可见时使用自定义 Tick 频率降频。
  • XD_OPTIMIZE_EFFECTIVE_PSC_TICKGROUP：PSC 依据挂点父组件计算 TickGroup，避免管理器在多组重复 Tick。
  • XD_OPTIMIZE_MORE_TICKGROUP_EVENT_BASIC：各 TickGroup 提供 enter/leave 委托，供项目统计与任务调度。

5. 渲染与外观扩展

  • XD_RENDEING_ADJUST_PARTICLE_LUMINANCE_AND_ALPHA：组件级全局亮度/Alpha 乘数（bAllowModifyLuminance/bAllowModifyAlpha + SetLuminanceScale/SetAlphaScale），通过额外 UBO 传给 Shader；配合 XD_RENDERING_ADJUST_BLOOM_MIN_RGB_VALUE 抑制过曝。
  • XD_RENDERING_PER_MESHBATCH_TRANSLUCENTPASS_RENDERING_PRIORITY + XD_RENDERING_AUTO_GENERATE_...：粒子按 Emitter 顺序自动生成半透明渲染优先级，解决多层特效的排序穿插。
  • XD_EXT_ALIGN_PARTICLE_SYSTEM_AXIS_WITH_CAMERA：粒子系统轴向对齐相机（要求 Emitter 勾选 bUseLocalSpace）。
  • XD_EXT_EXCLUDE_EMITTERS_FROM_PLATFORM：Emitter 可标记 bExcludeFromMobile/bExcludeFromDesktop，Cook 时按平台裁剪。
  • XD_MISC_MESH_PARTICLES_USE_STATIC_MESH_MIN_LOD：Mesh 粒子用 StaticMesh 的 MinLOD 控制 LOD（即使 fx.FXAllowParticleMeshLODs=0）。

6. 玩法/工具链扩展

  • XD_OPT_PARTICLE_SYSTEM_PRIMARY_CATEGORY_TAG + XD_PARTICLE_SYSTEM_ADD_ONE_TYPE_TAG：粒子资产增加主分类标签与玩法标签，运行时可查询、编辑器可筛选，是特效分级管理的入口。
  • XD_TOOL_DUMP_PARTICLE_COMPONENTS_INFO、XD_TOOL_ADD_PARTICLE_ACTIONS_MENU_ESTENSIONS、XD_TOOL_ADD_CASCADE_EDITOR_TOOLBAR_EXTENSIONS、XD_TOOL_PARTICLE_COLLISION_DISABLE_AS_DEFAULT、XD_TOOL_PARTICLE_SYSTEM_ADD_THOUGHT_AS_LOOPING、XD_TOOL_ALLOW_ACCESS_BOUNDING_GEOMETRY_BUFFER：Dump、菜单扩展、默认值、标记与属性开放。
  • XD_EXT_BROADCAST_PARTICLE_SPAWN_IN_ANIMNOTIFY、XD_MISC_SUPPORT_SKIP_OWNER_VISIBILITY_CHECK_WHEN_SPAWN_PARTICLE_INSTANCE、XD_MISC_PARTICLE_DESTORY_WHEN_HAS_ZERO_LIFE_USED_IN_ANIM_NOTIFY_STATE：动画通知生成粒子的时机广播、跳过 Owner 可见性检查、零寿命粒子自动销毁。
  • XD_MISC_DEBUG_PARTICLE_MEM_ERROR、XD_MISC_DEBUG_PARTICLE_PERF、XD_MISC_COLLECT_PARTICLE_MEM_FROM_STAT、XD_OPT_PARTICLE_FAST_POOLS_PRINT_DEBUG_LOGS：内存越界追踪、性能埋点与内存采集。

7. 一批数据/逻辑修复（挑重点）

  • XD_BUG_FIX_PARTICLE_INIT_TANGLED_EMITTER_INSTANCE_POINTER：NumInstances > NumEmitters 时的悬垂指针。
  • XD_BUG_FIX_CONSIDER_ROTATION_AND_SCALE_IN_EMITTER_SIMULATION_WORLD：Emitter 模拟空间矩阵考虑旋转/缩放，并在接近零值时钳制，避免求逆异常。
  • XD_BUG_FIX_MORE_ACCURATE_SOURCE_MOVEMENT_MODULE_IMPLEMENTAION：SourceMovement 偏移计算更精确（考虑 LegacySpawn 与位置插值）。
  • XD_BUG_FIX_GET_VALID_PARTICLE_DATA、XD_BUG_FIX_ERROR_RIBBON_DYNAMIC_DATA_REQUIRED_QUERY_RETURN_VALUE、XD_BUG_FIX_PARTICLE_BEAM_TRAIL_VERTEX_FACTORY_RETURN_POINTER、XD_BUG_FIX_MESH_PARTICLE_INVERSE_TRANSFORM_WITH_SCALE：Beam/Ribbon/Mesh 粒子的数据与矩阵修复。
  • XD_BUG_FIX_PARTICLE_ERROR_TICK_WITH_FIXED_TIME_MODE、XD_BUG_FIX_DISABLE_PSC_TICK_WHEN_GETS_NULL_WORLD、XD_BUG_FIX_DO_NOT_ADD_PSC_TO_MANAGER_WHEN_WORLD_TEARING_DOWN、XD_FIX_BUG_PARTICLE_EMITTER_STAT_COUNT_FAIL、XD_BUG_FIX_INDRECTIVE_LIGHT_DATA_OF_PARTICLE_FAIL：Tick、世界生命周期、统计与间接光的修复。
  • 三个默认关闭的潜在修复：XD_BUG_FIX_PARTICLE_MODULE_SPAWN_RELATIVE_TIME_EXTRA_CALIBRATION、XD_BUG_FIX_PARTICLE_RIBBON_EMITTER_INSTANCE_CURRENTSIZES_INIT、XD_BUG_FIX_PARTICLE_MODULE_SIZE_BY_TIME_SPAWN_INITIAL_SIZE。

8. 注意事项

  • XD_OPT_FAST_PARTICLE_SYSTEM_COMPONENT 虽是宏 1，但运行时 fx.FPSC.Enable 默认 0，且编辑器内强制不用；同时它开启时会强制关闭粒子快池（GEnableFastPools=0），两者是取舍关系。
  • 四个 UBT 强制依赖：PARTICLE_COMPONENT_INTERFACE → DUMMY_PARTICLE_SYSTEM_COMPONENT、GENERATE_PARTICLE_ID → PARTICLE_INSTANCING、INSTANCING_DEBUG → INSTANCING、FAST_POOLS_PRINT_DEBUG_LOGS → FAST_POOLS_ADD_EXTRA_CONTROLL。
  • 粒子实例化原在 UBT 里按平台自动关闭（Mac 编辑器），现已改为 C++ 内判断，避免 Definitions.h 变化导致全量重编。
