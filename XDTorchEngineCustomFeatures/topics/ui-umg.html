🪟 UI / Slate / UMG

控件、文本字体、布局与编辑器 UI 工具

一句话概括：把 UE4 的 Slate/UMG 改造成「手游 UI 可用」的形态：批处理与像素对齐可控、文本字体更稳、安全区/ComboBox/滚动条等控件补齐，并给火炬之光的 UI 工作流（蓝湖/PSD/HDUI）做了一整套定制。

1. UI 性能与批处理

  • XD_TOOL_MANUAL_BATCH_WIDGETS_BY_ZORDER：为 SConstraintCanvas（UMG CanvasPanel）引入「按 ZOrder 手动分批」，把同层相邻控件合并成一个绘制批次，减少 UI DrawCall；运行时由 CVar r.Mobile.EnableManualBatchWidgetsByZOrders 控制。
  • XD_TOOL_SLATE_SHOW_LAYER_ID_WHEN_DEBUG_BATCH：slate.showBatch 1 时额外渲染 LayerId+数字纹理，直观查看批次划分。
  • XD_MISC_SLATE_ADD_DEBUG_NAME：Slate 渲染资源带调试名，抓帧时能对应到具体控件。
  • XD_OPT_CUSTOM_CONCURRENT_SLATE_TASK：通过 OnBeforeSlateTick 委托把 Slate Tick 拆成并发任务，降低 UI 造成的 GT 卡顿。
  • XD_BUG_FIX_SLATE_UI_MATERIAL_BATCH：修复首次启动时 FeatureLevel/ShadingPath 非法导致 UI 不走材质合批（表现为首启 UI 卡）。

2. 像素对齐（Pixel Snapping）

  • XD_EXT_UE5_WIDGET_PIXEL_SNAPPING：移植 UE5 的 EWidgetPixelSnapping{Inherit/Disabled/SnapToPixel}，控件级控制是否对齐像素，解决 UI 缩放下的模糊/抖动。
  • XD_DISABLE_SLATE_PIXEL_SNAPPING：提供全局关闭开关 slate.EnablePixelSnapping，与文本渲染配合（描边文字在像素对齐下容易丢笔画）。

3. 文本与字体

  • XD_TOOL_SLATE_UMG_TEXT_VERTICAL_JUSTIFICATION：新增文本垂直对齐（Top/Center/Bottom），贯穿 FTextLayout、STextBlock、SRichTextBlock 与各可编辑文本控件，并带 UMG 编辑器自定义面板。
  • XD_BUG_FIX_SLATE_ASYNC_LOADING_FONT_MISSING_TEXT：修复异步字体加载未完成时把「缺字的排版结果」当成稳定结果缓存，导致文字永久缺失。
  • XD_BUG_FIX_ADJUST_FONT_ATLAS_DEFAULTS：调整字体图集默认页数/增长策略，避免 UI 闪烁（UE4-6450）。
  • XD_BUG_FIX_FONT_CACHE_MEM_LEAK、XD_BUG_FIX_FONT_PURE_FUNCTION_CALLED、XD_BUG_FIX_FONT_GLYPH_INVALID_SIZE_DUMP：字体缓存泄漏、纯虚函数崩溃、异常字形尺寸（>2K）转储。
  • XD_TOOL_DEBUG_SHOW_FREETYPE_FONT_RENDER_DATA（默认 0）：打印 FreeType 渲染结果，专治字体发虚/缺字。
  • XD_FIX_BUG_TEXT_BLOCK_ERROR_LAYER_ID_WHEN_USING_OUTLINE：描边文本的 LayerId 修正（CVar s.UseTextBlockLayerIdNewMethod）。

4. 控件与布局扩展

  • XD_EXT_SLATE_FIX_COMBO_BOX_LIST_WIDTH：ComboBox 支持固定下拉列表宽度（UE4-5581）。
  • XD_EXT_SLATE_SYMMETRIC_SAFE_ZONE：安全区对称填充（刘海屏左右对称适配，UE4-6438）。
  • XD_EXT_OVERRIDE_SAFE_ZONE：用 CVar（SafeZone.Landscape.*）覆盖安全区尺寸，方便 QA 验证与机型调试（UE4-6555）。
  • XD_EXT_PREVIEW_RETAINER_BOX_EFFECT_IN_EDITOR：编辑器内实时预览 RetainerBox 效果（UE4-7060）。
  • XD_OPTIMIZE_CUSTOMIZE_SCROLLBOX：ScrollBox 内部成员改为 protected，便于项目派生定制。
  • XD_BUG_FIX_LIST_VIEW_SCROLL_BAR_BRUSH_ADAPT、XD_BUG_FIX_RICHTEXT_CLICK_FAILD_IN_SCALEBOX、XD_BUG_FIX_MOUSE_LEAVE_WIDGETS_WHEN_CLICK_FASTLY、XD_BUG_FIX_IOS_UI_CACHEDELEMENTDATA_CRASH、XD_TRY_FIX_BUG_SLATE_INVALID_TEXTURE_PTR：滚动条贴图刷新、富文本点击、快速点击丢鼠标、iOS 缓存元素崩溃、纹理指针失效等交互/稳定性修复。

5. 火炬之光 UI 工作流定制

  • XD_TORCHLIGHT_WIDGET_ADD_PSID + XD_TORCHLIGHT_WIDGET_NEW_INTERFACE：控件保存 PSD 节点 ID（PsId/SkipAdjust/PSDDelta），并提供 GetWidgetFromPsId 反查接口，打通 PSD2UMG 迭代流程。
  • XD_TORCHLIGHT_WIDGETBLUEPRINTEDITOR_PASTEWIDGET_LANHU_RULE：从蓝湖复制粘贴 UI 代码时按 LanHuResourceObject 校正资源引用。
  • XD_TORCHLIGHT_UMG_AUTOWRAP：UMG 设计器新增「自动包裹」命令与布局调整逻辑。
  • XD_TORCHLIGHT_MARGIN_HDUI_SCALE：HDUI 九宫格边距按 Margin.HduiScale 缩放，保证高清 UI 在不同分辨率下的布局一致。
  • XD_TORCHLIGHT_SASSETPICKER_IGNORE_HDUI_ASSETS：资源选择器过滤 hdui 目录资源，避免美术误选。
  • XD_TORCHLIGHT_SLISTPANEL_ADD_ELISTITEMALIGNMENT_EVENLUFIXWIDE：列表新增 EvenlyFixWide/EvenlyFixSize 排列方式。
  • XD_TORCHLIGHT_WIDGET_CUSTOMIZE_TITLE_BAR：自研窗口标题栏绘制。
  • XD_TORCHLIGHT_RELEASE_INSTANCEDECORATORS_IN_URICHTEXTBLOCK：释放富文本时清空装饰器引用，避免资源滞留。
  • XD_TORCHLIGHT_FOCUS_TO_GAMEVIEWPORT_ON_COMMIT：文本提交后用 SetAllUserFocusToGameViewport 代替 ClearKeyboardFocus，保证提交后仍能接收键盘输入。
  • XD_TL_SlateVectorArtData_AddNewCreateMethod：矢量图数据支持运行时重建。

6. 编辑器与运行时配套

  • XD_EXT_EDITOR_BEHAVIOR_REWORK：修正编辑器若干反直觉交互（ToolsContext 命名、属性面板、搜索下拉等）。
  • XD_TOOL_ADD_RUNTIME_DELEGATES_EXTENSION：新增 XDRuntimeDelegates（PSC 生命周期、WorldCulling 等），项目可不改引擎注入逻辑。
  • XD_TOOL_ADD_DELEGATES_PRE_TICK_ON_SLATE_LOADING_TIME：Slate 加载阶段 Tick 前广播，便于做 Loading 期 UI 动画。
  • XD_MISC_ALLOW_REQUEST_UI_UPDATE_DELEGATE_IN_CPP：开放 OnGameUserSettingsUINeedsUpdate 委托。
  • XD_MISC_MEDIA_TEXTURE_ALLOW_KEEP_LAST_FRAME：媒体播放结束后可选择保留末帧而非清空。
  • XD_BUG_FIX_GAME_MOVIE_PLAYER_DPI、XD_BUG_FIX_RESTORE_ASPECT_RATIO_CONSTRAINT、XD_BUG_FIX_UMG_PLAYSEQUENCE_ON_LATENT_ACTION：首启 MoviePlayer DPI、纵横比约束恢复、UMG 动画在 Latent Action 中播放。

7. 注意事项

  • 多数扩展同时提供 CVar 运行时开关（slate.EnablePixelSnapping、r.Mobile.EnableManualBatchWidgetsByZOrders、SafeZone.Landscape.*），编译宏为 1 不代表线上一定开启。
  • XD_TORCHLIGHT_WIDGET_ADD_PSID 的 #if 在 Widget.h 中已被注释，字段实际无条件编译，宏仅具文档意义。
  • XD_BUG_FIX_MOUSE_LEAVE_WIDGETS_WHEN_CLICK_FASTLY 在非桌面平台会被 UBT 自动置 0；编辑器中刻意保留布局失效行为以免拖拽丢鼠标。

UE5 覆盖度

UE5 已覆盖UE5.8 原生等价，可直接删除

未覆盖UE5 没有该能力，需迁移或补丁

工程化可行性

可工程化放项目/插件/配置即可，不动引擎
需接入点引擎留少量 Hook，逻辑在工程侧
引擎内实现必须改引擎核心

引擎侵入等级

L0 无需侵入不改引擎源码
L1 仅加接入点Delegate / Interface / CVar 等扩展点
L2 结构性改动枚举 slot / 新 Pass / schema 字段
L3 深度侵入核心结构/生命周期/序列化，慎入

迁移处置

删除UE5 已覆盖，直接删
常开补丁确认的 bugfix，作为 fork 常开补丁
配置化改为 CVar / ini / DeviceProfile / 命令行
插件化迁到项目模块 / 编辑器插件
接入点引擎只留 Hook，逻辑在插件
移植代码保留，适配后移植
保留引擎深度绑定，暂留并登记 Feature Card
