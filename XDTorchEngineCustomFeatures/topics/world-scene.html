🌳 世界、植被、地形与动画

ISM/HISM、Landscape、多世界、流送与 Sequencer

一句话概括：围绕「大世界 + 移动端 + 多世界后台加载」三个前提，对植被实例化、地形绘制、纹理流送、动画/Sequencer 与网格资产链路做了系统改造，核心目标是降低带宽与提交量，同时保证多世界/FeatureLevel 切换的稳定性。

1. 植被 ISM/HISM：移动端性能主战场

火炬之光的植被是「簇状分布 + 大量实例」，UE 原生方案在移动端有两个瓶颈：每像素采样光照图，以及实例缓冲带宽。定制方案把它们拆成一组互相配合的宏：

  • XD_OPT_FOLIAGE_BAKE_LIGHTMAP_AND_SHADOWMAP_INTO_INSTANCE_BUFFER：把 LightMap/ShadowMap 采样结果按实例烘焙进 Instance Buffer，Shader 直接读取，不再逐像素采样（需静态 SkyLight、关闭 AO/虚拟纹理光照图，并依赖移动端关闭 Lightmap 方向性）。
  • XD_OPT_FOLIAGE_REPLACE_TRANSFORM_MATRIX_WITH_QUATERNION：实例变换用四元数 + 统一缩放替代 3×3 矩阵，实例缓冲带宽显著下降；代价是实例不支持非均匀缩放。
  • XD_OPT_FOLIAGE_DISABLE_PERINSTANCE_FUNCTIONS：按材质实际用到的表达式裁剪 PerInstance 参数（如未使用 FadeAmount 就不传）。
  • XD_OPT_FOLIAGE_SPLITING_INSTANCES_BY_MAX_INTERVAL：集群树改按「实例最大间隔」切分（原生按最小顶点数），契合簇状分布，减少视锥外实例提交。
  • XD_OPT_FOLIAGE_PER_FRAME_INSTANCE_BUFFER_RECONSTRUCTION：把相同 LOD 的集群节点重新打包成实例缓冲，RT 侧每帧重建。
  • XD_OPT_FOLIAGE_PER_INSTANCE_MOVEABLE_POINT_LIGHTING：只对与唯一可移动点光相关的实例计算光照。
  • XD_OPT_HISM_SPHERE_PROXY_MODE（默认 0）：HISM 球形代理剔除模式。
  • XD_BUG_FIX_REMOVE_BAD_INSTANCES、XD_BUG_FIX_DO_NOT_RENDER_UNBUILT_INSTANCES：剔除 NaN/零缩放实例、不渲染尚未构建缓冲的实例。

⚠ 植被三件套（切分/逐帧重建/逐实例点光）明确标注 Mobile(ES_31) Only；四元数方案与 DISABLE_PERINSTANCE_FUNCTIONS 有耦合。

2. 地形 Landscape

  • XD_LANDSCAPE_ADVANCE_PAINTING_TOOL：本项目对地形最大的改造——新增 Advanced Paint 绘制工具、UAdvancedLandscapeLayerInfo、通道分配器与 AdvancedChannelIDMap、ParameterLUT 布局、AdvancedTextureArray 材质节点；运行时提供 SetAdvancedAlphaData/GetAdvancedAlphaData/FillAdvancedLayer/ClearAdvancedLayer 等 API（78 处引用）。
  • XD_RENDERING_LANDSCAPE_LOD_BIAS：新增 r.LandscapeLODBias（移动端/ES3.1），按画质档位调整地形 LOD。
  • XD_OPT_MOBILE_LANDSCAPE_NO_LOD_MORPH：r.Mobile.DisableLandscapeLODMorph 关闭地形 LOD 形变（省 VS 计算，但会产生 LOD 跳变）。
  • XD_OPT_MOBILE_LANDSCAPE_POINT_LIGHTING（默认 0）：VS 预输出可见点光属性、PS 丢弃无用计算。
  • XD_BUG_FIX_GENERATE_LANDSCAPE_MOBILE_DATA_WHEN_SAVING：保存时生成 MobileData，避免重 Cook 后产生无谓热更（UE4-3547）。
  • XD_TORCHLIGHT_LANDSCAPE_GENERATE_MID_BY_DEFAULT（默认 0）：地形默认生成动态材质实例。

3. 世界、多世界（MultiWorld）与 FeatureLevel

  • XD_RENDERING_MULTIWORLD_BACKGROUND_TICK_COMPATIBILITY：为「后台子世界」打标（MarkSubWorld/IsSubWorld），在没有实际渲染时修正组件 Tick 与可见性逻辑。
  • XD_BUG_FIX_ADAPT_TEXTURE_STREAMING_TO_MULTI_WORLD_PLUGIN：纹理流送感知 ActiveWorld，可暂停非活跃关卡的流送（r.Streaming.PauseStreamingInInactiveLevels）。
  • XD_BUG_FIX_GET_CURRENT_WORLD_TIME_FOR_TEXTURE_STREAMING：流送改用「可 Tick 的世界」的时间，修复后台世界暂停导致的流送错乱（UE4-4169）。
  • XD_BUG_FIX_USE_CORRSPONDING_WORLD_FEATURE_LEVEL_IN_EDITOR、XD_BUG_FIX_THE_CRASH_WHEN_SWITCHING_FEATURE_LEVEL_WITH_MULTIPLE_UWORLDS、XD_BUG_FIX_REMOVE_CACHED_LEVEL_COLLECTION_IF_NOT_CONSISTENT_WITH_ACTIVE_LEVEL_COLLECTION：编辑器专用 FeatureLevel、多 UWorld 切 FL 崩溃防护、LevelCollection 缓存一致性（UE4-6191/3863）。
  • XD_OPT_DISABLE_NON_USABLE_WORLD_TICK_WORKS：空 LevelCollection 直接跳过 Tick。
  • XD_FIX_BUG_ZERO_MATRIX_CAUSE_CRASH_WHEN_COCOLLECT_DYNAMIC_MESH：零矩阵实例直接跳过收集，避免崩溃（TORCHLIGHT-115990）。
  • XD_TORCHLIGHT_TASK_GRAPH_EXT：ParallelFor/LevelTick 的任务图扩展，供项目并行任务使用。

4. 纹理流送细节优化

  • XD_BUG_FIX_CONSIDERING_FOV_FOR_TEXTURE_STREAMING：计算 ScreenSize 时考虑 FOV，并修正半径计算误差（UE4-3640）。
  • XD_BUG_FIX_DROP_MIPS_IF_MOVES_LONG_DISTANCE_SINCE_LAST_STREAMING：短时间远距离移动（传送/切图）时释放 CachedMips/HiddenMips，避免显存被历史 Mip 占住（UE4-3669）。
  • XD_MISC_MOBILE_USE_MIN_LOD_SIMULATE_LOD_BIAS：GLES 用 GL_TEXTURE_MIN_LOD 模拟 LOD Bias。
  • XD_BUG_FIX_RUNTIME_TEXTURE_LODBIAS：恢复按设备档位（IOS_Mid/Android_Low 等）设置运行时 LODBias 的能力。

5. 动画、骨骼网格与 LOD

  • XD_EXT_ANIMATION_TICK_OPTION_WITH_DISPLACEMENT：动画资产标记 bHasDisplacement，据此决定可见性 Tick 策略（配合 AnimMontage）。
  • XD_EXT_INVALID_LODSTATUS_UPDATE：不在渲染时（不可见）不再调用 UpdateLODStatus，省 CPU。
  • XD_EXT_RIGID_BODY_ANIMATION_NODE_SUPPORT_DEFAULT_SETTING_BODIES：刚体动画节点支持 Default 属性的 Body（原先只有 Kinematic/Simulated）。
  • XD_OPT_SKELETAL_MESH_SKIP_CREATE_UNIFORM_BUFFER_EVERY_FRAME：骨骼 UBO 不再每帧创建（性能 + 内存泄漏修复）。
  • XD_OPTIMIZATION_SHADOWS_FORCE_LOD（默认 0）：阴影 Pass 使用更低 LOD 的骨骼网格。
  • XD_MISC_ZERO_DEFAULT_BLEND_TIME：AnimMontage 默认混合时间改为 0。
  • XD_MISC_SKELETAL_MESH_COMPONENT_ADD_DELEGATES：组件 Begin/EndPlay、激活/失活新增委托。
  • XD_OPT_ASYNC_TICK_SKELETAL_MESH_COMPONENTS（默认 0）：并行 Tick 骨骼网格组件（需配合若干 CVar AnyThread 改造）。
  • XD_TOOL_SKELETAL_MESH_GET_GUID_FROM_FILEHASH、XD_SKELMESH_IMPORT_DEFAULT_SETTING、XD_SKELMESH_CHECK_DDC_KEY_MISS_MATCH_TOOL：骨骼网格资产标识、导入默认值与 DDC 一致性工具。

6. Sequencer 与过场动画

  • XD_OPTIMIZE_SEQUENCE_SUPPORT_PREVIEWSCENE_ASSET：序列支持 PreviewScene 资产（不进入关卡即可预览）。
  • XD_BUG_FIX_SEQUENCE_NOT_TICK_IGNORE_PAUSED：游戏暂停时 LevelSequence 仍可 Tick（bTickWhenPause 生效）。
  • 编辑器修复组：XD_BUG_FIX_ADD_ARRAY_ELEMENT_TO_SEQUENCER_TRACK、XD_BUG_FIX_WRONG_EXISTING_CAMERA_BINGDING_SPACE、XD_BUG_FIX_ADD_TARRAY_ELEMENT_FAILED_IN_DETAIL_PANEL、XD_BUG_FIX_ADD_SPAWNABLE_TO_TARRAY_NOT_SYNC_IN_SEQUENCER、XD_BUG_FIX_RECORD_SEQUENCER_CRASH、XD_BUG_FIX_SEQUENCER_KEYFRAME_DUPLICATE_NO_UPDATE_ON_DRAW。
  • XD_BUG_FIX_RESTORE_ASPECT_RATIO_CONSTRAINT：修复相机纵横比约束恢复（UE4-4328）。

7. 网格/材质资产链路

  • XD_RENDERING_FORCE_STATIC_MESH_SHARE_LIGHT_MAP：强制所有 LOD 共享 LOD0 的 Lightmap，显著减少光照图体积。
  • XD_TOOL_SUPPORT_NO_BAKED_LIGHTMAP_DIRECTIONALITY_GLOBALLY_MOBILE：移动端全局关闭 Lightmap 方向性，贴图体积减半（CVar r.DisableBakedLightMapDirectonality）。
  • XD_TORCHLIGHT_IMPORTSCENECONVERT_FORCEFRONTXAXIS：FBX 导入统一以 +X 为正面朝向。
  • XD_TORCHLIGHT_PHYSICSANIM_ADJUST：物理动画只混合旋转/缩放，保持骨骼位置稳定。
  • XD_TOOL_SOLVE_UNMATCHED_OVERRIDDEN_MAT_WITH_STATIC_MESH_MATERIALS、XD_EXT_ALLOW_USE_ORIGIN_PROXY_MATERIAL、XD_SERIALIZE_UPGRADE_FIXUP_STATIC_MESH_NONUSED_PROPERTY、XD_MISC_MAP_CHECK_ADJUST_STATIC_MESH_ACTOR_SAME_POSITION_METHOD：覆写材质对齐、Proxy 材质、序列化升级与 MapCheck 工具链。

8. 注意事项

  • 命名陷阱：零矩阵崩溃宏实际为 XD_FIX_BUG_ZERO_MATRIX_CAUSE_CRASH_WHEN_COCOLLECT_DYNAMIC_MESH（FIX_BUG 而非 BUG_FIX）。
  • 仅声明未使用：XD_EXT_ANIMATION_TICK_OPTION 在全源码中无 C++ 引用，是 _WITH_DISPLACEMENT 的遗留前缀。
  • 默认关闭：球形代理剔除、异步骨骼 Tick、阴影强制 LOD、Socket 警告关闭等均为 0。
  • Shader 联动：四元数实例、地形 LOD Bias、逐实例光照等改动会改变 Shader，修改后必须清理 DDC 重新编译。
