🎮 输入与手柄

键鼠、手柄、触控与模拟器输入路由

一句话概括：手游输入的三条链路——触控（含 IME 文本输入）、手柄（Android/iOS/模拟器）、模拟器键鼠——都做了针对性的修复与扩展，重点解决「坐标不对、连接崩溃、按键重复、识别错误」。

1. 触控与鼠标坐标

  • XD_MISC_GET_RAW_TOUCH_POSITIONS：新增 OnRawTouchStarted/Moved/Ended 与原始触点坐标接口，贯穿 RenderingCommon.h → SWidget → SViewport → PlayerInput → PlayerController；用于需要「屏幕真实坐标」而非 UI 变换后坐标的场景（UE4-4557）。
  • XD_FIX_BUG_ADD_REALTIME_MODE_FOR_GET_MOUSE_POS：为获取鼠标位置增加实时模式，避免使用上一帧缓存坐标（UE4-5614）。
  • XD_FIX_BUG_EMULATOR_GET_WRONG_MOUSE_POS：修复模拟器下 getMousePosition() 坐标错误（UE4-5857）。
  • XD_MISC_WIDGET_IGNORE_GESTURE_LONG_PRESS_EVENT：控件忽略长按手势事件，避免交互中意外丢失焦点（有运行时 CVar）。

2. 文本输入与输入法（IME）

  • XD_BUG_FIX_IOS_TEXT_INPUT_CRASH：修复 iOS 中文输入法组字导致文本框崩溃。
  • XD_BUG_FIX_TEXTFIELD_OPEN_FAILS_WHEN_SECOND_OPEN：修复 iOS 12.3.1 输入框第二次打开失败。
  • XD_BUG_FIX_SOME_IME_POP_UP_WITH_WRONG_POS：修复搜狗等输入法候选框不跟随输入框位置的问题（Windows TextStoreACP / 输入法系统）。

3. 手柄（Controller）

  • iOS：XD_FIX_IOS_CONTROLLER_CONCURRENT_CONNECT_CRASH（连接/断开并发崩溃）、XD_FIX_BUG_IOS_GAMEPAD_INVALID_PTR（空指针）、XD_BUG_FIX_IOS_CONTROLLER_CONNECTION_LOG_DUMP（连接日志）、XD_FIX_BUG_IOS_CONTROLLER_MENUE_KEY_RESPONSE_TWICE（Menu 键响应两次）。
  • Android：XD_FIX_BUG_ANDROID_GAMEPAD_INVALID_PTR（实现在 Java 模板 GameActivity.java.template）、XD_MISC_STRICT_DS_CONTROLLER_SELECT（按 VID/PID 严格识别 DualShock/DualSense，避免被误判为其他设备）、XD_FIX_BUG_FILTER_OUT_MOBILE_SIMULATOR_VIRTUAL_CONTROLLER（过滤移动模拟器按 ESC 时误报的虚拟手柄）。
  • 底层接口：IPlatformInputDeviceMapper/FGenericApplicationMessageHandler 相关改动在 ApplicationCore，如需扩展新设备建议走同一入口。

4. 模拟器输入（键鼠 + 手柄）

  • XD_EXT_EMULATOR_MOUSE_KEYBOARD_CONTROLLER_SUPPORT：模拟器支持鼠标/键盘/手柄操作游戏，覆盖 AndroidInputInterface、Launch、ApplicationCore、WebBrowser 等；调试日志宏 ..._DEBUG（默认 0）用于验证输入路由。
  • XD_EXT_EMULATOR_GAMEPAD_CONTROLLER_SUPPORT：模拟器手柄支持（含调试宏）。
  • XD_MISC_ANDROID_EMULATOR_USE_NATIVE_RESOLUTION、XD_RENDERING_EMULATOR_CONTROL_MOUSE_ICON_VISIBILITY：模拟器分辨率与鼠标光标显隐。

5. 与输入相关的平台/UI 行为

  • XD_TORCHLIGHT_FOCUS_TO_GAMEVIEWPORT_ON_COMMIT：文本提交后把焦点交还 GameViewport（ClearKeyboardFocus 会禁用全部键盘事件）。
  • XD_MISC_GET_RAW_TOUCH_POSITIONS 与安全区（XD_EXT_SLATE_SYMMETRIC_SAFE_ZONE、XD_EXT_OVERRIDE_SAFE_ZONE）配合使用，可解决刘海屏下的点击偏移。
  • XD_BUG_FIX_ANDROID_WAIT_FOR_SAFE_ZONE_WAS_UPDATED_BEFORE_CHANGING_ORIENTATION：切横竖屏前等待 Java 更新安全区，避免输入/UI 错位（UE4-4975）。

6. 注意事项

  • Android 手柄的空指针修复在 Java 模板（GameActivity.java.template），只查 C++ 会漏。
  • 模拟器输入支持会改变移动端输入栈的行为，正式机型不受影响，但相关宏不建议随意关闭——QA 全靠它。
  • 多数输入修复同时暴露 CVar，线上可通过配置回退验证。
