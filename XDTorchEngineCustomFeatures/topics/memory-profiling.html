📊 内存与性能分析

LLM、内存分配器、性能埋点与诊断

一句话概括：以 LLM（Low Level Memory Tracker）为核心搭建可落地的内存分析体系，同时补上分配器（Mimalloc）、低内存降级、显存与粒子的可观测性，并用一系列「去掉无用加载」的修复降低常驻内存。

1. LLM 内存统计体系

UE4 自带 LLM 只能看总量与粗粒度分类，项目需要「按资产、按子系统、按峰值时刻」定位问题，于是做了成组的扩展：

  • XD_OPT_LLM_CSV_EXTENSIONS：支持按资产输出独立 CSV，并支持 PublishCsvNow / 命令 LLMCSVNow 立即落盘——抓内存尖峰时不必等正常周期。
  • XD_OPT_LLM_TRACK_GLBOAL_PEAK_MEMORY：记录全局分配峰值（配合 FCoreDelegates 与 Editor 调用），定位“峰值出现在哪一步”。
  • XD_OPT_LLMTAG_EXTENSIONS + XD_MISC_ADD_MORE_LLM_TAGS_FOR_ENGINE：新增线程运行、粒子快池、Platform/Project 等标签区间，让火焰图/表格能细分到项目关心的模块。
  • XD_OPT_ANALYSIS_ANDROID/IOS/WIN_PLATFORM_UNTRACKED_MEMORY：三平台「未跟踪内存」分析，把 LLM 没覆盖到的原生分配暴露出来。
  • XD_MISC_LLM_GET_SMAPS_MEM：Android 读取 /proc/self/smaps 补充 PSS（原实现基于 status 不准），新增 SmapsPss 标签。
  • XD_MISC_IOS_SAVE_MEMREPORT_AND_LLMCSV_IN_PUBLIC_PATH：iOS 上把 MemReport/LLM CSV 写到 NSDocumentDirectory，方便测试同学直接取文件。
  • XD_MISC_PSO_PRECOMPILE_LLM_TAG：PSO 预编译内存单独打 PSOU 标签，与运行时 PSO 内存分开统计（TORCHLIGHT-251367）。
  • XD_TOOL_LLM_COMMAND_CSV_IMMEDIATE / XD_TOOL_LLM_UOBJECT_BREAKDOWN：命令即时输出、UObject 内存细分（后者默认关闭）。
  • XD_MISC_COLLECT_PARTICLE_MEM_FROM_STAT + XD_MISC_MEMREPORT_TIMER：从 STAT 提取粒子内存，并支持定时异步生成 MemReport（两者默认 0，且后者依赖前者）。
  • XD_MISC_COLLECT_LUA_MEM：Lua 内存采集项，供 MemReport 展示（引擎内未检索到消费点，由项目 Lua 层实现）。

2. 分配器

  • XD_OPT_UE5_4_WINDOWS_MIMALLOC：Windows 引入 UE5.4 的 Mimalloc 2.0 分配器（Core.Build.cs 链入，Win64 默认使用），改善大量小对象分配的性能与碎片（UE4-6600）。
  • XD_MISC_STOMP_MALLOC_SUPPORT_MORE_OPTIONS：Stomp 分配器支持 -stompunderrun 控制越界检测模式，便于精确定位越界写。
  • XD_MISC_TURN_OFF_IOS_GLOBAL_NEW_DELETE_OPERATOR：关闭 iOS 全局 new/delete 重载（当前代码为关闭状态）。
  • XD_TOOL_MEMORY_DEBUG_FORCE_ANSIC_MALLOC（默认 0）：强制 ANSI C malloc，配合 Perfetto 抓内存分配火焰图。
  • XD_TMP_FIX_MALLOC_ZERO_ISSUE：规避 0 字节分配的临时修复。
  • XD_BUG_FIX_IOS_MALLOC_BINNED_NANO_MEMORY_CORRUPTION：iOS MallocBinned nano 区域重分配越界修复（同步官方提交）。

3. 低内存与内存回收

  • XD_EXT_ADD_ON_LOW_MEMORY_DELEGATE：暴露低内存事件委托，项目可据此卸载资源、降画质。
  • XD_BUG_FIX_CODE_REFERENCED_ASSETS：修复引擎代码直接引用资源对象导致「没用到的资源也被加载」。
  • XD_BUG_FIX_ITERATE_CHECK_MATERIAL_LOAD：修复材质 PostLoad 泄漏。
  • XD_FIX_BUG_REMOVE_NONUSED_CHECK_IN_FREE_OBJECTS：移除 UObject 释放流程中无用的检查（UE4-5333）。
  • XD_BUG_FIX_GC_SYNCOBJ / XD_BUG_FIX_MORE_LOG_4_GC_TIMEOUT_CRASH：GC 卡死/超时崩溃的修复与日志（移动端 GC 超时是高频崩溃之一）。
  • XD_OPT_MEMORY_LIGHT_PRIMITIVE_INTERACTION_ALLOC：优化 STAT_LightInteractionMemory（光源-图元交互分配）占用。
  • XD_TORCHLIGHT_RELEASE_INSTANCEDECORATORS_IN_URICHTEXTBLOCK、XD_OPTIMIZATION_RELEASE_UserWidgetHolder_REFERENCE：主动释放 UI 相关引用，降低 UI 内存。

4. 性能与显存可观测性

  • XD_PC_RECORD_D3D11_RENDERING_RESOURCE_ALLOCATION：记录 D3D11 资源分配并可导出，定位显存超标（UE4-4264/4271）。
  • XD_TOOL_STAT_GL_PROGRAM_MEM_SIZE：GL Program 显存统计。
  • XD_TOOL_EXT_GPU_TIME_PROFILE（默认 0）：增加 GPU 阶段耗时采样。
  • XD_MISC_ADD_MORE_SCOPE_MARKER_IN_LOOP：主循环增加 Scope Marker，配合 UnrealInsights 看帧内分布。
  • XD_OPTIMIZATION_WWISE_PERF_GC_ISSUE：Wwise 音频 GC 性能问题优化（UE4-1473；Wwise 为插件模块，本树内无消费点）。
  • XD_DEBUG_PARTICLE_MEM_ERROR / XD_MISC_DEBUG_PARTICLE_PERF：粒子内存越界与性能埋点。

5. 常用命令与流程

命令 / CVar用途
LLMCSVNow立即输出 LLM CSV（配合分资产 CSV 抓尖峰）
memreport生成 MemReport（可被 XD_MISC_MEMREPORT_TIMER 定时触发）
XD.Engine.DumpRecordedD3D11VRAMAllocation导出 D3D11 资源分配记录
r.LLMGetSmapsMemAndroid 读取 smaps 补充内存数据
-stompunderrunStomp 分配器越界检测模式

6. 注意事项

  • 大部分 LLM 宏受 !UE_BUILD_SHIPPING 限制，Shipping 包默认不启用，需要专门的内存测试包。
  • XD_MISC_MEMREPORT_TIMER 依赖 XD_MISC_COLLECT_PARTICLE_MEM_FROM_STAT，UBT 会在依赖不满足时直接报错。
  • Mimalloc 替换了默认分配器，若项目有依赖 GMalloc 行为的代码需回归验证；排查内存问题时可用 XD_TOOL_MEMORY_DEBUG_FORCE_ANSIC_MALLOC 切回 ANSI。
