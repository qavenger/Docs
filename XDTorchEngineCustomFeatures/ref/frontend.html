引擎侵入等级

L0 无需侵入不改引擎源码
L1 仅加接入点Delegate / Interface / CVar 等扩展点
L2 结构性改动枚举 slot / 新 Pass / schema 字段
L3 深度侵入核心结构/生命周期/序列化，慎入

迁移处置

移植代码保留，适配后移植
