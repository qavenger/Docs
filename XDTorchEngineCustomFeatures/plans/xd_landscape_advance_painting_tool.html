修改草案 · XD_LANDSCAPE_ADVANCE_PAINTING_TOOL

Landscape 高级绘制：引入 IdMap 支持多图层材质与渲染

未覆盖 保留引擎 引擎内实现 深度侵入 工作量 L风险 高开发者 Que XiuChen主要模块 Landscape

一句话结论：深度侵入，含 Shader 与序列化，须整体移植并清 DDC

背景：新增地形 Id 贴图通道与编辑器绘制工具（78 处引用），支持更丰富的地表分层与特效混合。

0. 根因溯源（这个宏为什么存在）

XD 定制需求（非上游缺陷）

结论：宏开启使 Landscape 走 AdvancedPaint：ULandscapeComponent 增 AdvancedChannelSharing/AdvancedChannelIDMap(LandscapeComponent.h:545-590)，ULandscapeEditInterface 增 Set/Get/ClearAdvanced*Data(LandscapeEdit.h:249-272)，渲染侧加 NumStripesOverride/AdvancedLayerUsage，并新增 AdvancedPaint 目录、5 个材质节点与 AdvancedPaintCopyTexture.usf。

上游引入：XD 自研(Que Xiuchen 等)；XDBuildToolsConfiguration.cs:185。UE4 源树 79 文件、1179 处引用。

上游历史（是否修过）：未能确认上游等价实现；UE5 无 AdvancedPaint 目录，HEAD 5.8.2 无该宏。

为什么可以断定不是「故意为之」3 条依据
  • 有完整设计文档注释(AdvancedPaintTypes.h 的 Layout v2/通道分配规则)
  • 双语诊断 helper 与 4KB 缓冲属刻意工程化
  • 5 个专用材质节点 + usf 说明是产品级特性

调用方契约：编辑器绘制与渲染/材质采样须 channel/ID 一致；序列化字段需与旧关卡兼容。

内层真实语义：通道由 AdvancedChannelAllocator/Layout 分配，LUT 与 Texels 1:1；IDMap 不一致静默画错层。

代码库惯例：UE 原生用 WeightmapTextures+LODGroup；AdvancedPaint 在其旁扩展。

为何长期未被发现：仅启用该工具的地形资产走此路径，表现为层权重错位。

XD 侧的做法与意图：支持更多地形层/ID 通道与 texture array 采样。

只复制 .cpp/.h 而漏 AdvancedPaintCopyTexture.usf 与 Landscape.Build.cs:27 依赖，会致材质节点编译失败/UHT 缺失；新增 UPROPERTY 无版本守卫会让旧关卡加载错位。

迁移方案（按根因定）

整目录移植 Landscape/{Public,Private,Classes}/AdvancedPaint 与 Materials 节点、shader，按 UE5 结构重落点；移植期保留宏，稳定后移除，并全量重 cook+清 DDC。

根因级自检用例

  • 旧关卡(未开特性)加载不崩、权重正确
  • 开特性绘制/擦除/烘焙 round-trip 一致
  • 5 个材质节点编译且采样正确
  • 三平台 shader 编译

2. 修改步骤（暂留引擎）

  1. 登记 Feature Card
    记录 owner、影响面、依赖、关闭条件、验证方式与回滚方式；这是当前最高风险的一类（引擎内深度改动）。
  2. 评估替代路径
    优先考虑改用 UE5 原生机制（如 Niagara / Substrate / PSOPrecache / WorldPartition）替代自研实现；替代前保留最小可用补丁。
  3. 设定复查条件
    每个版本复查一次：是否可以降级为插件/配置，或直接删除。
  4. Shader 侧配套
    删除 DerivedDataCache 重编 Shader；同步更新受影响的 shader permutation / ShaderVersion。

风险评估

原代码风险：直接改 WrittenWeightmapTextures 之外的 IdMap 通道并驱动材质采样，任何 channel/ID 不一致会静默画错层，且新序列化字段带版本兼容问题。

移植风险：影响 Landscape 模块 210 文件、材质节点与 shader 编译；迁移后旧关卡 Asset 加载、DDC、cook 数据都可能不匹配。

开发自检

  • 编辑器多图层绘制→保存→重开数值一致
  • DDC 清空后 shader 全量编译通过
  • cook 后 IDMap 运行时采样正确(>4 层共享 channel)
  • 旧 Landscape 资产加载不报版本错

结论置信度：medium — AdvancedPaint 私有头/实现对 UE4 ULandscapeComponent 序列化布局依赖深，UE5 需逐文件核对后才知是否只能重写。
