半透明 Pass 支持按 MeshBatch 设置额外渲染顺序（目前主要移动端）

未覆盖 移植 引擎内实现 结构性改动 工作量 M风险 中开发者 Gong Bai Liang主要模块 Engine

一句话结论：半透明按 MeshBatch 额外优先级，UE5 仅支持逐 primitive 排序

背景：UE 原生半透明顺序由距离/材质决定，此功能允许材质/组件/粒子指定优先级，用于 UI 型特效、贴花等必须固定层次的效果。

1. UE5 现状与证据

结论依据：UE5 MeshBatch.h 无排序优先级字段；仅 PrimitiveSceneProxy.h:755/1334 逐 primitive TranslucencySortPriority

覆盖说明：UE5 仅逐 primitive 排序，无逐 MeshBatch

证据路径（UE5.8.2）行号核对结果
MeshBatch.h—✅ 已命中：Source/Runtime/Engine/Public/MeshBatch.h
PrimitiveSceneProxy.h755✅ 已命中：Source/Runtime/Engine/Public/PrimitiveSceneProxy.h

覆盖度：未覆盖  处置：移植

3. 代码级实现（开发用）

独立 Agent 审核并修正修正 1 处　提出问题 2 条

审核意见：方向正确（port-as-is：UE5 的 FMeshBatch 与 CalculateTranslucentMeshStaticSortKey 均在），但 after 不能照搬 UE4 的位域宽度，需先核实 UE5 布局可压缩空间；移动端与 PC 两条排序路径都要同步回归。

简单移植 改动方式：UE5 同名类/函数（FMeshBatch、CalculateTranslucentMeshStaticSortKey、FMeshDrawCommandSortKey::Translucent）仍在且签名一致。

代码脉络：FMeshBatch 加 SetPerBatchTranslucentPriority（UE4 MeshBatch.h:256）与 ETranslucencyBlendLayer（Scene.h:102），特效侧经 ParticleHelper.h:1504、ParticleEmitter.h:280、SkeletalMesh.cpp:5508 写入；MeshPassProcessor.h:1114 重排 Translucent sort key，BasePassRendering.cpp:614 ApplyPerBatchTranslucentSortKey 受 CVar r.xd.EnableTranslucentPriorityOverride 控制，由 BasePassRendering.cpp:1738、MobileBasePass.cpp:1122 调用。

步骤 1Runtime/Engine/Public/MeshBatch.hMeshBatch.h:431-438（bOverlayMaterial 之后）

补 3 个优先级字段与 setter，并把 ETranslucencyBlendLayer 搬到 UE5（Scene.h 已无 UE4 插入点，放 MeshBatch.h:95 附近）。

uint64 Distance : 32;
uint64 Priority : 16;   // UE5:1553-1555

    uint64 Distance          : 32;
    uint64 Priority          : 16; // UE5 为 16（UE4 是 8）

// XD 需要额外的 per-batch 优先级时：先在 BasePassRendering.cpp:309
// CalculateTranslucentMeshStaticSortKey 里确认可占据的高位，再决定是否压缩 MeshIdInPrimitive/Distance，
// 并在 MobileBasePass.cpp:930 同步（移动端另有 SHRT 路径）。

⚠ 漏改任一处 clamp 会静默截断或越界，Priority 语义也随之变窄。

风险评估

原代码风险：位域收窄把 TranslateSortPriority 从 16bit 压到 8bit，越界值依赖调用点 clamp，无运行时校验。

移植风险：改的是全局半透明排序键，移动端与 PC、粒子/骨骼/植被四条写入路径都要回归；漏改 clamp 会静默错序。

开发自检

  • r.xd.EnableTranslucentPriorityOverride=0/1 对比半透明层次
  • 移动端与 SM5 半透明特效/植被顺序
  • 粒子 EmitterLayer 覆盖与 SecondPerBatch 优先级

结论置信度：medium — ETranslucencyBlendLayer 在 UE5 放 MeshBatch.h 还是新建头文件需定；SCHAR 下限改动的兼容性需人工确认。
