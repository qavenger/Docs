修改草案 · XD_OPT_FOLIAGE_DISABLE_PERINSTANCE_FUNCTIONS

按材质表达式使用情况裁剪植被 PerInstance 参数（只保留用到的）

待确认 移植 需接入点 结构性改动 工作量 M风险 高开发者 Lu Xun主要模块 Engine

一句话结论：影响 shader permutation，改动后清 DDC

背景：例如材质没有用 PerInstanceFadeAmount，则不传该参数，节省实例缓冲带宽。

1. UE5 现状与证据

结论依据：UE5 未找到按材质表达式裁剪 per-instance 参数的等价逻辑（InstancedStaticMesh.cpp/StaticMeshResources.h）

覆盖说明：需在材质编译器复核

证据路径（UE5.8.2）行号核对结果
InstancedStaticMesh.cpp/StaticMeshResources.h—✅ 已命中：Source/Runtime/Engine/Public/StaticMeshResources.h

覆盖度：待确认  处置：移植

2. 修改步骤（移植）

  1. 定位 UE5 对应文件
    见下方「UE5 对应文件」；重点比对同文件在 UE4/UE5 的差异。
  2. 移植实现
    原实现位置：Source/Runtime/Engine/Private/InstancedStaticMesh.cpp、Source/Runtime/Engine/Private/Materials/HLSLMaterialTranslator.cpp、Source/Runtime/Engine/Private/Materials/HLSLMaterialTranslator.h、Source/Runtime/Engine/Public/StaticMeshResources.h、Source/Runtime/Landscape/Private/LandscapeGrass.cpp。如涉及 Shader，需同步改 shader define 或共享 include。
  3. 适配 UE5 接口与规范
    注意 C++20、UHT（反射）规则、bValidateCircularDependencies 默认开启等差异；必要时回归 DDC/Cook。
  4. Shader 侧配套
    删除 DerivedDataCache 重编 Shader；同步更新受影响的 shader permutation / ShaderVersion。

3. 代码级实现（开发用）

独立 Agent 审核通过

审核意见：核对通过：UE4 HLSLMaterialTranslator.cpp:1277-1296 的 XD_USES_PER_INSTANCE_* 与字段 bUsesPerInstanceFadeOutAmount 属实；UE5 :2304-2305 USES_PER_INSTANCE_CUSTOM_DATA/USES_PER_INSTANCE_FADE_AMOUNT、:2317 NEEDS_PER_INSTANCE_RANDOM_PS 逐行吻合，:253/14829 确认改名为 bUsesPerInstanceFadeAmount，LocalVertexFactoryCommon.ush:11/1

建议舍弃 改动方式：UE5 已内建等价的按需裁剪：NEEDS_PER_INSTANCE_PARAMS（LocalVertexFactoryCommon.ush:11）、LOCAL_VF_INTERPOLATE_PER_INSTANCE_RANDOM（:15）、USES_PER_INSTANCE_FADE_AMOUNT/USES_PER_INSTANCE_CUSTOM_DATA（HLSLMaterialTranslator.cpp:2304-2305,2317）。

代码脉络：值=1；UE4 在 HLSLMaterialTranslator 里定义 XD_USES_PER_INSTANCE_PARAMS/RANDOM/FADEOUTAMOUNT（HLSLMaterialTranslator.cpp:1277-1292，标志位 .h:290-293），shader 据此只声明被用到的 per-instance varying（LocalVertexFactoryCommon.ush:16-26、MaterialTemplate.ush:324-333）。

步骤 1Runtime/Engine/Private/Materials/HLSLMaterialTranslator.cppHLSLMaterialTranslator.cpp:2304-2305 与 2317

不迁移 XD define，直接用 UE5 原生按材质使用情况裁剪的 define（可执行语句即保留下列行）

#if XD_OPT_FOLIAGE_DISABLE_PERINSTANCE_FUNCTIONS
    OutEnvironment.SetDefine(TEXT("XD_USES_PER_INSTANCE_PARAMS"), 0);
    OutEnvironment.SetDefine(TEXT("XD_USES_PER_INSTANCE_RANDOM"), bUsesPerInstanceRandom && Material->IsUsedWithInstancedStaticMeshes());
#endif
OutEnvironment.SetDefine(TEXT("USES_PER_INSTANCE_CUSTOM_DATA"), EnvironmentDefines->bUsesPerInstanceCustomData);
OutEnvironment.SetDefine(TEXT("USES_PER_INSTANCE_FADE_AMOUNT"), EnvironmentDefines->bUsesPerInstanceFadeAmount);
OutEnvironment.SetDefine(TEXT("NEEDS_PER_INSTANCE_RANDOM_PS"), EnvironmentDefines->bUsesPerInstanceRandomPS);

⚠ UE4 的 bUsesPerInstanceFadeOutAmount 字段在 UE5 已改名 bUsesPerInstanceFadeAmount（:253、14829），不要照抄旧名。

步骤 2Runtime/Engine/Public/StaticMeshResources.hStaticMeshResources.h:1191 FStaticMeshInstanceData::SetInstance

如仍要省实例缓冲里的 RandomID 字节，需单独改 SetInstance 与 GetInstanceRandom；不建议随本宏迁移

#if XD_OPT_FOLIAGE_DISABLE_PERINSTANCE_FUNCTIONS
    float UniformScale = Origin.W;
#else
    float UniformScale = 1.0f;
#endif
	inline void SetInstance(int32 InstanceIndex, const FMatrix44f& Transform, float RandomInstanceID, const FVector2D& LightmapUVBias, const FVector2D& ShadowmapUVBias) // UE5 原样

⚠ 残余收益仅在缓冲字节数，需要改 FStaticMeshInstanceData 布局 + LocalVertexFactory.ush:657 GetInstanceRandom，属独立优化项，非本宏必须。

风险评估

⚠ 与早期迁移处置结论存在分歧：早期结论=要移植，代码级分析=建议舍弃。早期结论=移植，代码级分析=建议舍弃；建议以代码级分析为准并回写评估矩阵。

原代码风险：定义与 Shader 强绑定，若 define 与工程 shader 版本不一致会编译报“XD_USES_PER_INSTANCE_PARAMS should be 0 or undefined”（MaterialTemplate.ush:120-123）。

移植风险：不迁移零风险；强行移植会与 UE5 既有 NEEDS_PER_INSTANCE_PARAMS 体系冲突并改动 shader permutation（清 DDC）。

开发自检

  • 只用到 PerInstanceRandom 的植被材质不出现在 PS 阶段的额外 varying
  • 改动后所有植被材质 shader 编译通过、无 DDC 不一致报错

结论置信度：high — UE5 仍会把 RandomID 写入实例缓冲，故“完全不传该参数”的收益无法完全等价，需要人工确认是否接受。
