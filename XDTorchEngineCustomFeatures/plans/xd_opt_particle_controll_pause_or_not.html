修改草案 · XD_OPT_PARTICLE_CONTROLL_PAUSE_OR_NOT

扩展接口：允许游戏逻辑暂停/恢复粒子系统

部分覆盖 移植 需接入点 结构性改动 工作量 M风险 中开发者 Ran Qing Sen主要模块 Engine

一句话结论：优先用 UE5 CanSkipTickDueToVisibility 机制替代实例级暂停，避免模板 schema

可主动舍弃性（UE5 架构更替）

需在新体系重做 Cascade 粒子 → Niagara

判定依据：UE5 特效体系已全面转向 Niagara，Cascade 仅保留兼容维护；项目迁移到 UE5 后特效会重做，针对 Cascade 运行时的定制可在迁移时直接不带过去。

舍弃前提：前提：迁移后在 UE5 用 Niagara 重做特效（不再走 Cascade 运行时）

UE5 替代能力：Niagara（NiagaraSystem / NiagaraComponent / NiagaraDataInterface）

相关文件：Source/Runtime/Engine/Classes/Particles/ParticleSystem.h

3. 代码级实现（开发用）

独立 Agent 审核通过

审核意见：抽查全部通过：XDBuildOptConfiguration.cs:94；ParticleSystem.h:407-420（属性 :413、SetPauseWhenNoVisible :418、非 const 的 IsPauseWhenNoVisible :419）；消费方 Engine/Source/Runtime/CascadeParticleOptimizationStrategies/Private/XDParticleCullingOptimization.cpp:287-288（bDisableTick / SetForceComponentTickDisable）；UE5 Cla

简单移植 改动方式：UParticleSystem 类在 UE5 仍在且 IsLooping() 保留（ParticleSystem.h:589），属性可直接照搬。

代码脉络：宏在 XDBuildOptConfiguration.cs:94 定义为 1。生效点有两处：UParticleSystem 在 Classes/Particles/ParticleSystem.h:407-420 新增 UPROPERTY bool bPauseWhenNoVisible（AssetRegistrySearchable）及 Set/IsPauseWhenNoVisible 访问器；消费方是插件 Source/Runtime/CascadeParticleOptimizationStrategies/Private/XDParticleCullingOptimization.cpp:287，用 (Template->IsLooping()||Template->bThoughtAsLooping) && Template->IsPauseWhenNoVisible() && MinVisibleBoundingBoxIdx>0 得出 bDisableTick，再 PSC->SetForceComponentTickDisable。该逻辑依赖 extent 包围盒剔除结果（宏 13）。

步骤 2Runtime/CascadeParticleOptimizationStrategies/Private/XDParticleCullingOptimization.cppXDParticleCullingOptimization.cpp:287

消费侧改为接 UE5 的可见性跳过机制，避免自持裁剪结果

bool bDisableTick = (Template->IsLooping() || Template->bThoughtAsLooping) && Template->IsPauseWhenNoVisible() && (MinVisibleBoundingBoxIdx > 0);
PSC->SetForceComponentTickDisable(bDisableTick);
// 可选替代：UE5 ParticleSystemComponent.cpp:653 CanSkipTickDueToVisibility()
if (Template && Template->IsLooping() && CanConsiderInvisible() && !bWasDeactivated) return;

⚠ bThoughtAsLooping 属工具宏 XD_TOOL_PARTICLE_SYSTEM_ADD_THOUGHT_AS_LOOPING，需一并处理。

风险评估

原代码风险：UPROPERTY 直接写死在 UParticleSystem，资产序列化 1 byte 开关；IsPauseWhenNoVisible() 非 const，在 const 上下文需 const_cast。

移植风险：所有 ParticleSystem 资产需重存；若裁剪结果（宏 13）未同时移植，IsPauseWhenNoVisible 恒被忽略。

开发自检

  • 循环特效出视锥后 tick 被挂起、回屏恢复
  • 非法空 Template 下不崩

结论置信度：medium — 是否真按 UE5 CanSkipTickDueToVisibility 替代而非保留自定义裁剪，需与渲染同学确认。
