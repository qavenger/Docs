Slate/UMG TextBlock 支持垂直对齐（Vertical Justification）

未覆盖 移植 引擎内实现 结构性改动 工作量 L风险 中开发者 Han Shu Bin主要模块 Slate

一句话结论：引用最多的 UI 定制（37 处），必须整体移植；注意 UE5 文本布局/ShapedTextCache 已改。

背景：补齐 UE4 TextBlock 缺失的垂直对齐能力，编辑器中直接可用。

3. 代码级实现（开发用）

独立 Agent 审核并修正修正 2 处　提出问题 2 条

审核意见：thread 与 UE4 侧核实（TextLayout.h:49-72 枚举、TextLayout.cpp:485、SlateTextBlockLayout.cpp:43、TextWidgetTypes.h:81/99）；UE5 TextLayout.h:421-425 确有 SetJustification/GetVisualJustification，且 UE5 全仓 grep VerticalJustification 无结果，refactor 分类成立；修掉 anchor 与大小写笔误即可。

完全重构 改动方式：UE5 文本布局/STextBlock/InWidgetArgs 已改动，须按新结构重写整条链路

代码脉络：开启后 TextLayout.h:49-72 新增 ETextVerticalJustify 枚举，FTextLayout 增 VerticalJustification 属性，TextLayout.cpp:485-550 JustifyLayout 按 VisualVerticalJustification 调整行盒 Y；SlateTextBlockLayout.cpp:43-45 透传 InWidgetArgs.VerticalJustification，UMG 侧 TextWidgetTypes.h:81/99 暴露 SetVerticalJustification 与 UPROPERTY。UE5 全仓 grep VerticalJustification 无结果，未上游。

风险评估

原代码风险：改动贯穿 FTextLayout/多个 TextBlock 与可编辑文本，行高与自动滚动叠加易算错；影响所有文本渲染。

移植风险：UE5 文本布局与 ShapedTextCache 已改，接口签名不同，整体移植工作量大、回归面广（全部 UMG 文本）。

开发自检

  • Top/Center/Bottom 三种对齐在 STextBlock 与 UTextBlock 生效
  • 现有文本换行/行高/滚动无回归

结论置信度：medium — UE5 InWidgetArgs 与 JustifyLayout 内部 LineViews 结构差异需逐文件核对，工作量估计偏大
