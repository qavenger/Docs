3. 代码级实现（开发用）

独立 Agent 审核通过提出问题 1 条

审核意见：UE4 声明 UserWidget.h:1092-1098、实现 :801/:841、UE5 UserWidget.h:1426/:1524 与 WidgetTree.h:65/:78 均已核实，after 的压缩 lambda 与 UE4 原文语义一致（含先比自身 PsId、Result 短路、Cast 递归），可保留。

简单移植 改动方式：UE5 UUserWidget 仍有 WidgetTree(UserWidget.h:1524) 与 UWidgetTree::GetAllWidgets/ForEachWidget(WidgetTree.h:65/78)，两函数可整段搬。

代码脉络：宏给 UUserWidget 加 GetWidgetFromPsId（UserWidget.cpp:800，先比自身 PsId，再 WidgetTree->ForEachWidget 递归子控件）与 GetAllWidgets（:841，转发 WidgetTree->GetAllWidgets），声明在 UserWidget.h:1092-1098。

步骤 1Source/Runtime/UMG/Public/Blueprint/UserWidget.h:1426 GetWidgetFromName 之后

增加两个声明

UMG_API UWidget* GetWidgetFromName(const FName& Name) const;
#if XD_TORCHLIGHT_WIDGET_NEW_INTERFACE
	UMG_API UWidget* GetWidgetFromPsId(const FName& InPsId) const;
	UMG_API TArray<UWidget*> GetAllWidgets() const;
#endif

⚠ 与 ADD_PSID 同开关；UE5 声明处要带 UMG_API 导出宏

步骤 2Source/Runtime/UMG/Private/UserWidget.cpp:800 / :841

搬 GetWidgetFromPsId 与 GetAllWidgets 实现

UWidget* UUserWidget::GetWidgetFromName(const FName& Name) const
{
	return WidgetTree ? WidgetTree->FindWidget(Name) : nullptr;
}
#if XD_TORCHLIGHT_WIDGET_NEW_INTERFACE
UWidget* UUserWidget::GetWidgetFromPsId(const FName& InPsId) const {
	if (InPsId.IsNone()) return nullptr;
	if (PsId == InPsId) return const_cast<UUserWidget*>(this);
	if (!WidgetTree) return nullptr;
	UWidget* R = nullptr;
	WidgetTree->ForEachWidget([&](UWidget* W){ if(R||!W) return; if(W->PsId==InPsId){R=W;return;} if(const UUserWidget* U=Cast<UUserWidget>(W)) R=U->GetWidgetFromPsId(InPsId); });
	return R;
}
TArray<UWidget*> UUserWidget::GetAllWidgets() const { TArray<UWidget*> A; if(WidgetTree) WidgetTree->GetAllWidgets(A); return A; }
#endif

⚠ 依赖 ADD_PSID 的 UWidget::PsId；WidgetTree 为 TObjectPtr<UWidgetTree>，用前判空

风险评估

原代码风险：GetWidgetFromPsId 每次遍历整棵 WidgetTree，频繁调用为 O(N)。

移植风险：改 Runtime/UMG 公共类，需回归 UMG 编译与蓝图；依赖 PsId 字段，若 ADD_PSID 未迁则编译失败。

开发自检

  • 含新接口的 UUserWidget 派生类可编译
  • 按 PsId 查控件与批量取控件结果正确

结论置信度：medium — 是否必须放 UUserWidget 基类（否则可做项目子类+函数库）。
