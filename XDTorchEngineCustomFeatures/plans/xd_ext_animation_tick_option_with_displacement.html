修改草案 · XD_EXT_ANIMATION_TICK_OPTION_WITH_DISPLACEMENT

基于位移的动画可见性 Tick 优化（作用于 EVisibilityBasedAnimTickOption 与 AnimMontage）

部分覆盖 插件化 需接入点 结构性改动 工作量 M风险 中开发者 Gong Bai Liang主要模块 Engine

一句话结论：优先用 AnimationBudgetAllocator/SignificanceManager 替代

⚠ 原宏备注：该宏应恒为 1，仅用于正确设置并保存 bHasDisplacement 属性。

3. 代码级实现（开发用）

待独立 Agent 审核该草案尚未进入审核轮次：审核会打开 UE5 源码逐条核对行号、函数与 after 代码 引用的 API 是否存在。

简单移植 改动方式：AnimationAsset/AnimMontage 结构 UE5 未变，代码可照搬，仅需补 ENGINE_API。

代码脉络：UAnimationAsset 加持久化 bool bHasDisplacement(AnimationAsset.h:848,构造 AnimationAsset.cpp:184)，HasDisplacement()(:853)由 UAnimMontage::HasDisplacement(AnimMontage.cpp:801-822)汇总 SlotAnimTracks；:736 声明 override。SKM 的 OnMontage_BeginPlay/OnSetAnimation(SkinnedMeshComponent.cpp:819-828)为空实现，被 AnimInstance.cpp:1963 与 SkeletalMeshComponent.cpp:3473 调用。注释说明 tick 已退化，仅用于保存该属性。

步骤 1Runtime/Engine/Classes/Animation/AnimationAsset.hUE5 AnimationAsset.h:987(类)/1007(MetaData 后)

加 bHasDisplacement 与 HasDisplacement()

// XD_EXT_ANIMATION_TICK_OPTION_WITH_DISPLACEMENT -- Begin
protected:
  UPROPERTY(EditAnywhere, Category = Animation)
  bool bHasDisplacement;
public:
#if XD_EXT_ANIMATION_TICK_OPTION_WITH_DISPLACEMENT
  virtual bool HasDisplacement() const { return bHasDisplacement; }
#endif
protected:
  UPROPERTY(EditAnywhere, Category = Animation)
  bool bHasDisplacement = false;
public:
#if XD_EXT_ANIMATION_TICK_OPTION_WITH_DISPLACEMENT
  virtual bool HasDisplacement() const { return bHasDisplacement; }
#endif

⚠ 属性在 UE4 本就无条件，保持以便旧 uasset 反序列化；UE5 无 UAnimationAsset 构造，初值放声明。

步骤 2Runtime/Engine/Classes/Animation/AnimMontage.hUE5 AnimMontage.h:867(HasRootMotion 旁)

加 override 并在 .cpp 实现

#if XD_EXT_ANIMATION_TICK_OPTION_WITH_DISPLACEMENT
  virtual bool HasDisplacement() const override;
#endif
#if XD_EXT_ANIMATION_TICK_OPTION_WITH_DISPLACEMENT
  ENGINE_API virtual bool HasDisplacement() const override;
#endif

⚠ UE5 AnimMontage 为 MinimalAPI(AnimMontage.h:634)，须加 ENGINE_API，否则链接失败；cpp 实现照搬 AnimMontage.cpp:802-821。

风险评估

原代码风险：SKM 两个回调为空实现(死代码)，bHasDisplacement 仅编辑器打标。

移植风险：丢属性会丢旧资产位移标记(不崩但丢数据)；漏 ENGINE_API 链接失败。

开发自检

  • Montage 含位移段时 HasDisplacement()==true
  • 旧 AnimSeq/AnimMontage 加载后 bHasDisplacement 保留
  • 引擎导入库符号完整

结论置信度：medium — UE5 是否仍有逻辑消费 bHasDisplacement 需确认；若无消费可直接 abandon 并启用 AnimationBudgetAllocator。
