修改草案 · XD_MISC_DISABLE_UECHECK_FOR_AUDIO_ANIMNOTIFY

关闭音频 AnimNotify（WwiseAudio_EBP）的 UECheck 依赖校验

未覆盖 配置化 可工程化 仅加接入点 工作量 S风险 低开发者 （未署名）主要模块 仅定义（无引用）

一句话结论：改用配置排除，勿留引擎宏。

0. 根因溯源（这个宏为什么存在）

XD 定制需求（非上游缺陷）

结论：XD 的资产检查插件把'WwiseAudio_EBP 依赖缺失'报成 UE0201 噪音，插件里用 #if 读该宏跳过字符串匹配。宏本身由 UBT 反射注入（UEBuildTarget.cs:3839-3861），是 XD 构建配置问题而非上游缺陷。

上游引入：XD 自建。定义：XDBuildMiscConfiguration.cs:292-293（注释 'Disable Audio AnimNotify UECheck for dependencies, using string matching: WwiseAudio_EBP'）；使用：UE_game/Plugins/UEChecker/Source/UEChecker/Private/UECheckerDependency.cpp:288-293。

上游历史（是否修过）：引擎源码 0 引用（rg 仅命中 .cs:293 与插件）；UE5 无 XDBuild* 配置类，故迁移后该宏默认未定义。上游无关（UEChecker 是 XD 插件）。

为什么可以断定不是「故意为之」3 条依据
  • 这是 XD 插件自己的规则开关，上游不存在对应概念
  • 用 'Contains("WwiseAudio_EBP")' 字符串匹配（:289）而非配置/正则，属临时压制手段
  • 插件同目录 Settings/test_case_dependency.json:10 已有 ignoreFileRegexStrings 含该路径，说明作者本意是配置化，宏是补丁式实现

调用方契约：UECheckerDependency.cpp:288-293：宏=1 时仅当依赖路径不含 WwiseAudio_EBP 才 LogError；宏未定义(=0)时 #if 块被删掉，变为无条件 LogError（行为反转，重新刷 UE0201）。

内层真实语义：宏=0/未定义 → 该分支整体消失，只留下带花括号的 LogError，即'总是报错'；宏=1 → 依赖含 WwiseAudio_EBP 时静默跳过。

代码库惯例：插件惯例是把忽略规则写进 Settings/*.json 由 UECheckerBase.cpp:202 读取（TryGetStringArrayField(TEXT("ignoreFileRegexStrings"), ...)），而不是读编译期宏。

为何长期未被发现：宏=1 时压制生效、日志干净，团队以为规则已配置化；一旦换构建（UE5 不再注入该宏）噪音立刻回归，且改名音频包后匹配会静默失效。

XD 侧的做法与意图：目录 Settings/test_case_dependency.json:5-11 已把 /Game/WwiseAudio_EBP 列入 ignoreFileRegexStrings，作者想彻底不报该包相关的依赖缺失。

⚠ 步骤 2 提议的 'dependencyIgnoreRegexStrings' 键目前没有任何代码读取（全局 rg 无命中），写进 json 是死配置；另注意 ignoreFileRegexStrings 只过滤'被检查的文件'，不会过滤'依赖路径'，因此把依赖路径加到该数组（迁移副本 test_case_dependency.json:10/42 就是这么写的）不会抑制 UE0201。

迁移方案（按根因定）

不改引擎宏：把判断改为项目侧常量或插件配置，并在插件里实现真正的依赖级忽略（读取新键 dependencyIgnoreRegexStrings 或复用 checkPathRegexStrings 语义）。同时清理迁移副本 UECheckerDependency.cpp:288-290 的 #if，避免 UE5 下宏未定义导致行为反转。

根因级自检用例

  • UE5 构建（无 XD 宏注入）下 WwiseAudio_EBP 依赖缺失不再报 UE0201
  • 其他真实缺失依赖仍照常报 UE0201（排除规则不误放行）
  • 音频包改名后规则按配置正则生效，无需重编译引擎
  • 插件 json 中不再出现无人读取的配置键

风险评估

⚠ 与早期迁移处置结论存在分歧：早期结论=要移植，代码级分析=建议舍弃。早期结论=配置化，代码级分析=建议舍弃；建议以代码级分析为准并回写评估矩阵。

原代码风险：硬编码包名字符串，音频包改名后排除规则静默失效或误放过。

移植风险：UEChecker 属项目插件、不在引擎迁移范围，但若忘记删引擎宏会因未定义(=0)导致插件行为反转、重新刷 UE0201 噪声。
