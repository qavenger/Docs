修改草案 · XD_FORCE_SATATICMESH_LOD_STREAM_BULK

把静态网格 LOD 渲染数据拆入 ubulk 流式文件（默认关闭）

部分覆盖 配置化 需接入点 仅加接入点 工作量 S风险 中开发者 Yu Hang主要模块 Engine

一句话结论：建议把宏换成读 ini/CVar 的开关；默认关闭可直接删宏

⚠ 原宏备注：默认 0。开启可减小常驻内存，但增加 I/O；纹理/骨骼网格由 UE 自带 ini 控制。

0. 根因溯源（这个宏为什么存在）

XD 定制需求（非上游缺陷）

结论：UE4 IsLODCookedOut/IsLODInlined 依 LODGroup.IsLODStreamingSupported()；XD 用 CVar 覆盖并令 MaxNumStreamedLODs=MAX_MESH_LOD_COUNT，还把开关写进 BuildStaticMeshDerivedDataKeySuffix。UE5 提供 SetLODStreaming 每资产开关，5.6 起把 streaming 设置移出 DDC key。

上游引入：XD 自研；定义 XDBuildProjectFeaturesConfiguration.cs:50（现=0）。

上游历史（是否修过）：UE5 无同名宏；等价能力 StaticMesh.cpp:3565 GetEnableLODStreaming、:511/:537 IsLODCookedOut/Inlined；EStaticMeshLODStreaming 提交 c63b1a301425(2026-02-02, 5.8.0-preview-1)；DDC key 去 streaming 为 443e7884c17d(2025-01-27, 5.6.0-preview-1)。

为什么可以断定不是「故意为之」3 条依据
  • 宏名带 CVar 与 DEBUG，属显式可配特性
  • 刻意把 LS1/LS0 写入 DDC key 是知情的取舍
  • 默认 0，属候选优化

调用方契约：cook 与加载两侧一致；DC key 变化会全量静态网格 DDC 失效。

内层真实语义：宏开时 IsLODInlined 令 MaxNumStreamedLODs=MAX_MESH_LOD_COUNT 且返回 LODIdx>=InlinedLODStartIdx(UE4 StaticMesh.cpp:409-419)。

代码库惯例：UE 用 LODGroup ini([StaticMeshLODSettings] bSupportLODStreaming, StaticMesh.cpp:3287-3300) 与 per-asset LODStreaming。

为何长期未被发现：只影响 cook 产物与 I/O，编辑器不触发；LS 切换静默令 DDC 失效。

XD 侧的做法与意图：所有分组 LOD 都流式，降低常驻内存。

在 UE5 把 LODStreaming 塞进 DDC key 是反优化(443e7884c17d)；MaxNumStreamedLODs 过大在 bDiscardBulkData/可选 LOD 下行为不同。

迁移方案（按根因定）

删宏，改用 DefaultEngine.ini [StaticMeshLODSettings] 对各 LODGroup 配置 bSupportLODStreaming/MaxNumStreamedLODs，或对资产 SetLODStreaming(Enabled)；不要改 DDC key。

根因级自检用例

  • 目标资产 cook 后引用 optional pak
  • r.MeshStreaming=0 时回退内联
  • 切换设置 DDC 正确失效/复用
  • 首帧无 missing bulk 警告

风险评估

⚠ 与早期迁移处置结论存在分歧：早期结论=要移植，代码级分析=建议舍弃。早期结论=配置化，代码级分析=建议舍弃；建议以代码级分析为准并回写评估矩阵。

原代码风险：把全部 LOD 拆 ubulk 会显著增加 I/O 且改变 cook 产物；依赖一个非官方 CVar，且 KeySuffix 里写入 LS1/LS0 后任何开关翻转都会使全量静态网格 DDC 失效。

移植风险：改用 ini 后行为等价但需重跑 cook 与 DDC；MaxNumStreamedLODs 过大在 UE5 的 bDiscardBulkData/可选 LOD 逻辑下可能行为不同（StaticMesh.cpp:949-960）。

开发自检

  • 确认目标平台 SupportsFeature(MeshLODStreaming) 为 true 后，非 LOD0 数据进 .ubulk
  • LOD 切换/流送不闪丢，pak 内含 optional chunk
  • cook 后静态网格 DDC key 变化导致重跑一次

结论置信度：medium — UE5 是否仍按宏原意“所有 LOD 都流式”，以及 MaxNumStreamedLODs 上限语义，需实机验证。
