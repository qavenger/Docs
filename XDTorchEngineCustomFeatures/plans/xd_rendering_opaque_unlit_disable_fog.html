修改草案 · XD_RENDERING_OPAQUE_UNLIT_DISABLE_FOG

Opaque Unlit 材质可单独关闭雾效叠加

未覆盖 移植 引擎内实现 结构性改动 工作量 M风险 中开发者 Lu Xun主要模块 Shaders

一句话结论：材质属性 + shader permutation，需双端一致性与 DDC 重新验证

背景：为不透明无光照材质提供开关，避免远景雾把天空盒/特效类 Unlit 材质染灰。

1. UE5 现状与证据

结论依据：UE5 Runtime/Engine/Public/MaterialShared.h grep OpaqueUnlit/DisableFog 无结果；UE5 仅有 bUseTranslucencyVertexFog

覆盖说明：UE5 无 Opaque Unlit 单独关雾开关

证据路径（UE5.8.2）行号核对结果
Runtime/Engine/Public/MaterialShared.h—✅ 已命中：Source/Runtime/Engine/Public/MaterialShared.h

覆盖度：未覆盖  处置：移植

2. 修改步骤（移植）

  1. 定位 UE5 对应文件
    见下方「UE5 对应文件」；重点比对同文件在 UE4/UE5 的差异。
  2. 移植实现
    原实现位置：Shaders/Private/AtmosphericFogShader.usf、Shaders/Private/BasePassCommon.ush、Shaders/Private/DeferredShadingCommon.ush、Shaders/Private/Definitions.usf、Shaders/Private/HeightFogPixelShader.usf、Shaders/Private/ShadingModelsMaterial.ush、Shaders/Private/SkyAtmosphere.usf、Source/Editor/MaterialEditor/Private/MaterialEditorDetailCustomization.cpp。如涉及 Shader，需同步改 shader define 或共享 include。
  3. 适配 UE5 接口与规范
    注意 C++20、UHT（反射）规则、bValidateCircularDependencies 默认开启等差异；必要时回归 DDC/Cook。
  4. Shader 侧配套
    删除 DerivedDataCache 重编 Shader；同步更新受影响的 shader permutation / ShaderVersion。

3. 代码级实现（开发用）

独立 Agent 审核并修正修正 1 处　提出问题 3 条　其中高风险 1 条

审核意见：材质属性/FMaterialResource/SetDefine 锚点都真实（Material.h:1082、HLSLMaterialTranslator.cpp:2532-2533），但 after 丢 #else 且 shader 侧只写注释，UE5 需补 Unlit 分支。

简单移植 改动方式：素材属性、FMaterialResource 虚函数、SetDefine 与雾像素着色器在 UE5 均同名存在，照搬即可。

代码脉络：UMaterial 新增 bOpaqueUnlitDisableFog（Material.h:423-427）→ FMaterialResource::GetOpaqueUnlitDisableFog（MaterialShared.cpp:1600-1601）→ HLSLMaterialTranslator.cpp:1512 SetDefine → ShadingModelsMaterial.ush:218 写入 GBuffer.CustomData.r → HeightFogPixelShader.usf:63-75/SkyAtmosphere.usf:894/AtmosphericFogShader.usf:66 见 Unlit 且 CustomData.r>0.5 即跳过雾。

步骤 1Runtime/Engine/Public/Materials/Material.hMaterial.h:1082（UE5 已移到 Public/Materials/）

/** When true, translucent materials are fogged. */

uint8 bUseTranslucencyVertexFog : 1;   // 1082
#if XD_RENDERING_OPAQUE_UNLIT_DISABLE_FOG

// 消费点还需补：ShadingModelsMaterial.ush 的 Unlit 分支写 GBuffer.CustomData.r；BasePassCommon.ush:26/32；HeightFogPixelShader.usf:63-75 / SkyAtmosphere.usf:894 / AtmosphericFogShader.usf:66 跳过雾；Definitions.usf 兜底 0

⚠ GBuffer.CustomData.r 已被占用需查 UE5 该通道用途；UE5 Unlit 走 Substrate 时需另测。

风险评估

原代码风险：复用 GBuffer 通道易与其他特性（CustomData）冲突，且 4 个雾路径需同时改，漏改会雾残留。

移植风险：材质属性+shader permutation，影响全部 Unlit 材质 DDC 与双端一致性。

开发自检

  • Opaque Unlit+勾选后高度雾/体积雾/大气雾均不生效
  • 天空盒类 Unlit 远景不再被染灰
  • PC/Mobile 双端一致

结论置信度：medium — UE5 UE_5.8 Substrate 路径下 GBuffer 布局与 CustomData.r 语义可能变化，需实测。
