修改草案 · XD_MISC_CONSOLE_VARIABLES

注册 XD 新增的控制台变量（xd.* 命名空间）

部分覆盖 配置化 可工程化 仅加接入点 工作量 M风险 低开发者 Ran Qing Sen主要模块 Core

一句话结论：xd.* 变量整体迁到项目模块/CVar。

⚠ 原宏备注：UBT 依赖检查要求该宏必须为 1。

1. UE5 现状与证据

结论依据：Source/Runtime/Core/Private/HAL/ConsoleManager.cpp 原生 CVar 系统；XD 的 XDConsoleVariables.inc 为 xd.* 注册表

覆盖说明：UE5 无 xd.* 变量，但机制完全具备

证据路径（UE5.8.2）行号核对结果
Source/Runtime/Core/Private/HAL/ConsoleManager.cpp—✅ 已命中：Source/Runtime/Core/Private/HAL/ConsoleManager.cpp

覆盖度：部分覆盖  处置：配置化

2. 修改步骤（配置化）

  1. 确定配置承载
    项目模块用 TAutoConsoleVariable 注册 xd.* 变量（或插件）
  2. 设定默认值与灰度
    默认值应与当前线上行为一致；通过 ini/DeviceProfile 按平台/机型灰度，可随时回滚。
  3. 清理宏
    删除 UE4 宏与 Source/Runtime/Core/Private/HAL/ConsoleManager.cpp、Source/Runtime/Core/Private/HAL/XDConsoleVariables.inc 中的编译期分支，改为读取配置。

3. 代码级实现（开发用）

待独立 Agent 审核该草案尚未进入审核轮次：审核会打开 UE5 源码逐条核对行号、函数与 after 代码 引用的 API 是否存在。

简单移植 改动方式：TAutoConsoleVariable/ECVF 机制在 UE5 ConsoleManager.cpp:4090+ 完全一致，只需搬 inc 并补 UBT 宏注入点。

代码脉络：仅配置开关+一处 include：XDBuildMiscConfiguration.cs:38 定义值，UEBuildTarget.cs:3839-3857 反射写出 -DXD_MISC_CONSOLE_VARIABLES=1；UE4 真实引用只有 ConsoleManager.cpp:2967 `#include "XDConsoleVariables.inc"`，inc 内 TAutoConsoleVariable 注册 r.*/xd.* 变量。XDBuildMiscConfiguration.cs:520 强制该宏必须为 1。

步骤 1Source/Programs/UnrealBuildTool/Configuration/UEBuildTarget.csUE4 UEBuildTarget.cs:3836-3857；UE5 :6178-6179 之后

把 XD 宏表与反射写入循环移植进 UE5

// UE4 UEBuildTarget.cs:3845-3856
foreach (string FiledTypeName in XDBuildConfiguration.ConfigurationClasses)
{
    var Definition = Field.Name + "=" + FiledValue;
    GlobalCompileEnvironment.Definitions.Add(Definition);
}
// 插到 UE5 UEBuildTarget.cs:6179 GlobalCompileEnvironment.Definitions.AddRange(Rules.GlobalDefinitions); 之后
foreach (string T in XDBuildConfiguration.ConfigurationClasses)
{
    Type Ty = Type.GetType("UnrealBuildTool." + T);
    foreach (FieldInfo F in Ty.GetFields(BindingFlags.Public | BindingFlags.Static))
        GlobalCompileEnvironment.Definitions.Add(F.Name + "=" + (int)F.GetValue(null));
}

⚠ UE5 全 Source 内 grep XD_MISC_/XDBuildConfiguration 均 0 命中，这 8 个宏全靠本步注入；字段是 static，用 GetValue(null)，勿照抄 UE4 的 Activator.CreateInstance。

步骤 2Source/Runtime/Core/Private/HAL/ConsoleManager.cppConsoleManager.cpp:2967（UE4）→ UE5 :4105

插入 inc 引用并复制 XDConsoleVariables.inc 到同目录

#if XD_MISC_CONSOLE_VARIABLES
#include "XDConsoleVariables.inc"
#endif
// 插到 UE5 ConsoleManager.cpp:4105 '// ---------------------------------------' 之后
#if XD_MISC_CONSOLE_VARIABLES
#include "XDConsoleVariables.inc"
#endif

⚠ inc 内是 static TAutoConsoleVariable（XDConsoleVariables.inc:14-60，如 r.Mobile.EnableManualBatchWidgetsByZOrders、xd.r.BasePassSortPriorityMode），无额外模块依赖。

风险评估

原代码风险：宏=0 时 inc 不编译，xd.* 变量整批静默消失，功能无报错地退化。

移植风险：漏掉 UBT 注入步会导致所有 #if XD_MISC_* 恒为 0（未定义即 0），能编过但功能全丢，是本批共同前置风险。

开发自检

  • 构建日志出现 Setup XD Features Macros 且含 XD_MISC_CONSOLE_VARIABLES=1
  • 控制台可查询 xd.r.BasePassSortPriorityMode
  • 宏=0 时 CheckDependencies 主动报错

结论置信度：high
