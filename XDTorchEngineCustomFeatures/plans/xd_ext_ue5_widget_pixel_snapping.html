3. 代码级实现（开发用）

独立 Agent 审核通过

审核意见：核实属实：UE4 XD 分支遍布 SWidget.h:31/241/259/1233/1685、DrawElements.h:15/555/686、WidgetProxy.h:125/144、Widget.h:23/569、SHeaderRow.cpp:54/430（另含 DeclarativeSyntaxSupport.h，草案 thread 漏列）；UE5 原生 EWidgetPixelSnapping(WidgetPixelSnapping.h:14-23)、UWidget::PixelSnapping(Widget.h:445)/Get/SetPixelSnapping(:613/:6

建议舍弃 改动方式：UE5 原生具备 EWidgetPixelSnapping 与 UWidget::Get/SetPixelSnapping，无需移植。

代码脉络：XD 把 UE5 像素对齐反向移植进 UE4：SlateCore 的 WidgetPixelSnapping.h、SWidget.h:31/241/1233/1685、DrawElements.h:555/686、WidgetProxy.h:125/144 全被宏包住，UMG Widget.h:445/613-616、SHeaderRow.cpp:54 亦如此。

步骤 1Runtime/SlateCore/Public/Widgets/WidgetPixelSnapping.hUE5:13-24

删除 XD 移植版，直接用引擎头

#if XD_EXT_UE5_WIDGET_PIXEL_SNAPPING
UENUM() enum class EWidgetPixelSnapping : uint8 { Inherit, Disabled, SnapToPixel };
#endif
// 删除；UE5 原生 EWidgetPixelSnapping { Inherit, Disabled, SnapToPixel }（WidgetPixelSnapping.h:13-24）

⚠ 枚举值一致，无需改名。

步骤 2Runtime/UMG/Public/Components/Widget.h、Runtime/SlateCore/Public/Widgets/SWidget.hUE5 Widget.h:445/613-616、SWidget.h:1307-1310

去掉宏与自定义实现

#if XD_EXT_UE5_WIDGET_PIXEL_SNAPPING
	EWidgetPixelSnapping PixelSnapping;
...
#endif
// UE5 原生：Widget.h:445 UPROPERTY EWidgetPixelSnapping PixelSnapping; :613-616 Get/SetPixelSnapping；SWidget.h:1307 SetPixelSnapping / :1963 PixelSnappingMethod

⚠ 项目若引用 XD 分支成员需改为引擎 API。

风险评估

原代码风险：XD 版本与 DrawElements/WidgetProxy 深度耦合，宏关闭才回旧路径，维护成本高。

移植风险：删除后项目 UI 上设置过 PixelSnapping 的资产需换用引擎属性，需回归。

开发自检

  • 控件设置 PixelSnapping 后像素对齐正常
  • 动画/移动控件关闭对齐无抖动

结论置信度：high
