修改草案 · XD_OPT_MOBILE_UPSCALE_PASS_DISABLE_WHEN_SIZE_DIFF_LITTLE

当 Tonemap 输出与 BackBuffer 尺寸仅差一点时跳过 Upscale Pass

部分覆盖 配置化 需接入点 仅加接入点 工作量 S风险 中开发者 Ran Qing Sen主要模块 Renderer

一句话结论：先靠 ScreenPercentage/分辨率对齐消除缩放；仍存在则加 CVar 控制跳过（避免误判导致画面偏移）

0. 根因溯源（这个宏为什么存在）

XD 定制需求（非上游缺陷）

结论：宏=1 时只在 UnscaledViewRect 与 ViewRect 宽/高差>=10px 才启用 PrimaryUpscale，避免近乎等比时多跑一个全屏 upscale pass；代价是 9px/10px 之间的阶跃误判。

上游引入：XD 自加：PostProcessing.cpp:1662-1671。上游 UE4 原判据为 View.UnscaledViewRect != View.ViewRect(:1671)。Engine 无 .git，无提交号。

上游历史（是否修过）：UE5.8.2 PostProcessing.cpp:2844 `bShouldPrimaryUpscale = (SpatialUpscale && View.GetSecondaryViewRectSize() != View.ViewRect.Size()) || View.LensDistortionLUT.IsEnabled()`，:2866 SetEnabled；已不用 UnscaledViewRect/10px。UE5 PostProcessUpscale.cpp:33 另有 r.Mobile.Upscale.Quality(CVarMobileUpscaleQuality，e20418f8e1e0/2025-11-25 引入)。

调用方契约：PassSequence.SetEnabled(EPass::PrimaryUpscale, bShouldPrimaryUpscale && bDisableUpscaleInTonemapper)(:1688) 与 :2323 的 tonemap/最后一次 pass 交互；bShouldPrimaryUpscale 还影响输出 ViewRect 取值。

内层真实语义：10px 阈值下 <10px 不 upscale、>=10px upscale，存在不连续边界；与 r.MobileTonemapperUpscale 共同决定最终是否单独跑 primary upscale。grep 确认步骤里建议新增的 CVarMobileSkipUpscaleOnLittleDiff 在源码中无任何引用，是死开关。

代码库惯例：上游用精确 rect.Size() 比较(UE5:2844)，缩放质量交给 CVarMobileUpscaleQuality，不用像素阈值。

为何长期未被发现：近乎无缩放时画面几乎看不出，仅在特定 ScreenPercentage/窗口尺寸组合下才触发误判，正常游玩难复现。

XD 侧的做法与意图：省一次全屏 upscale，提升移动端帧率。

⚠ 把 10px 阈值照搬到 UE5 会与 GetSecondaryViewRectSize 语义打架，在 1080p 等边缘尺寸触发黑边/整帧偏移；新增却无人引用的 CVar 开关会让维护者误以为已生效。

迁移方案（按根因定）

删除宏，采用 UE5 精确比较(GetSecondaryViewRectSize 与 LensDistortionLUT)；若要省 pass，应基于 ScreenPercentage 比值而非像素阈值，并统一走 r.Mobile.Upscale.Quality。

根因级自检用例

  • 各档 ScreenPercentage 下输出分辨率正确、无黑边/偏移
  • LensDistortion 开启时仍强制 primary upscale
  • TonemapperUpscale=0 时单独 upscale 生效、=1 时不重复
  • 尺寸差 9px/10px 边界行为连续(采用精确比较后)

风险评估

原代码风险：10px 硬阈值在非整数缩放比下可能误判，导致整帧画面偏移/欠采样。

移植风险：改动移动端后处理 Pass 启用位，误判会让输出分辨率错误或黑屏，需回归各档 ScreenPercentage。

开发自检

  • 100%/非整比例 ScreenPercentage 下无画面偏移
  • 开启 LensDistortion 时 PrimaryUpscale 仍执行

结论置信度：medium — UE5 移动端另有 Tonemap Subpass 内联，是否还需 PrimaryUpscale 跳过需实测
