修改草案 · XD_TORCHLIGHT_IMPORTSCENECONVERT_FORCEFRONTXAXIS

导入场景转换时强制以 +X 作为模型正面朝向

部分覆盖 常开补丁 需接入点 仅加接入点 工作量 S风险 中开发者 Cheng Zhi Jun主要模块 Editor/UnrealEd

一句话结论：需改/替换 FFbxImporter JointOrientationMatrix 分支（导入器非项目扩展点）；会改变既有资产朝向，需重新导入校验

背景：统一外部工具（3ds Max/Maya）导出的模型朝向，避免美术资源进引擎后朝向不一致。

1. UE5 现状与证据

结论依据：E:/TorchLight_UE5/Engine/Engine/Source/Editor/UnrealEd/Private/Fbx/FbxMainImport.cpp:220/1536（bForceFrontXAxis、ECoordinateSystemPolicy::MatchUpForwardAxes）

覆盖说明：UE5 有坐标系策略与 bForceFrontXAxis，但没有 XD 的 JointOrientationMatrix(0,0,-90) 修正

证据路径（UE5.8.2）行号核对结果

覆盖度：部分覆盖  处置：常开补丁

2. 修改步骤（常开补丁）

  1. 在 UE5 上复核问题
    UE5 证据：E:/TorchLight_UE5/Engine/Engine/Source/Editor/UnrealEd/Private/Fbx/FbxMainImport.cpp:220/1536（bForceFrontXAxis、ECoordinateSystemPolicy::MatchUpForwardAxes）。先在 UE5 复现原问题；若已不存在，则按「删除」处理。
  2. 在 UE5 fork 重新应用补丁
    原实现位置：Source/Editor/UnrealEd/Private/Fbx/FbxMainImport.cpp。引擎侧改动点：UFbxImportUI.bForceFrontXAxis / ECoordinateSystemPolicy、FbxMainImport JointOrientationMatrix 分支。补丁应保持最小范围，避免改公共接口。
  3. 登记为常开补丁
    在 Feature Registry 记录：问题、修法、验证方式、回滚方式；不再挂编译开关。

3. 代码级实现（开发用）

待独立 Agent 审核该草案尚未进入审核轮次：审核会打开 UE5 源码逐条核对行号、函数与 after 代码 引用的 API 是否存在。

简单移植 改动方式：UE5 FFbxImporter::ConvertScene（:1499）同一分支原样存在（:1559-1561），类/函数/签名一致，只需改旋转常量。

代码脉络：只影响 FFbxImporter::ConvertScene（UE4 FbxMainImport.cpp:1366，宏在 :1428-1434）：当 ImportUI->bForceFrontXAxis 为真时把 JointOrientationMatrix 旋转由 (-90,-90,0) 改为 (0,0,-90)，随后交给 FFbxDataConverter::SetJointPostConversionMatrix(:1442)。

步骤 1Editor/UnrealEd/Private/Fbx/FbxMainImport.cpp1559-1561

改 JointOrientationMatrix 旋转分量

if (GetImportOptions()->bForceFrontXAxis)
{
	JointOrientationMatrix.SetR(FbxVector4(-90.0, -90.0, 0.0));
}
if (GetImportOptions()->bForceFrontXAxis)
{
	// XD_TORCHLIGHT_IMPORTSCENECONVERT_FORCEFRONTXAXIS
	JointOrientationMatrix.SetR(FbxVector4(0.0, 0.0, -90.0));
}

⚠ 引擎导入器无项目扩展点；建议用 CVar（默认 1）包一层便于回退。

步骤 2Editor/UnrealEd/Classes/Factories/FbxAssetImportData.h40 与 47-48

确保前置开关让该分支进入

bool bForceFrontXAxis; // 仅它为真才走 UE4 :1428 分支
; DefaultEditorPerProjectUserSettings.ini
[/Script/UnrealEd.FbxAssetImportData]
bConvertScene=True
bForceFrontXAxis=True

⚠ bForceFrontXAxis 是 config 属性；等价枚举为 CoordinateSystemPolicy=MatchUpForwardAxes。

风险评估

原代码风险：改动骨骼后转换矩阵会让所有开 FrontX 的导入资产朝向/绑定偏离引擎默认，且只影响新导入，重导入结果会变。

移植风险：补丁在引擎导入器，影响全部 Fbx 导入路径（含 scene import/批量/自动化），既有骨骼资产需重导校验。

开发自检

  • +X 朝向模型导入后朝向与期望一致
  • 骨骼动画无轴向错位/手部翻转
  • 关闭开关后与 UE5 原生一致

结论置信度：medium — UE5 新增 bUsingLUFCoordinateSysem/ECoordinateSystemPolicy 分支（:1526-1563 选择 UnrealImportAxis），需确认 (0,0,-90) 在各 policy 下仍正确。
