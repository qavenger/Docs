修改草案 · XD_OPT_SHADER_BYTE_CODE_PREFER_OODLE_COMPRESSION_FORMAT

Shader 字节码默认优先使用 Oodle 压缩格式

UE5 已覆盖 删除 可工程化 无需改引擎 工作量 S风险 中开发者 Ran Qing Sen主要模块 RenderCore

一句话结论：直接删除

背景：Shader 代码库(USBC)压缩格式切换为 Oodle，提升加载速度/压缩率。

1. UE5 现状与证据

结论依据：Runtime/RenderCore/Public/ShaderCore.h:178 GetShaderCompressionFormat()；Runtime/RenderCore/Private/ShaderCore.cpp:4285 “We now force shaders to compress with oodle”

覆盖说明：UE5 已强制 Oodle 压缩 Shader

覆盖度：UE5 已覆盖  处置：删除

  1. 确认 UE5 已覆盖（无需写代码）
    依据：Runtime/RenderCore/Public/ShaderCore.h:178 GetShaderCompressionFormat()；Runtime/RenderCore/Private/ShaderCore.cpp:4285 “We now force shaders to compress with oodle”。先在 UE5 中核对上述路径/行为，确认等价后再删除宏。
  2. 删除 UE4 侧的宏与代码

3. 代码级实现（开发用）

独立 Agent 审核通过

审核意见：核实：UE4 六处别名/压缩点（ShaderResource.cpp:53/228/508、ShaderCodeArchive.cpp:41/205/910、ShaderCodeLibrary.cpp:995、Shader.cpp:1448、OpenGLShaderLibrary.cpp:4、VulkanShaderLibrary.cpp:5）均与描述一致；UE5 ShaderResource.cpp:37-43 GetShaderCompressionFormat 恒返回 NAME_Oodle、ShaderCore.cpp:4285 check==NAME_Oodle、ShaderResou

建议舍弃 改动方式：UE5 已强制用 Oodle 压缩 shader 字节码，XD 的格式切换与 LZ4 回退都无对象。

代码脉络：def XDBuildOptConfiguration.cs:65。ShaderResource.cpp:53-59 定义 ShaderCompressionFormat="Oodle"（失败回退 NAME_LZ4），在 :228（FShaderMapResourceCode::AddShader 压缩）与 :508（解压）使用；ShaderCodeArchive.cpp:41,205,910 与 ShaderCodeLibrary.cpp:995 同构；Shader.cpp:1448 给 shader key 追加 "_OodleCompression"；OpenGLShaderLibrary.cpp:4、VulkanShaderLibrary.cpp:5 复制同款别名。

步骤 1Runtime/RenderCore/Private/ShaderResource.cppShaderResource.cpp:53-59（UE5 同文件:37-56 GetShaderCompressionFormat）

删除别名与 LZ4 回退，直接沿用 UE5 实现

#if XD_OPT_SHADER_BYTE_CODE_PREFER_OODLE_COMPRESSION_FORMAT
static const FName ShaderCompressionFormat = TEXT("Oodle");
static const FName ShaderCompressionFormat_Orig = NAME_LZ4;
#else
static const FName ShaderCompressionFormat = NAME_LZ4;
#endif
FName GetShaderCompressionFormat()
{
 // UE5 ShaderResource.cpp:37-56："We always use oodle now"
 return NAME_Oodle;
}

⚠ ShaderCore.cpp:4285 有 check(ShaderCompressionFormat == NAME_Oodle)，LZ4 通道已死；解压/校验路径统一见 UE5 ShaderResource.cpp:687。

步骤 2Runtime/RenderCore/Private/Shader.cppShader.cpp:1448（AppendShaderKey）

不移植 key 后缀，UE5 已在 key 里自动带压缩格式

#if XD_OPT_SHADER_BYTE_CODE_PREFER_OODLE_COMPRESSION_FORMAT
    { KeyString += TEXT("_OodleCompression"); }
#endif
// UE5 Shader.cpp:2906-2912 已生成：
KeyGen.AppendSeparator();
KeyGen.Append(TEXT("Compr"));
FName CompressionFormat = GetShaderCompressionFormat();
KeyGen.Append(CompressionFormat);
if (CompressionFormat == NAME_Oodle) { /* 追加 oodle 参数 */ }

⚠ 需要临时退回未压缩时用 r.Shaders.SkipCompression=1（Shader.cpp:103-107，仅非 shipping/test 生效）。

风险评估

原代码风险：手工在 6 个 RHI/渲染文件里维护压缩格式名，任何一处漏改就会解压失败（check 崩）或 shader key 不一致导致重复编译。

移植风险：不移植无功能损失；但旧 DDC/旧 pak 里的 LZ4 shader 会与 UE5 的 Oodle 校验(ShaderCore.cpp:4357-4400)冲突，必须重编 shader 库。

开发自检

  • r.Shaders.SkipCompression 默认 0 时打包/加载 shader 无 Fatal
  • ShaderKey 与 UE4 基线差异仅来自格式，无额外重复编译

结论置信度：high
