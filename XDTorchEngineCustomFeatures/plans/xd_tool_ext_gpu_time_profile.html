扩展 GPU 时间采样，输出更多 GPU 阶段耗时（当前关闭）

1. UE5 现状与证据

结论依据：UE5 Runtime/RHI 有 GPUProfiler（stat GPU / r.GPUStats 系列）

覆盖说明：有 GPU 计时框架，阶段覆盖不同

覆盖度：部分覆盖  处置：移植

2. 修改步骤（移植）

  1. 定位 UE5 对应文件
    见下方「UE5 对应文件」；重点比对同文件在 UE4/UE5 的差异。
  2. 移植实现
    原实现位置：Source/Runtime/Apple/MetalRHI/Private/MetalCommandEncoder.cpp、Source/Runtime/Apple/MetalRHI/Private/MetalCommandList.cpp、Source/Runtime/Apple/MetalRHI/Private/MetalCommandList.h、Source/Runtime/Apple/MetalRHI/Private/MetalCommands.cpp、Source/Runtime/Apple/MetalRHI/Private/MetalDynamicRHI.h、Source/Runtime/Apple/MetalRHI/Private/MetalProfiler.cpp、Source/Runtime/Apple/MetalRHI/Private/MetalProfiler.h、Source/Runtime/Engine/Private/UnrealClient.cpp。如涉及 Shader，需同步改 shader define 或共享 include。
  3. 适配 UE5 接口与规范

3. 代码级实现（开发用）

独立 Agent 审核并修正修正 2 处　提出问题 2 条

审核意见：UE4 行号（DynamicRHI.h:1163/1754、MetalProfiler.cpp:323-325、MetalCommands.cpp:700-706、EngineGlobals.h:16、UnrealEngine.cpp:766、UnrealClient.cpp:459-463）与 UE5 FMetalTiming 均核实无误；需清掉 reason 里的假断言并补跨模块 extern。

完全重构 改动方式：UE5 Metal RHI 与 GPU 计时已重构（FMetalGPUProfiler、FMetalCommandList::Commit 均不存在），必须按 FMetalTiming(MetalCommandQueue.h:15) + UE::RHI::GPUProfiler 新结构重写；RHI 侧已有全局 GGPUFrameTime(RHI/Private/GPUProfiler.cpp:2265) 可作模板。

代码脉络：值=0。开启后在 RHI 层补 GPU 空闲采样：Runtime/RHI/Public/DynamicRHI.h:1163-1170 加虚函数 RHIGetGPUFrameIdleCycles、:1754-1759 加同名自由函数；MetalRHI/Private/MetalProfiler.cpp:323-325(FMetalGPUProfiler::RecordFrame) 写 GGPUFrameIdleTime，MetalCommands.cpp:700-706 实现，EngineGlobals.h:16 与 UnrealEngine.cpp:766 定义，UnrealClient.cpp:459-463 消费；另在 MetalCommandList/FMetalCommandBufferTiming 上加 DebugBufferName 做逐 command buffer 打印。

⚠ UE5 已无 FMetalGPUProfiler/GMetalGPUWorkTime，逐 command buffer DebugName 改由 UE::RHI::GPUProfiler::FEventStream + FMetalCommandBuffer::EmplaceProfilerEvent 承载；此步为等价重写方案，需人工在 submit/end-frame 处取真实时间戳

风险评估

原代码风险：在 RHI 抽象层加虚函数，所有 RHI 后端都得实现（XD 仅在 Metal 实现，其余靠基类 return 0）；STATS 关闭时变量未定义而读侧未同步加宏会编译失败。

移植风险：改 RHI 公共头触发全量重编；Metal 侧新结构（FMetalTiming/GPUProfiler 事件流）语义不同，写错时间戳会让 stat GPU 数值失真。

开发自检

  • stat unit/stat GPU 出现非负 GPU idle 数值
  • Metal 与 D3D/Vulkan 后端均编译通过
  • 非 Metal 平台 RHIGetGPUFrameIdleCycles 返回 0 不崩

结论置信度：low — UE5 是否仍有『帧内 GPU 空洞』语义需人工确认；宏默认关闭且属 Metal 专有调试卷，判 abandon 亦可接受。
