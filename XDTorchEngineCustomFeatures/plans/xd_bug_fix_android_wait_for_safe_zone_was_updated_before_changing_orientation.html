3. 代码级实现（开发用）

独立 Agent 审核通过

审核意见：核对通过：UE4 AndroidWindow.cpp:126-128 的 `GAndroidSafezoneRequiresUpdate = true`、AndroidApplication.cpp:140-147（HandleDeviceOrientation，函数体 100-162）与 before 一致；UE5 已核实 AndroidWindow.cpp:199-204 在安全区变化时 EnqueueAppEvent(APP_EVENT_STATE_SAFE_ZONE_UPDATED)（:202），Launch/Private/Android/AndroidEventManager.cp

建议舍弃 改动方式：UE5 安全区更新已改为独立事件驱动，方向切换不再提前广播。

代码脉络：宏加原子标记 GAndroidSafezoneRequiresUpdate 与 FAndroidWindow::SafezoneUpdated()（Private/Android/AndroidWindow.cpp:88、126-146），JNI nativeSetSafezoneInfo 置位后，HandleDeviceOrientation 才广播 OnSafeFrameChangedEvent（Private/Android/AndroidApplication.cpp:140）。UE5 无此等待逻辑，但 nativeSetSafezoneInfo 会入队安全区事件（AndroidWindow.cpp:191-205），由事件管理器广播（Launch/Private/Android/AndroidEventManager.cpp:186-187）。

风险评估

⚠ 与早期迁移处置结论存在分歧：早期结论=要移植，代码级分析=建议舍弃。早期结论=移植，代码级分析=建议舍弃；建议以代码级分析为准并回写评估矩阵。

原代码风险：依赖 Java 回调时序，异常时序下仍可能用旧安全区。

移植风险：若 UE5 事件未触发，安全区变化不通知 UI，需真机回归旋转。

开发自检

  • Android 旋转后安全区正确
  • 旋转过程无重复通知

结论置信度：medium — UE5 事件入队与 Java 回调先后顺序需真机确认。
