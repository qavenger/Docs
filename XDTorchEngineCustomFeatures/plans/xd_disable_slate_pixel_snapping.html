修改草案 · XD_DISABLE_SLATE_PIXEL_SNAPPING

关闭 Slate 文本渲染的像素对齐（Pixel Snapping）

部分覆盖 配置化 可工程化 仅加接入点 工作量 S风险 低开发者 Lu Xun主要模块 Slate

一句话结论：宏删除，改由项目按控件设置像素对齐；如确需全局开关，加 CVar 挂到 PushPixelSnappingMethod。

背景：避免文字在缩放/位移动画中出现抖动或笔画丢失，代价是可能出现半像素模糊。

0. 根因溯源（这个宏为什么存在）

XD 定制需求（非上游缺陷）

结论：宏开(=1，XDBuildRenderingConfiguration.cs:206)时在 ElementBatcher.cpp:29-35 注册 CVar slate.EnablePixelSnapping，AddElementsInternal(:377)读 bEnablePixelSnapped，并在 10 处(:389 起，Box/Border/Text/ShapedText/Quad/Viewport)把 DrawElement.IsPixelSnapped() 与之取与，使全部元素改走 Disabled。

上游引入：XD 需求且 CVar 名自造：git log -S "slate.EnablePixelSnapping" -- Engine/Source/Runtime/SlateCore 全历史 0 命中；HEAD 全 Engine/Source grep EnablePixelSnapping 亦 0。

上游历史（是否修过）：上游从无全局开关；UE4.19/4.20 的 ElementBatcher.cpp 中同名者只是局部变量，4.21.2-release 已内联为 DrawElement.IsPixelSnapped()(:139)。UE5 5.8.2 无任何 PixelSnapping CVar，改为控件级 WidgetPixelSnapping.h:14 与 DrawElementTypes.cpp:170-185。

为什么可以断定不是「故意为之」3 条依据
  • 上游把“是否对齐”设计成每元素/每控件决定(NoPixelSnapping)，不存在“缺全局开关”
  • XD 的 CVar 默认 1=零行为变化，属保险丝而非修复
  • 同名局部变量在 4.21 被有意内联，属上游重构而非删功能

调用方契约：ElementBatcher 是 Slate 唯一 element→vertex 批处理入口；bEnablePixelSnapped 只在那 10 个 switch 分支读；CVar 用 ECVF_RenderThreadSafe(:33)，故可热切换。

内层真实语义：CVar=0 时全部走 Add*Element<Disabled>，等价于给所有元素强加 NoPixelSnapping；=1 或变量缺失时与上游逐字节一致。IsPixelSnapped() 语义为 !EnumHasAllFlags(DrawEffects,NoPixelSnapping)(DrawElements.h:278)，取与保留了“已显式关闭者仍关闭”。

代码库惯例：上游全局开关惯例=CVar+inline 取值函数；UE5 的 GSlateFeathering(ElementBatcher.cpp:36)可作模板。

为何长期未被发现：默认 1 无人察觉；只在 QA 反馈“文字发虚”手动设 0 时显形；只影响顶点取整，不影响布局。

XD 侧的做法与意图：ElementBatcher.cpp:29-35(CVar)、:377(读取)、:389 起 10 处取与；意图是“需要时全局关掉 Slate 像素对齐”，不改默认观感。

⚠ 照搬 CVar 且默认 0 会让全 UI 变半像素模糊(XD 自己默认写 1)；⚠ 若在 AddElementsInternal 开头改写 DrawElement.DrawEffects，会污染 const 元素并可能破坏 cached element 复用；⚠ UE5 中 FSlateDrawElement/ESlateDrawEffect 已拆到 DrawElementTypes.h，按老位置改会编译不过。

迁移方案（按根因定）

①首选删除：UE5 用控件级 SetPixelSnapping(EWidgetPixelSnapping::Disabled) 或 PushPixelSnappingMethod 即可；②若必须保留全局开关，挂在 FSlateDrawElement::Init 的 GetPixelSnappingMethod switch(DrawElementTypes.cpp:170-185) 的 Disabled 分支上，一处生效，避免 10 处散点取与；③CVar 默认保持 1。

根因级自检用例

  • CVar=1 与原生 UE5 渲染结果逐帧一致
  • CVar=0 时所有元素走 Disabled，且显式 NoPixelSnapping 元素不受影响
  • CVar 热切换无越界/无残留缓存
  • 仅指定控件关闭时不改变其它控件清晰度

2. 修改步骤（配置化）

  1. 确定配置承载
    项目侧对需要关闭的控件调用 SetPixelSnapping(EWidgetPixelSnapping::Disabled)（UMG/C++ 均可用）
  2. 设定默认值与灰度
    默认值应与当前线上行为一致；通过 ini/DeviceProfile 按平台/机型灰度，可随时回滚。
  3. 清理宏
    删除 UE4 宏与 Source/Runtime/SlateCore/Private/Rendering/ElementBatcher.cpp 中的编译期分支，改为读取配置。

3. 代码级实现（开发用）

独立 Agent 审核通过

审核意见：核实属实：UE4 ElementBatcher.cpp:29-35 定义 CVar、:378 读 bEnablePixelSnapped、:390/:400/:411 各处取与；UE5 全 Source grep 'slate.EnablePixelSnapping' 无结果，确可新增，且 ElementBatcher.cpp:399/410/421/440/464/475 的 `Add*Element<ESlateVertexRounding::...>` 结构存在，steps[1].after 语法正确，refactor 判断合理。仅锚点略偏：UE5 AddElementsInternal

完全重构 改动方式：UE5 ElementBatcher 改为 FSlateDrawElementMap 按元素类型批量添加，原 switch+bool 结构已不存在，需按新结构重挂。

代码脉络：开启后 ElementBatcher.cpp:29 定义 CVar slate.EnablePixelSnapping，AddElementsInternal 在 :377 读取 bEnablePixelSnapped，并在每个 Add*Element 前与 DrawElement.IsPixelSnapped() 取与(如 :390/:400/:411)，为 0 时全部走 ESlateVertexRounding::Disabled，从而关闭 Slate 文本像素对齐。

步骤 1Runtime/SlateCore/Private/Rendering/ElementBatcher.cppElementBatcher.cpp:33

新增全局 CVar 与谓词

#if XD_DISABLE_SLATE_PIXEL_SNAPPING

#endif
static TAutoConsoleVariable<int32> CVarEnablePixelSnapping(
    TEXT("slate.EnablePixelSnapping"), 1, TEXT("switch for pixel snapping"), ECVF_RenderThreadSafe);
static bool IsPixelSnappingEnabled() { return CVarEnablePixelSnapping.GetValueOnAnyThread() > 0; }

⚠ UE5 无同名 CVar(ElementBatcher.cpp grep 无结果)，可安全新增

步骤 2Runtime/SlateCore/Private/Rendering/ElementBatcher.cppAddElementsInternal:396

对 Box/RoundedBox/Border/Text/ShapedText/Line/Quad/Viewport 各类调用统一加上 CVar 判定

DrawElement.IsPixelSnapped() ? AddBorderElement<ESlateVertexRounding::Enabled>(DrawElement) : AddBorderElement<ESlateVertexRounding::Disabled>(DrawElement);
(DrawElement.IsPixelSnapped() && IsPixelSnappingEnabled()) ? AddBorderElement<ESlateVertexRounding::Enabled>(DrawElement) : AddBorderElement<ESlateVertexRounding::Disabled>(DrawElement);

⚠ UE5 中 Box/Border/Line 等分支均已内联 IsPixelSnapped()(如 :399/:410/:421)，需逐条改；项目也可用 SWidget::SetPixelSnapping(EWidgetPixelSnapping::Disabled)(SWidget.h:1307)

风险评估

原代码风险：全局关闭像素对齐会让所有控件文字出现半像素模糊，影响面大于预期。

移植风险：CVar 默认值若为 0 会全局改变 Slate 渲染观感，需回归 UI 清晰度。

开发自检

  • slate.EnablePixelSnapping 0/1 切换下文本抖动与模糊符合预期
  • 仅目标文本受影响，UI 布局无位移

结论置信度：medium — 需要全局开关还是按控件 SetPixelSnapping，需产品确认
