3. 代码级实现（开发用）

待独立 Agent 审核该草案尚未进入审核轮次：审核会打开 UE5 源码逐条核对行号、函数与 after 代码 引用的 API 是否存在。

建议舍弃 改动方式：UE5 已有等价原生分辨率查询接口，该宏只是把同一能力暴露成引擎 API，工程/插件侧封装即可。

代码脉络：FGenericPlatformMisc::GetScreenSize 提供默认 0（GenericPlatformMisc.cpp:413，声明 GenericPlatformMisc.h:557），Android 覆写 FAndroidMisc::GetScreenSize（AndroidPlatformMisc.cpp:3528）转发 JNI AndroidThunkCpp_GetScreenSize（AndroidJNI.cpp:1628）；jmethodID AndroidThunkJava_GetScreenSize 在 AndroidJNI.h:63 声明、AndroidJNI.cpp:415 以 "()F" 绑定。UE5 无 GetScreenSize，已有 FAndroidApplicationMisc::GetNativePhysicalScreenResolution（ApplicationCore/Private/Android/AndroidPlatformApplicationMisc.cpp:291）。

步骤 1Runtime/Core/Private/Android/AndroidPlatformMisc.cppFAndroidMisc::GetScreenSize(:3528) 与 GenericPlatformMisc.cpp:413 默认实现、GenericPlatformMisc.h:557/AndroidPlatformMisc.h:201 声明

不迁移引擎补丁，删除宏及其 JNI 绑定（AndroidJNI.h:63、AndroidJNI.cpp:116/415/1628-1641）。

#if XD_EXT_ADD_ANDROID_GET_SCREEN_SIZE_INTERFACE
float FAndroidMisc::GetScreenSize()
{
#if USE_ANDROID_JNI
    extern float AndroidThunkCpp_GetScreenSize();
    return AndroidThunkCpp_GetScreenSize();
#else
    return 0;
#endif
}
#endif
// UE5: 删除引擎补丁；需要时用引擎已有接口
// Runtime/ApplicationCore/Private/Android/AndroidPlatformApplicationMisc.cpp:291
void FAndroidApplicationMisc::GetNativePhysicalScreenResolution(FIntVector2& OutScreenResolution);

⚠ UE5 该接口读 unreal.display 元数据的 realWidth/realHeight，返回像素而非 UE4 的 float。

步骤 2Runtime/ApplicationCore/Private/Android/AndroidPlatformApplicationMisc.cppGetNativePhysicalScreenResolution(:291)，调用示例 :240

工程/插件侧改为调用引擎接口取真实屏幕尺寸。

float Size = FAndroidMisc::GetScreenSize();  // UE4 自定义 API
FIntVector2 NativeRes;
FAndroidApplicationMisc::GetNativePhysicalScreenResolution(NativeRes);
// 需要窗口/缩放后尺寸时用 Runtime/ApplicationCore/Private/Android/AndroidWindow.cpp:405 FAndroidWindow::GetNativeWindowResolution

⚠ AndroidPlatformApplicationMisc.h:29 已声明；不要在 Game/插件外再走 JNI 直调。

风险评估

⚠ 与早期迁移处置结论存在分歧：早期结论=要移植，代码级分析=建议舍弃。早期结论=插件化，代码级分析=建议舍弃；建议以代码级分析为准并回写评估矩阵。

原代码风险：自行加 JNI 方法与全局静态方法，Java 侧未实现时会返回 0（bIsOptional 绑定）造成静默错误值。

移植风险：UE4 返回单个 float、UE5 返回 FIntVector2，若沿用旧调用点会类型不匹配或语义变化（物理像素 vs 逻辑像素）。

开发自检

  • Android 真机与模拟器上对比 GetNativePhysicalScreenResolution 与系统分辨率
  • 确认删除 GetScreenSize 后无工程残留引用导致链接失败

结论置信度：high — UE4 返回值的具体含义（DPI 还是像素）未在源码注释中说明，需与原使用方核对后决定是否需要额外换算。
