修改草案 · XD_OPT_CUSTOM_CONCURRENT_SLATE_TASK

底层并发 Slate Tick 任务支持

未覆盖 保留引擎 引擎内实现 结构性改动 工作量 L风险 高开发者 Wang Xiao Bo主要模块 Engine

一句话结论：高风险性能特性，UE5 tick 体系已重构（TG_PreSlate 等），需重新评估收益后再实现。

背景：把 Slate Tick 拆分为可并发的任务，降低 UI 造成的 GT 卡顿。

1. UE5 现状与证据

结论依据：UE5 Runtime/Slate/Private/Framework/Application 下无并行 Slate Tick（grep Parallel 无结果）；无 XD 的 OnBeforeSlateTick 类扩展点

覆盖说明：UE5 无等价并发 Slate Tick 能力

覆盖度：未覆盖  处置：保留引擎

2. 修改步骤（暂留引擎）

  1. 登记 Feature Card
    记录 owner、影响面、依赖、关闭条件、验证方式与回滚方式；这是当前最高风险的一类（引擎内深度改动）。
  2. 评估替代路径
    优先考虑改用 UE5 原生机制（如 Niagara / Substrate / PSOPrecache / WorldPartition）替代自研实现；替代前保留最小可用补丁。
  3. 设定复查条件
    每个版本复查一次：是否可以降级为插件/配置，或直接删除。

3. 代码级实现（开发用）

独立 Agent 审核并修正提出问题 2 条

审核意见：thread 行号全部核实为真（CoreDelegates.h:711、LaunchEngineLoop.cpp:5160/5282、LevelTick.cpp:180/1630/1668、World.h:3860）；最大缺口是未把 World::Tick 侧的两处广播写成 steps。

完全重构 改动方式：UE5 tick/委托体系重构，FCoreDelegates 无这两个委托，且需重挂广播点

代码脉络：开关打开后，LaunchEngineLoop.cpp:5160 在 FSlateApplication::Tick(TimeAndWidgets) 前广播 FCoreDelegates::OnBeforeSlateTick、:5282 广播 OnBeforeEndFrame；World.h:3860 声明 FLowLevelOnWorldTickGroupEvent，LevelTick.cpp:180/1630 在 TG_PrePhysics/TG_StartPhysics 前广播，:1668 之后广播，供项目挂并发任务与 Slate tick 重叠。

步骤 1Runtime/Core/Public/Misc/CoreDelegates.h紧跟 UE5 OnEndFrame(283 行)后

补回两个低层 tick 委托声明

// #if XD_OPT_CUSTOM_CONCURRENT_SLATE_TASK begin
DECLARE_MULTICAST_DELEGATE_OneParam(FXDLowLevelTickEvent, double);
static FXDLowLevelTickEvent OnBeforeSlateTick;
static FXDLowLevelTickEvent OnBeforeEndFrame;
// #endif end
#if XD_OPT_CUSTOM_CONCURRENT_SLATE_TASK
DECLARE_MULTICAST_DELEGATE_OneParam(FXDLowLevelTickEvent, double /*DeltaSeconds*/);
static CORE_API FXDLowLevelTickEvent OnBeforeSlateTick;
static CORE_API FXDLowLevelTickEvent OnBeforeEndFrame;
#endif // 并在 CoreDelegates.cpp 加定义

⚠ UE5 该头只用 OnEndFrame，无 OnBeforeSlateTick/OnBeforeEndFrame，必须新增；须在 Core/Private/Misc/CoreDelegates.cpp 补 out-of-line 定义否则链接失败

步骤 2Runtime/Launch/Private/LaunchEngineLoop.cppFSlateApplication::Get().Tick(...TimeAndWidgets) 前(UE5 ~5991)

在 Slate tick 前广播

#if XD_OPT_CUSTOM_CONCURRENT_SLATE_TASK
    FCoreDelegates::OnBeforeSlateTick.Broadcast(FApp::GetDeltaTime());
#endif
#if XD_OPT_CUSTOM_CONCURRENT_SLATE_TASK
    FCoreDelegates::OnBeforeSlateTick.Broadcast(FApp::GetDeltaTime());
#endif

⚠ UE5 还有 :5921 PlatformAndInput tick 分支；LevelTick 侧 UE5 RunTickGroup(TG_PrePhysics) 在 :1750，可复用 FWorldDelegates::OnWorldPreActorTick(World.h:4523)

风险评估

原代码风险：委托每帧在 GT 广播，项目回调若阻塞或与加载/渲染线程竞争会拖慢或崩溃；宏无默认监听者时仍有委托开销。

移植风险：UE5 tick 编排已改（TG_PreSlate、Slate tick 拆成 PlatformAndInput/TimeAndWidgets），漏挂广播点会导致特性静默失效。

开发自检

  • 项目监听者在 UE5 仍被调用
  • Profile 并发任务与 Slate tick 重叠确实降 GT 卡顿

结论置信度：medium — UE5 下该并发方案收益需重新实测；是否还需 TG_StartPhysics 时点需确认
