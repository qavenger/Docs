非首次运行限制 PSO 预编译最大耗时（TORCHLIGHT-254075）

3. 代码级实现（开发用）

独立 Agent 审核并修正修正 1 处　提出问题 3 条　其中高风险 1 条

审核意见：分工脉络（读点 :870/:872/:1953、FShaderPipelineCacheTask::TotalPrecompileTasks/TotalPrecompileWallTime 真实存在）正确，但 after 引用了 UE5 不存在的 FShaderPipelineCache 成员，必须补成员或改为经 FShaderPipelineCacheTask::PrecompileContext 取（FShaderPipelineCache 是 FShaderPipelineCacheTask 的 friend）。

完全重构 改动方式：UE5 PSO 预编译子系统已拆成 FShaderPipelineCache/FShaderPipelineCacheTask，MaxPrecompileTime 读取点分散(:870/:872/:1953)，须按新结构重写等价取值逻辑。

代码脉络：新增 CVar r.ShaderPipelineCache.MaxPrecompileTimeNonFirstRun（ShaderPipelineCache.cpp:172）与 FShaderPipelineCache::SetGameTreatAsFirstRun/IsGameTreatAsFirstRun(:631-643)，核心是 GetEffectiveMaxPrecompileTime()(:646)：非首启（!IsPrecompilationSlowTask() && !bGameTreatAsFirstRun）时用 min(MaxPrecompileTime, NonFirstRun) 收紧前台预编译墙钟，首启仍用原值以便建二进制缓存（TORCHLIGHT-254075）。NumPrecompilesRemaining/ReadyForNextBatch 等多处改调该函数。

步骤 1Source/Runtime/RenderCore/Private/ShaderPipelineCache.cppCVarPSOFileCacheMaxPrecompileTime(:170)

新增 NonFirstRun CVar（照搬 UE4 :172-181）

static TAutoConsoleVariable<float> CVarPSOFileCacheMaxPrecompileTime(
	TEXT("r.ShaderPipelineCache.MaxPrecompileTime"), (float)0.f, TEXT("..."), ECVF_Default | ECVF_RenderThreadSafe);
// 需按 UE4 一并给 FShaderPipelineCache 补成员/静态量：
//   FShaderCachePrecompileContext ShaderCachePrecompileContext;
//   static bool bGameTreatAsFirstRun;
float FShaderPipelineCache::GetEffectiveMaxPrecompileTime() const
{
	const float Base = CVarPSOFileCacheMaxPrecompileTime.GetValueOnAnyThread();
	// First-run = UE 自身建 PBC 信号 或 项目注入信号
	if (ShaderCachePrecompileContext.IsPrecompilationSlowTask() || bGameTreatAsFirstRun)
	{
		return Base;
	}
	const float NonFirst = CVarPSOFileCacheMaxPrecompileTimeNonFirstRun.GetValueOnAnyThread();
	if (NonFirst > 0.0f)
	{
		return (Base > 0.0f) ? FMath::Min(Base, NonFirst) : NonFirst;
	}
	return Base;
}

风险评估

原代码风险：仅单一上限，非首启也会长时间前台预编译，遮挡屏/启动时长不可控。

移植风险：NonFirstRun 设错过小会让缓存补不齐，运行期 PSO 编译抖动；首启判定依赖 IsPrecompilationSlowTask，若失效则首启也被收紧。

开发自检

  • 非首启启动墙钟受 NonFirstRun 限制
  • 首启仍完整预编译并建好二进制缓存
  • 运行期无 PSO 编译尖峰

结论置信度：medium — UE5 是否保留了 ShaderCachePrecompileContext 的 available 状态机（:1953 分支上下文）
