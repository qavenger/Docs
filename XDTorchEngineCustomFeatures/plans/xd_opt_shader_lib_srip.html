修改草案 · XD_OPT_SHADER_LIB_SRIP

允许把部分 Shader 剥离到独立 ShaderLib，用于热更（依赖 XDLivePatch 插件）

部分覆盖 保留引擎 需接入点 结构性改动 工作量 L风险 高开发者 Yu Hang主要模块 RenderCore

一句话结论：涉及 Shader 库切分与热更，风险最高，建议独立插件承载

1. UE5 现状与证据

结论依据：UE5 原生具备按 Chunk 切分+热更 patch 库：Runtime/RenderCore/Private/ShaderLibrary/ShaderCodeLibrary.cpp:1829-1884、:2648-2677 CreatePatchLibrary；EditorShaderCodeArchive.cpp:1235-1294；与 XD 的资源级切分粒度不同

覆盖说明：UE5 原生具备按 Chunk 切分/热更 patch 库机制，XD 的资源级切分粒度不同，保留 XDLivePatch 层即可

证据路径（UE5.8.2）行号核对结果
Runtime/RenderCore/Private/ShaderLibrary/ShaderCodeLibrary.cpp1829✅ 已命中：Source/Runtime/RenderCore/Private/ShaderLibrary/ShaderCodeLibrary.cpp
EditorShaderCodeArchive.cpp1235✅ 已命中：Source/Runtime/RenderCore/Private/ShaderLibrary/EditorShaderCodeArchive.cpp

覆盖度：部分覆盖  处置：保留引擎

2. 修改步骤（暂留引擎）

  1. 登记 Feature Card
    记录 owner、影响面、依赖、关闭条件、验证方式与回滚方式；这是当前最高风险的一类（引擎内深度改动）。
  2. 评估替代路径
    优先考虑改用 UE5 原生机制（如 Niagara / Substrate / PSOPrecache / WorldPartition）替代自研实现；替代前保留最小可用补丁。
  3. 设定复查条件
    每个版本复查一次：是否可以降级为插件/配置，或直接删除。
  4. Shader 侧配套
    删除 DerivedDataCache 重编 Shader；同步更新受影响的 shader permutation / ShaderVersion。

3. 代码级实现（开发用）

待独立 Agent 审核该草案尚未进入审核轮次：审核会打开 UE5 源码逐条核对行号、函数与 after 代码 引用的 API 是否存在。

完全重构 改动方式：UE5 的 FSerializedShaderArchive 已重写为资产关联+分块+pach 体系（FShaderMapAssetPaths/FindOrAddShaderMapEditor/CreatePatchLibrary），XD 自建的资产表与 json 流程不能照搬。

代码脉络：def XDBuildOptConfiguration.cs:327。ShaderCodeLibrary.cpp:950-1010 在 FindOrAddShaderMap 前构造 FShaderCodeToAssetsInfo（AssetPaths + code 大小）并参与序列化；ShaderCodeArchive.cpp:48-160 给 archive 加该资产表；CookOnTheFlyServer.cpp:231,8386,9585 在 cook 期缓存/导出资产信息；ShaderCodeLibrary.h:229 的 CreateSubShaderLibraryFromAssetInfoJson 据此从既有库切出子库，配合 IPlatformFilePak.cpp:7414(iOS) 从 patch 库取 shader。

⚠ XD 的 json 资产粒度需插件侧基于 GetShaderMapAssetAssociations()/EditorShaderCodeArchive.cpp:1235-1294 自行生成；宏与全部逻辑一起移出引擎，避免污染 UE5 archive 版本。

风险评估

原代码风险：自建资产表改动 archive 序列化布局，与包体/DDC 版本强耦合，一旦与 cook 顺序不一致会出现 shader 缺库或 pak 内 shader 错配。

移植风险：UE5 archive 增加了分块与 mmap 布局（USE_MMAPPED_SHADERARCHIVE），切库工具的偏移/校验逻辑必须重写；改动面覆盖 cook、打包、热更、加载四段，回归成本最高。

开发自检

  • 增量 cook 后用 CreatePatchLibrary 产出 patch 库，旧包+patch 可正常启动
  • iOS/IoStore 下从 patch 库加载 shader 无 miss，stat shaders 无回落

结论置信度：medium — UE5 的 FShaderMapAssetPaths 具体类型与 XD json 字段的一一映射需人工核对（本次未逐字段比对）。
