修改草案 · XD_REPORT_ALL_REQUEST_EXIT_EVENT_AS_ERROR

RequestExit(force=1) 时上报更完整的崩溃/退出信息

部分覆盖 接入点 需接入点 仅加接入点 工作量 M风险 中开发者 Wang Xiao Bo主要模块 Core

一句话结论：利用 RequestExit 原因参数，flush 逻辑少量补丁

1. UE5 现状与证据

结论依据：UE5 FPlatformMisc::RequestExit(bool,const TCHAR*) 带原因；多处 RequestExit(true,...)（如 WindowsErrorOutputDevice.cpp:90）

覆盖说明：有原因字符串但无统一 flush 上报

证据路径（UE5.8.2）行号核对结果
WindowsErrorOutputDevice.cpp90✅ 已命中：Source/Runtime/Core/Private/Windows/WindowsErrorOutputDevice.cpp

覆盖度：部分覆盖  处置：接入点

2. 修改步骤（接入点）

  1. 引擎侧只加接入点
    需要的接入点：FPlatformMisc::RequestExit 原因参数（机制：Delegate）。引擎改动应最小、稳定、无业务语义。
  2. 插件侧实现完整逻辑
    退出原因上报可项目侧订阅；日志 flush 入口须引擎
  3. 无插件时的行为
    未绑定接入点时应回退到官方默认行为（引擎侧不能假设插件存在）。

3. 代码级实现（开发用）

独立 Agent 审核通过

审核意见：核实: UE4 声明 GenericPlatformMisc.h:452、实现 cpp:315（GLog SetCurrentThreadAsMasterThread+Flush / GWarn Flush / GError Flush+HandleError），调用点 D3D11Util.cpp:249-251 等（输入包引用=13 与 draft '13 处'一致）；UE5 RequestExitWithStatus 在 WindowsPlatformMisc.cpp:1474，if(Force) 内已有 GLog->Flush（约 :1499-1502），FOutputDeviceErr

改接口/改名 改动方式：UE5 保留 RequestExit(bool,const TCHAR* CallSite)，RequestExitWithStatus(Force,..) 已内建 GLog->Flush，只需补 GWarn/GError。

代码脉络：GenericPlatformMisc.h:451 声明 FlushAllLogsBeforeForceExit、cpp:315 实现(GLog SetCurrentThreadAsMasterThread+Flush、GWarn Flush、GError Flush+HandleError)；各 RHI/平台在 RequestExit(true) 前调用(D3D11Util.cpp:249、WindowsDynamicRHI.cpp:245 等共 13 处)。

步骤 1Runtime/Core/Private/Windows/WindowsPlatformMisc.cppUE5 WindowsPlatformMisc.cpp:1474 RequestExitWithStatus

在 UE5 强制退出分支的 GLog->Flush() 后补 GWarn/GError 处理

if (GLog){ GLog->SetCurrentThreadAsMasterThread(); GLog->Flush(); }
if (GWarn) GWarn->Flush();
if (GError){ GError->Flush(); GError->HandleError(); }
// UE5 RequestExitWithStatus 的 if(Force) 分支:
if (GWarn) GWarn->Flush();
if (GError){ GError->Flush(); GError->HandleError(); }

⚠ UE5 已含 GLog->Flush()，勿重复

步骤 2Runtime/Windows/D3D11RHI/Private/D3D11Util.cppD3D11Util.cpp:249

把 13 处 FlushAllLogsBeforeForceExit 调用改为 RequestExitWithStatus 并传原因串

#if XD_REPORT_ALL_REQUEST_EXIT_EVENT_AS_ERROR
FPlatformMisc::FlushAllLogsBeforeForceExit();
#endif
FPlatformMisc::RequestExit(true);
FPlatformMisc::RequestExitWithStatus(true, 3, TEXT("D3DDeviceLost"));

⚠ 调用点分散在 D3D11/D3D12/Metal/Android，逐个核对

风险评估

原代码风险：崩溃/设备丢失路径调 GError->HandleError() 可能重入崩溃处理，非交互环境会卡住。

移植风险：13 处调用点需逐个核对，并能保持 RequestExitWithStatus 返回码语义一致。

开发自检

  • 强制 RequestExit(true) 场景日志含 Warning/Error 完整落盘
  • 确认崩溃路径不因 HandleError 死锁

结论置信度：medium — UE5 是否要求统一改走 RequestExitWithStatus 而非 RequestExit 待人工确认。
