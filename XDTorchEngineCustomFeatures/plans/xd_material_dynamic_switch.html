修改草案 · XD_MATERIAL_DYNAMIC_SWITCH

材质 Selector Switch（多选一静态开关组）支持动态切换与编辑器参数复制

未覆盖 移植 引擎内实现 深度侵入 工作量 L风险 高开发者 Yu Hang主要模块 Engine

一句话结论：高风险项：改变材质序列化与 shader key，迁移后需全量重编 shader 与 DDC/材质校验

背景：新增 UDEditorStaticSelectorSwitchParameterValue 等类型，编辑器侧支持 Selector 开关的参数复制/覆盖，运行时按选择结果走不同分支；用于用少量材质覆盖多套外观，减少材质数量与 Shader 变体。

1. UE5 现状与证据

结论依据：E:/TorchLight_UE5/Engine/Engine/Source/Runtime/Engine/Public/StaticParameterSet.h（FStaticSwitchParameter 无 SelectorValue/SelectorBits；无 Selector Switch 概念）

覆盖说明：UE5 静态参数集无多选一 Selector 语义

证据路径（UE5.8.2）行号核对结果
TorchLight_UE5/Engine/Engine/Source/Runtime/Engine/Public/StaticParameterSet.h—✅ 已命中：Source/Runtime/Engine/Public/StaticParameterSet.h

覆盖度：未覆盖  处置：移植

2. 修改步骤（移植）

  1. 定位 UE5 对应文件
    见下方「UE5 对应文件」；重点比对同文件在 UE4/UE5 的差异。
  2. 移植实现
    原实现位置：Source/Editor/MaterialEditor/Private/MaterialEditorInstanceDetailCustomization.cpp、Source/Editor/MaterialEditor/Private/MaterialPropertyHelpers.cpp、Source/Editor/UnrealEd/Classes/MaterialEditor/DEditorStaticSwitchParameterValue.h、Source/Editor/UnrealEd/Private/EditorParameters.cpp、Source/Editor/UnrealEd/Private/PlayLevel.cpp、Source/Editor/UnrealEd/Private/PreviewMaterial.cpp、Source/Runtime/Engine/Classes/Materials/Material.h、Source/Runtime/Engine/Classes/Materials/MaterialExpressionStaticSwitchParameter.h。如涉及 Shader，需同步改 shader define 或共享 include。
  3. 适配 UE5 接口与规范
    注意 C++20、UHT（反射）规则、bValidateCircularDependencies 默认开启等差异；必要时回归 DDC/Cook。
  4. Shader 侧配套
    删除 DerivedDataCache 重编 Shader；同步更新受影响的 shader permutation / ShaderVersion。

3. 代码级实现（开发用）

独立 Agent 审核通过提出问题 2 条

审核意见：refactor 判断正确：UE5 FStaticSwitchParameter 已改 UpdateHash(FXxHash64Builder&)（StaticParameterSet.h:127，旧 SHA1 重载 :204 标 UE_DEPRECATED(5.8)），值体系走 FMaterialParameterMetadata，after 引用的 GetStaticBoolValue(:515)/DynamicBranch(:329)/FProxyMaterialCompiler(:1095)/MaterialInterface.cpp:547/MaterialExpressions.c

完全重构 改动方式：FStaticSwitchParameter 与材质参数取值体系在 UE5 已重构，且编译接口改名为 DynamicBranch/Switch，需按新结构重建。

代码脉络：核心是给 FStaticSwitchParameter 加 SelectorValue/SelectorBits 并纳入序列化/hash（StaticParameterSet.h:115-170、MaterialInstance.cpp:52-108），编辑器/编译侧新增 UMaterialExpressionDynamicSwitchParameter 与 StaticSelectorSwitchParameter（MaterialExpressions.cpp:8048/8104），配合 FMaterialCompiler 的 GetStaticSwitchParameterValue/DynamicSwitchBranch(第 227/231 行) 与 MaterialStaticParameterValueResolver.h:163 取值。UE5 同名类型仍在但结构已变（UpdateHash 换 FXxHash64Builder、StaticParameterSet 拆 Runtime/EditorOnly、参数取值改走 FMaterialParameterMetadata），必须重写。

步骤 1Runtime/Engine/Public/StaticParameterSet.hUE5 :90-135 FStaticSwitchParameter

补字段与 hash/key

UPROPERTY() uint8 SelectorValue {0};
UPROPERTY() uint8 SelectorBits {0};
void UpdateHash(FSHA1& HashState) const { HashState.Update(&SelectorValue, sizeof(SelectorValue)); ... }
UPROPERTY() uint8 SelectorValue = 0;
UPROPERTY() uint8 SelectorBits = 0;
// 签名已变：FSHA1 -> FXxHash64Builder
void UpdateHash(FXxHash64Builder& HashState) const { FStaticParameterBase::UpdateHash(HashState); uint8 V = Value; HashState.Update(&V, sizeof(V)); HashState.Update(&SelectorValue, sizeof(SelectorValue)); HashState.Update(&SelectorBits, sizeof(SelectorBits)); }

⚠ AppendKeyString/Append 在 UE5 是引擎外置实现（:134-135，实现在 StaticParameterSet.cpp），要同步改；FStaticSwitchParameterValue 类型可原样加在 :139 后。

步骤 2Runtime/Engine/Private/Materials/MaterialExpressions.cppUE5 :8669 UMaterialExpressionStaticSwitchParameter::Compile、MaterialCompiler.h:329

重建 selector 编译与取值入口

FStaticSwitchParameterValue SwitchValue = Compiler->GetStaticSwitchParameterValue(ParameterName, bFound);
return Compiler->DynamicSwitchSelector(MacroName, Value, SelectorNodes);
// MaterialCompiler.h:515 GetStaticBoolValue 旁新增：
virtual FStaticSwitchParameterValue GetStaticSwitchParameterValue(FName ParameterName, bool& bSucceeded) = 0;
virtual int32 DynamicSwitchSelector(const FString& DefName, int32 Condition, TArray<int32> SelectorNodes) = 0;
// 值来源改用 UE5 元数据：MaterialInterface.cpp:547 UMaterialInterface::GetStaticSwitchParameterValue(FHashedMaterialParameterInfo(ParameterName), bOut, OutGuid)
// 二元分支可直接复用现成的 DynamicBranch(cond,A,B)（MaterialCompiler.h:329）

⚠ FProxyMaterialCompiler 等转发类（MaterialCompiler.h:1095 附近）每处都要加；UE5 已内置 bDynamicSwitchParameter（MaterialParameters.h:496、MaterialCachedData.h:346），二元动态开关可不再自研。

风险评估

原代码风险：改的是 shader static parameter 的序列化格式与 hash，容易造成新旧包/DDC 冲突；MaterialInstance.cpp:52 手写 4 字节打包（B=7 魔数）可读性差且越界只 check。

移植风险：波及 138 个文件、材质序列化与全部 shader key，迁移后必须全量重编 shader、清 DDC 并做材质校验；UI/编辑器侧 DEditorStaticSwitchParameterValue 也要跟着改。

开发自检

  • 旧材质二进制能按新字段读回（无 version 变更时值不丢）
  • 同参数在 MaterialInstance 与 Material 中 hash/KeyString 一致
  • 全部材质重编后 shader perm 数量与预期相符

结论置信度：medium — 是否需要保持与 UE4 XD 包二进制兼容（SelectorBits 打包格式）需引擎组决定；编辑器侧类清单未逐一核对。
