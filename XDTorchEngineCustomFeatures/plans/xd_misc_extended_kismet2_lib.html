3. 代码级实现（开发用）

待独立 Agent 审核该草案尚未进入审核轮次：审核会打开 UE5 源码逐条核对行号、函数与 after 代码 引用的 API 是否存在。

简单移植 改动方式：UE5 里 FKismetEditorUtilities、CreateBlueprintFromActors_Internal(Kismet2.cpp:1671) 与 FBlueprintAssemblyProps/RepositionNodes 结构一致，XD 版本可原样重贴。

代码脉络：声明在 KismetEditorUtilities.h:389-527（CreateBlueprintAtWorldCenter*/HarvestBlueprintAtWorldCenter*），实现在 Kismet2.cpp:1065、1770、2050、2187、2270；核心是 Kismet2.cpp:1771 的 CreateBlueprintAtWorldCenterFromActorsAndKeepRelativePosition_Internal，把平均位置改为 FVector::ZeroVector 并重排顶层节点。

步骤 2Source/Editor/UnrealEd/Private/Kismet2/Kismet2.cppUE4 Kismet2.cpp:1771-1830；UE5 :1671-1748（CreateBlueprintFromActors_Internal）

复制 UE5 :1671 内部函数为 _Internal 版本，仅把平均位置改成世界原点

// UE5 Kismet2.cpp:1716-1734（原平均位置逻辑）
FVector AverageLocation = FVector::ZeroVector;
for (const AActor* Actor : RootActors) { AverageLocation += Actor->GetActorLocation(); }
AverageLocation /= (float)RootActors.Num();
NewActorTransform.SetTranslation(AverageLocation);
// XD _Internal（其余行与 UE5 :1671-1748 逐行相同）
FVector WorldCenterLocation = FVector::ZeroVector;
NewActorTransform.SetTranslation(WorldCenterLocation);
// 另有 msc 版本：WorldCenterLocation 由 FVector::ZeroVector 保持，重排 SCS->GetRootNodes()

⚠ UE5 grep 无 CreateBlueprintAtWorldCenter* 符号，必须重贴；轻量替代仅适用于非 Harvest 路径：用 FAddActorsToBlueprintParams::RelativeToTransform(Identity)（UE5 KismetEditorUtilities.h:254 / Kismet2.cpp:1979-1986）也能得到原点枢轴，但 UE5 :1898 CreateBlueprintFromActors 只传 RelativeToInstance，Harvest 路径无此参数。

风险评估

原代码风险：复制基类内部实现会与上游演进脱节；对多根 actor 直接置零会改变 ComponentTemplate 相对变换语义。

移植风险：影响编辑器『从选中 actor 聚合蓝图』的放置位置与相对坐标，需回归所有聚合/采集蓝图功能及 RootActor 分支。

开发自检

  • 多选 actor 聚合蓝图后根节点在 (0,0,0) 且相对位置保持
  • Harvest 版本同样验证，单根 actor 路径行为不变

结论置信度：medium — UE5 :1898 的非 RootActor 分支还需确认是否也要同步改为原点枢轴；_Internal 复制体在 UE5.8 是否有额外新增语句（如 FAssetRegistryModule 通知顺序）需逐行比对。
