控件忽略长按手势事件（避免丢失焦点）

未覆盖 插件化 可工程化 仅加接入点 工作量 S风险 低开发者 Ran Qing Sen主要模块 Slate

一句话结论：做成项目级控件基类即可。

1. UE5 现状与证据

结论依据：UE5 SlateCore/Slate 无控件级“忽略长按”开关（grep LongPress 仅见 GestureDetector::LongPressSeconds/LongPressAllowedMovement 全局参数与 EKeys::Gesture_LongPress）

覆盖说明：未上游

覆盖度：未覆盖  处置：插件化

2. 修改步骤（插件化）

  1. 确定插件/模块归属
    项目插件派生 SButton/UButton（覆写 OnTouchStarted/OnTouchGesture）或统一开关控件
  2. 实现主体逻辑
    把原引擎内实现迁到插件：Source/Runtime/Engine/Private/Slate/SceneViewport.cpp、Source/Runtime/Slate/Private/Framework/Application/SlateApplication.cpp、Source/Runtime/Slate/Private/Widgets/Input/SButton.cpp、Source/Runtime/Slate/Public/Widgets/Input/SButton.h、Source/Runtime/SlateCore/Private/Widgets/SWidget.cpp、Source/Runtime/SlateCore/Public/Input/Events.h、Source/Runtime/SlateCore/Public/Widgets/SWidget.h、Source/Runtime/UMG/Private/Components/Button.cpp。引擎侧只保留必要接口/事件。
  3. 模块与构建规则
    Editor 工具放 Editor 模块（Shipping 自动剔除）；运行时逻辑放 Runtime 模块；如需引擎接口，见「引擎改动」列。
