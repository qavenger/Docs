修改草案 · XD_RENDERING_NATIVESTENCIL_SUPPORT_MATERIAL

材质支持 NativeStencil：材质可自定义模板测试与写入

部分覆盖 移植 引擎内实现 结构性改动 工作量 L风险 高开发者 Liu Xing Kui主要模块 Engine

一句话结论：XD 全材质 NativeStencil（自定义测试/写入）远超 UE5 PP-only，需完整移植

背景：在预深度 Pass 中按材质设置 stencil 比较/参考值/读写掩码，用于角色描边、遮挡、UI 遮罩等效果；PC Deferred 路径由 XD_PC_RENDERING_NATIVESTENCIL_SUPPORT_MATERIAL 扩展。

1. UE5 现状与证据

结论依据：UE5 仅 MD_PostProcess 支持 stencil test：MaterialShared.h:2566/3375 IsStencilTestEnabled、Materials/Material.h:1169 bEnableStencilTest、StencilRefValue；不透明/半透明材质无自定义 stencil

覆盖说明：UE5 有 PP-only stencil test，非全材质 NativeStencil

证据路径（UE5.8.2）行号核对结果
MaterialShared.h2566✅ 已命中：Source/Runtime/Engine/Public/MaterialShared.h
Materials/Material.h1169✅ 已命中：Plugins/Enterprise/MDLImporter/Source/MDLImporter/Private/mdl/Material.h

覆盖度：部分覆盖  处置：移植

  1. 定位 UE5 对应文件

3. 代码级实现（开发用）

待独立 Agent 审核该草案尚未进入审核轮次：审核会打开 UE5 源码逐条核对行号、函数与 after 代码 引用的 API 是否存在。

完全重构 改动方式：UE5 仅有 MD_PostProcess 的 stencil test（MaterialShared.h:2566-2568、:3375-3377），不透明/半透明材质无自定义 stencil，需按新材质与 pass 结构重建整套 schema + 渲染状态。

代码脉络：定义 XDBuildRenderingConfiguration.cs:77；UE4 在 EngineTypes.h:252-268 定义 EStencilCompareOpMode，Material.h:404-410/1223-1226 与 MaterialInstance.h:366-369/615-618 加 StencilTestMode/StencilValue，MaterialInstanceBasePropertyOverrides.h:87-105 加 override 字段，MaterialShared.h:1683-1686/2610-2613 加 GetStencilTestMode/GetStencilValue/FitMobileStencilValueForPC。渲染侧 MobileBasePass.cpp:627-629/714-717 与 BasePassRendering/DepthRendering 设状态，MaterialInterface.cpp:303-305 把结果写入 MaterialRelevance::bIsOpenStencilWrite。

风险评估

原代码风险：自定义 stencil 与 UE5/UE4 内建用途（RECEIVE_DECAL、CAST_SHADOW、RAY_TRACING_REPRESENTATION、VSM、DBuffer）共用同一 depth-stencil 附件，位分配冲突会导致内建 pass 误剔除。

移植风险：53 个文件量级：材质 schema（UPROPERTY 序列化）、着色器映射（MaterialShared/MaterialInstance 的 shader map diff）、渲染状态、编辑器详情面板（MaterialEditorInstanceDetailCustomization）与烘焙工具（MaterialUtilities）全部要跟；漏改编辑器会导致材质保存丢字段。

开发自检

  • 材质编辑器可设 StencilTestMode/StencilValue 并保存后重开不变
  • PreDepth/BasePass/半透明三处 stencil op 与参考值符合设计
  • 宏=0 时 UE5 原生后处理 stencil（Material.h bEnableStencilTest）不受影响

结论置信度：medium — UE5.8 的 EStencilCompareOpMode 命名与取值需与 XD 侧美术/工具链一致；pp-stencil 与材质 stencil 是否会争用 ref value 需人工确认。
