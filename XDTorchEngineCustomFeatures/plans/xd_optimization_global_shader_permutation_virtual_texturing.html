1. UE5 现状与证据

结论依据：Runtime/Engine/Private/ShaderCompiler/ShaderGenerationUtil.cpp:214 IS_VIRTUAL_TEXTURE_MATERIAL define；无 r.SupportVirtualTexturing 开关

覆盖说明：有 VT 变体标记但无项目级裁剪 CVar

证据路径（UE5.8.2）行号核对结果

2. 修改步骤（配置化）

  1. 确定配置承载
    项目侧 ShouldCompilePermutation / 关闭 VT 项目设置
  2. 设定默认值与灰度
    默认值应与当前线上行为一致；通过 ini/DeviceProfile 按平台/机型灰度，可随时回滚。
  3. 清理宏
    删除 UE4 宏与 Source/Runtime/RenderCore/Public/VirtualTexturing.h、Source/Runtime/Renderer/Private/VT/RuntimeVirtualTextureRender.cpp、Source/Runtime/Renderer/Private/VT/VirtualTextureSpace.cpp 中的编译期分支，改为读取配置。

3. 代码级实现（开发用）

独立 Agent 审核并修正修正 2 处　提出问题 2 条　其中高风险 2 条

审核意见：api-adapt 方向正确，但两个 after 都无法直接使用：一个是不存在的 API，一个是不存在的插入点，必须换 UseVirtualTexturing 并说明 UE5 已删除这些 ShaderType 的 ShouldCompilePermutation。

改接口/改名 改动方式：UE5 VirtualTexturing.h 已无 ShouldCompileVTPermutation，改由平台信息/材质标志判定，需改调用点。

代码脉络：开宏后 RenderCore/Public/VirtualTexturing.h:15 定义 ShouldCompileVTPermutation() 读 CVar r.VirtualTextures，在 VT/VirtualTextureSpace.cpp:180/207 与 RuntimeVirtualTextureRender.cpp:577/675 的 ShouldCompilePermutation 中使用，关闭 VT 时不生成相关全局变体。

步骤 1Runtime/RenderCore/Public/VirtualTexturing.hUE4 :15 ShouldCompileVTPermutation

#if XD_OPTIMIZATION_GLOBAL_SHADER_PERMUTATION_VIRTUAL_TEXTURING
static bool ShouldCompileVTPermutation()
{ static const auto CVarVirtualTexturesEnabled = IConsoleManager::Get().FindTConsoleVariableDataInt(TEXT("r.VirtualTextures")); ... }
#endif
// UE5 VirtualTexturing.h 已无 ShouldCompileVTPermutation（grep 无）；改用 Runtime/RenderCore/Public/RenderUtils.h:420
// RENDERCORE_API bool UseVirtualTexturing(const FStaticShaderPlatform InShaderPlatform);  // 内部读 r.VirtualTextures

⚠ UE5 VirtualTexturing.h grep 无该 helper，确认已删。

步骤 2Runtime/Renderer/Private/VT/VirtualTextureSpace.cppUE4 :180/:207

在各 ShaderType::ShouldCompilePermutation 改用新判据

#if XD_OPTIMIZATION_GLOBAL_SHADER_PERMUTATION_VIRTUAL_TEXTURING
    return ShouldCompileVTPermutation();
#endif
// UE5 VT/VirtualTextureSpace.cpp 的 ShaderType 已无 ShouldCompilePermutation；如需按 VT 开关裁剪须自行新增：
static bool ShouldCompilePermutation(const FGlobalShaderPermutationParameters& Parameters)
{
    return UseVirtualTexturing(Parameters.Platform);
}

⚠ RuntimeVirtualTextureRender.cpp:577/675 同样处理。

风险评估

原代码风险：运行时 CVar 与编译期变体可能不一致；关 VT 后仍有资源引用会缺变体。

移植风险：UE5 VT ShaderType 布局与判定来源(平台信息 vs r.VirtualTextures)需对齐，误裁会黑纹理。

开发自检

  • 关 VT 时打包无 VT 变体
  • 开 VT 时 RVT/流送正常

结论置信度：medium — UE5 中 r.VirtualTextures 是否仍为权威开关需确认。
