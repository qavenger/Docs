风险评估

原代码风险：0 字节分配在 Binned/Mimalloc 上可能落到非法 pool 或断言，属定位内存问题的临时绕过；补丁散落 7 个平台私有文件易与上游冲突。

移植风险：无运行时风险；漏删某分配器也不崩（UE5 已自防），但建议连同 UBT 定义一起清掉避免宏悬空。

开发自检

  • grep XD_TMP_FIX_MALLOC_ZERO_ISSUE 在 UE5 全库为 0 处
  • FMemory::Malloc(0) 与 Realloc(p,0) 在 binned2/binned3/ansi/mimalloc 下不崩

结论置信度：high — UE5 Windows 默认走 mimalloc（WindowsPlatformMemory.cpp:154 MIMALLOC_ENABLED），其 0 字节返回行为建议实测确认。
