Stage 01 · world → voxel

连续坐标，先归一化，再离散化

不要直接把 world position 乘分辨率。必须先减去 volumeMin，再除以 volumeExtent；域外点要拒绝，不能 clamp 回边界。

实验 1A · 移动世界坐标2D XZ SLICE
白点是连续世界位置；高亮格是整数 cell。把点拖到 ±1 外，观察结果从索引变成“域外拒绝”。
① 减去 volumeMin把任意世界 AABB 的左下角移到原点。
② 除以 extent得到 0..1 的无量纲坐标 uvw。
③ 乘 N 并 floor得到整数 cell；最大边界采用半开区间 [min,max)。
④ 域外直接返回 nullclamp 会把域外几何粘到边墙，制造假遮挡。

把 2 米宽的盒子切成 16 份，每格宽 0.125 米。世界 x=0.28 距离左边界 -1 共 1.28 米，所以它大约在第 10 格。

uvw = (p − volumeMin) / (volumeMax − volumeMin)
cell = floor(uvw × N)
uvw.x = (0.28 − (−1)) / 2 = 0.64
cell.x = floor(0.64 × 16) = 10
如果 p 不在半开区间 [min,max)，返回“域外”
uvw = (p - min) / (max - min)
返回 floor(uvw * resolution)

function worldToVoxel(position, resolution) {
  const uvw = position.map((value, axis) =>
    (value - VOXEL_SPEC.min[axis]) /
    (VOXEL_SPEC.max[axis] - VOXEL_SPEC.min[axis])
  );

  const outside = uvw.some((value) => value < 0 || value >= 1);
  if (outside) return null;

  return uvw.map((value) => Math.floor(value * resolution));
}

function dominantAxis(normal) {
  const magnitude = normal.map(Math.abs);
  let axis = 0;

  if (magnitude[1] > magnitude[axis]) axis = 1;
  if (magnitude[2] > magnitude[axis]) axis = 2;

  return axis;
}
生产实现提醒：主轴投影不等于 conservative rasterization。D3D12 的 Conservative Rasterization、Vulkan 的 VK_EXT_conservative_rasterization 有明确覆盖与 overestimation 规则；本实验只在 CPU 上用“角点、顶点、边相交”判断 2D triangle-cell overlap。
Stage 05 · attribute merge

一个 cell 收到多个 surface，不能靠最后写入者

occupancy 可以用 OR 合并；normal、albedo、radiance 却需要可解释的策略。这里把三次并发候选写入画出来。

实验 4 · 三个候选如何合并DETERMINISTIC CPU MODEL
“最后写入者”会随并发顺序闪烁；平均更稳定但会把不相关表面混在一起；最近表面保方向，却可能丢掉另一层。
occupancy位 OR 或原子计数，回答“是否有表面”。
normal先加权求和，最后 normalize；相反法线可能抵消。
albedo / opacity可加权平均或 fragment list；策略必须与薄片/透明政策一致。
radiance不要在未知竞争顺序下直接覆盖；常见做法是原子打包、独立注入 pass 或唯一 writer。

把每个候选看作一票，opacity 是票重。颜色可以加权平均；法线先平均向量再归一化，否则长度不再是 1。

attribute = Σ(wᵢ × attributeᵢ) / Σwᵢ
normal = normalize(Σ(wᵢ × normalᵢ))
red=0.8, blue=0.6 → R=(0.8×1+0.6×0.1)/1.4=0.614
累计 每个候选颜色 × opacity
累计 opacity
颜色除以 opacity 总和
法线向量加权后重新归一化

function mergeAttributes(candidates, mode) {
  if (mode === "last") return candidates.at(-1);

  if (mode === "nearest") {
    return candidates.reduce((best, item) =>
      item.distance < best.distance ? item : best
    );
  }

  const weight = candidates.reduce(
    (sum, item) => sum + item.opacity,
    0
  );
  const color = [0, 1, 2].map((channel) =>
    candidates.reduce(
      (sum, item) => sum + item.color[channel] * item.opacity,
      0
    ) / weight
  );

  return { color, opacity: Math.min(1, weight) };
}

每个表面 voxel 像一个很小的漫反射贴片。先算它面向光多少，再乘颜色与光强。Level 0 存“这个贴片当前向外发出的近似 radiance”。

NdotL = max(dot(normal, toLight), 0)
outgoing = albedo × (ambient + irradiance × NdotL / π)
stored.rgb = outgoing × opacity
normal=(0,1,0), toLight=(0.45,0.82,-0.35) normalized
NdotL≈0.82；灰地板得到比背墙更高的当前 radiance
对每个 occupied voxel：
  求表面指向光的方向
  点光源额外计算 1 / distance² 衰减
  计算 max(normal · toLight, 0)
  写入 outgoingRadiance × opacity 与 opacity

function injectRadiance(surface, light) {
  const sample = evaluateLight(surface.position, light);
  const nDotL = Math.max(0, dot(surface.normal, sample.toLight));
  const scale = 0.045 + sample.strength * nDotL / Math.PI;
  const outgoing = surface.albedo.map(
    (channel) => channel * scale
  );

  return {
    rgb: outgoing.map((channel) => channel * surface.opacity),
    opacity: surface.opacity,
    nDotL
  };
}
Level 0 还不是 Voxel GI：它只是一份空间数据。下一课会建立 3D mip，并用 cone 读取它；若只有 occupancy 没有 radiance，cone 只能做遮挡，不能返回间接光。
