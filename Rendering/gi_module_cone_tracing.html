Stage 01 · footprint and LOD

距离越远，一个样本要代表越大的圆盘

二维画布是 cone 的轴向截面。紫色竖线在三维中是垂直于 trace direction 的圆盘直径。

实验 1 · 只改距离与张角2D AXIAL SLICE
保持距离，增大张角；再保持张角，增大距离。两种操作都会提高 footprint 和 LOD。
① 先求 diameter张角是完整锥角，公式里使用 halfAperture。
② 除以 voxelSize得到 footprint 跨越多少个 Level-0 cells。
③ 取 log₂跨 1 格→LOD0，2 格→LOD1，4 格→LOD2。
④ 不要立刻 round保留小数 LOD，之后在相邻 mip 层间插值。

把 cone 想成手电筒光束：离灯越远，光斑越大。粗 mip 是“提前把大光斑覆盖的许多小格平均好”，因此一次读取可近似宽查询。

diameter = 2 × distance × tan(aperture / 2)
lod = log₂(max(diameter / voxelSize, 1))
distance=0.58, aperture=34°, voxelSize=0.125
diameter≈0.354，跨 2.83 格，lod≈1.50
半角 = 完整张角的一半
直径 = 2 × 距离 × tan(半角)
至少按一个 voxel 宽度采样
LOD = log2(直径 / voxelSize)

function coneFootprint(distance, aperture, voxelSize) {
  const halfAperture = aperture * 0.5;
  const diameter = Math.max(
    voxelSize,
    2 * distance * Math.tan(halfAperture)
  );
  const lod = Math.log2(diameter / voxelSize);

  return { diameter, lod };
}
Stage 02 · within-level + between-level

一次“小数 LOD 采样”其实有两层插值

先在每个 3D mip 内对 8 个邻居做 trilinear，再在 floor(lod) 与 ceil(lod) 之间做线性插值。漏掉第二层会出现 mip 跳变。

实验 2 · 8 邻居三线性TRILINEAR
点越靠近某个角，该角权重越大。八个权重之和应为 1。
实验 3 · Mip 层间插值LOD BLEND
LOD=1.45 表示先分别读取 Level 1 和 Level 2，再用 0.45 混合，而不是直接四舍五入。

三线性就是先沿 X 混 4 对，再沿 Y 混 2 对，最后沿 Z 混 1 对。层间插值把“刚好跨进下一层”的突变也抹平。

w(x,y,z)=(x?fx:1−fx)(y?fy:1−fy)(z?fz:1−fz)
L=lerp(sample(level₀), sample(level₁), frac(lod))
lod=1.45 → l₀=1, l₁=2, t=0.45
sample = 0.55×Level1 + 0.45×Level2
A = 在 floor(LOD) 层做 8 邻居三线性
B = 在 ceil(LOD) 层做 8 邻居三线性
结果 = lerp(A, B, LOD 的小数部分)

function sampleMipChain(position, lod, mips) {
  const maximum = mips.length - 1;
  const clamped = clamp(lod, 0, maximum);
  const level0 = Math.floor(clamped);
  const level1 = Math.min(level0 + 1, maximum);
  const fraction = clamped - level0;
  const a = sampleTrilinear(mips[level0], position);
  const b = sampleTrilinear(mips[level1], position);

  return a.map((value, channel) =>
    mix(value, b[channel], fraction)
  );
}

从 receiver 沿 cone direction 前进：
  由距离和张角得到 footprint 与 LOD
  读取 3D mip chain
  用 remaining transparency 累计 premultiplied RGB 与 opacity
  步长随 footprint 增长
  opacity 接近 1 或走出 volume 时停止

function traceCone(origin, direction, aperture, stepFactor, forceLevel0) {
  const color = [0, 0, 0];
  let opacity = 0;
  let distance = FIELD.cellSize * 0.8;
  const samples = [];

  while (samples.length < 64 && distance < 2.6 && opacity < 0.98) {
    const footprint = coneFootprint(
      distance,
      aperture,
      FIELD.cellSize
    );
    const position = origin.map(
      (value, axis) => value + direction[axis] * distance
    );
    if (position.some((value) => value < -1 || value >= 1)) break;

    const lod = forceLevel0 ? 0 : footprint.lod;
    const sample = sampleMipChain(position, lod, MIPS);
    const remaining = 1 - opacity;
    for (let channel = 0; channel < 3; channel += 1) {
      color[channel] += remaining * sample[channel];
    }
    opacity += remaining * sample[3];
    samples.push({
      position,
      distance,
      sample,
      remaining,
      ...footprint,
      lod
    });
    distance += Math.max(FIELD.cellSize * 0.6, footprint.diameter * stepFactor);
  }
  return { color, opacity, samples };
}

一个 cone 只是调试单位，不是完整 GI

漫反射通常用多个宽 cone 覆盖半球；镜面 cone 围绕反射方向，roughness 越高张角越大。下面两个独立 Demo 只解释采样布局。

Stage 06 · known failure

各向同性 mip 为什么把墙两侧混在一起

粗 mip 只有一个 RGB/opacity，不知道能量来自哪个方向。一个粗 texel 同时覆盖亮室和暗室时，cone 从暗侧读取也可能得到亮色。

实验 6 · Isotropic leakage A/BERROR EXPLAINER
B 是方向分桶的教学示意，不是本页数据的实际 anisotropic volume。常见缓解还包括加厚 occupancy、提高分辨率、缩小 cone、边界权重和六方向 mip。
根因粗 cell 跨过薄墙，同时平均亮侧 radiance 与暗侧数据。
最直接的证据固定 trace，只切换 LOD0 与 mip；漏光随粗 LOD 加强。
方向相关存储按 ±X/±Y/±Z 或更细方向存 radiance，查询时选朝向相符的 lobe。
仍然不是精确 raycone 是宽查询近似；墙厚、分辨率与 filtering policy 仍决定质量。
性能/质量边界：每个像素 5–9 个 diffuse cones，再加 specular cone，会产生大量 3D texture 带宽。动态几何要重建 occupancy/attributes，动态灯要重注入 radiance 与更新 mip；它能在当前帧响应，但不等于“免费”。
