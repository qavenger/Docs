# GSR 对比页 · 按文件夹分档

```
GSR_Compare/
├─ index.html            ← 唯一的页面：顶部 Tab 切档位（双击这个）
├─ tiers.js              ← 自动生成的档位列表（Tab 名 = 子文件夹名，勿手改）
├─ 扫描图片.bat           ← 扫各档 src 下的 png，生成 src/files.js 与 tiers.js，并打开页面
├─ scan-shots.ps1        ← 上面那个 bat 用的脚本
├─ <档位名>/              ← 文件夹名就是 Tab 名，新建/删除文件夹即可增删 Tab
│  ├─ config.js           ← 机型 / 配色 / 左右默认图（可选，缺了会自动补占位）
│  └─ src/
│     ├─ files.js         ← 自动生成的图片清单（勿手改）
│     └─ *.png            ← 截图，按命名规则丢进来即可
└─ README.md
```

> 档位文件夹里**不需要** index.html：根目录那一个页面会按 Tab 去加载 `<档位名>/config.js` 和 `<档位名>/src/files.js`。

## 日常流程（只需两步）

1. 把截图按命名规则丢进对应档位的 `src/`
2. 双击根目录 **`扫描图片.bat`**（生成各档 `src/files.js` 和根目录 `tiers.js`，并自动打开对比页）

页面启动时读 `src/files.js` 得到图片清单，再按文件名解析出「输出 / 渲染 / GSR」，
并自动排序：默认 → 输出升序 → 渲染升序 → GSR Off 在前。

> 浏览器直接打开本地 html 时无法列目录，所以清单由这个 bat（PowerShell 扫描）生成。
> 加图/删图/改名后重新跑一次即可，其它都不用改。

## 文件名规则（通用识别）

| 文件名 | 识别结果 |
|---|---|
| `1080p.png` | 真机设置：输出 1080 / 渲染 1080 |
| `540p.png` | 真机设置：输出 540 / 渲染 540 |
| `540-1080.png` | 渲染 540 / 输出 1080（前半渲染，后半输出） |
| `540-1080+GSR.png` | 同上且开启 GSR（`+GSR`、`-GSR`、`空格 GSR` 都认） |
| `540x1080.png` / `540_1080.png` | 同上，分隔符支持 `- _ x × /` |
| `1080p+GSR.png` | 真机 1080 且开 GSR |
| `默认576p.png` | 该机型**默认**档位（标题显示「真机默认 576p」，数字各机型不同） |

解析不出来的名字也能用，只是标题直接显示文件名；需要自定义时再在
`config.js` 的 `shots` 里写 `{ file, label, note, out, rend, gsr }` 覆盖。

`config.js` 里的 `shots` 是可选的：有 `src/files.js` 时以扫描结果为准，没有时才用它。

## 新增 / 删除档位

**不用改任何代码**：在根目录建一个文件夹（名字就是 Tab 名），里面建 `src/` 把图丢进去，再跑一次 `扫描图片.bat`：

- Tab 数量和名字直接跟文件夹走（只认「有 `src` 子目录」的文件夹）；
- 新文件夹没有 `config.js` 时，脚本会自动补一个占位到 `<档位名>/config.js`（`tier` 已填好，左右默认图取前两张）；
- 顺序：**沿用上一次 `tiers.js` 的顺序**，新文件夹追加在末尾；想调顺序直接改 `tiers.js` 里那行数组，下次扫描会保留；
- 删文件夹后重扫，对应的 Tab 自动消失。

## 改机型
打开对应档位的 `<档位名>/config.js`（在 src 的上一层），改 `device` / `hardware`；
默认分辨率变了就把 `默认576p.png` 改名，页面会自动跟着显示新数字。

## config.js 字段
| 字段 | 说明 |
|---|---|
| `tier` | 档位名（高 / 中 / 低），显示在标题里 |
| `device` | 机型，显示在标题括号里 |
| `hardware` | 副标题里的 SoC / 内存信息 |
| `subtitle` | 可选，整段覆盖副标题 |
| `source` | 可选，右上角来源说明 |
| `accent` | 标题高亮色 |
| `mode` | 打开时的默认模式：`wipe`（擦除）/ `side`（并排） |
| `left` / `right` | 左右默认选中的文件名（留空则用清单第 1、2 张） |
| `shots` | 可选：手写图片清单（没有 files.js 时的回退） |

## 增删档位
复制一份文件夹（含 `src/`），把名字加进根目录 `tiers.js`，再跑一次 `扫描图片.bat`。
档位顺序就是 `tiers.js` 里的数组顺序。

## 页面操作
- 滚轮缩放、拖拽平移、双击复位、「适应窗口」/「1:1」
- 擦除模式：单击画面任意位置 → 滑杆跳到该横坐标；拖动分隔条或 ← → 微调
- 并排模式：勾选「联动缩放」后两侧同步到同一区域

## 出问题先看这里
- 某一档标题显示「配置读取失败」→ `<档位名>/config.js` 有语法错误，最常见是**中文逗号「，」**、少写逗号或引号没闭合
- 图片列表缺图/多图 → 重新运行 `扫描图片.bat`
- 页面显示「缺少 src/xxx.png」→ 文件名大小写或后缀对不上，重新扫描
