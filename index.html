打开报告

这个视图按“迁移时通常需要先解决谁”的关系排布。越靠左越偏底层基础设施，越靠右越偏上层功能插件；箭头文字表示主要牵引方向，并不等同于严格的 Build.cs 编译依赖。角色布料/Dataflow 与音频图已从主链路摘出，放到下方可选区。

底层引擎基础

RDG / RenderGraph 渲染图、资源生命周期、Pass 调度、RHI 状态。 → 支撑 GPU 渲染、Compute、Water、Niagara GPU Editor Framework AssetDefinition、TypedElement、ContentBrowserData。 → 支撑各插件编辑器移植 StructUtils / PropertyBag 动态参数、图参数覆盖、属性绑定。 → 支撑 PCG、StateTree、Niagara Data Channel

中间支撑系统

ComputeFramework GPU 计算图、Shader/RDG/RHI 计算调度。 依赖 RDG → 支撑 PCGCompute、Deformer 等 GPU 计算路径 GeometryScripting DynamicMesh、GeometryProcessing、几何蓝图库。 → 支撑 PCG Geometry、Water、建模工具

领域框架

Mass / StateTree / SmartObjects 大规模 AI、状态树、智能对象生态。 依赖 PropertyBag/Editor → 影响 PCG InstancedActors Water / Landmass 水体、地形刷、采样与水体渲染接口。 依赖 RDG/Geometry/Niagara → 影响 PCG/Niagara Water Interop Animation Rigging ControlRig、IKRig、MotionWarping、PoseSearch。 依赖 Editor/RigVM/动画系统 → 独立动画专项

上层功能插件

PCG 程序化生成图、编辑器、Runtime 生成和 Interop。 牵引 PropertyBag、Geometry、Compute、Editor、Water、Niagara Niagara 粒子系统、GPU Sim、Data Channel、相关 Interop。 牵引 RDG、Compute、Editor、Water、PCG Enhanced Input InputAction、MappingContext、Trigger、Modifier。 相对独立 → 可单独回迁

可选/暂缓，不纳入主移植链路

这两个模块可能被某些 UE5 高阶功能间接提到，但不是 PCG、Niagara、RDG、Geometry、Editor 等主线移植的硬前置。建议保留调研报告，默认从执行计划中摘出。

Dataflow / ChaosCloth 主要服务角色布料、Dataflow 图资产、Hair/Deformer 等后置工具链。 摘出理由：不是 PCG/Niagara 基础路径；需要时单独立角色专项 MetaSounds / Audio 程序化音频图和 AudioGameplay 能力，和当前视觉/生成/渲染迁移链路弱耦合。 摘出理由：独立音频专项；不作为上层功能插件前置依赖
