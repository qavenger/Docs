Verse 编程语言概览

概览页解释 Verse 的设计哲学、关键特性、命名规范、格式约定和语法风格。它是理解 Verse 为什么重视表达式、失败、效果、事务和并发的入口。

源文件：00_overview.md小节数：8生成：2026-06-25

核心提炼

  • Verse 强调长期兼容、安全并发、可组合代码和面向全球持久模拟的设计。
  • 控制流、循环和代码块都可以产生值，语言整体以表达式为核心。
  • 失败是一等控制流，<decides> 标记可失败函数，[] 调用表达可能失败。
  • 效果系统用 <computes>、<reads>、<writes>、<transacts>、<suspends> 等声明函数能力。
  • 示例库存系统串起 enum、struct、class、option、case、模块、访问控制、高阶函数和事务回滚。
  • 命名建议：变量、常量、函数、字段和方法用 PascalCase；class、struct、enum 和枚举值用 snake_case。

规则与坑点

  • 默认不可变；只有显式 var 与 set 才引入可变状态。
  • 建议 4 空格缩进，冒号引入缩进块；花括号、缩进、inline 和 dotted 风格可按可读性选择。

典型语法

  • Result := if (...) then A else B
  • Func[] 表示可失败调用，Func() 表示普通调用。
  • using { /Verse.org/... } 导入路径模块。
