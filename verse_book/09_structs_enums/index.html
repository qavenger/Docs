结构体与枚举

结构体与枚举页介绍值类型聚合和有限命名集合。重点是值语义、构造、比较、持久化和 enum 穷尽检查。

源文件：09_structs_enums.md小节数：14生成：2026-06-25

核心提炼

  • struct 是轻量值类型，字段公开且默认不可变。
  • struct 使用 archetype 构造，未指定字段使用默认值。
  • 所有字段都 comparable 的 struct 支持逐字段相等。
  • struct<persistable> 可用于持久化，但发布后结构更难变更。
  • enum 定义类型与命名值，适合状态、方向、类型等固定集合。
  • closed enum 支持穷尽检查；open enum 为未来新增值预留空间。

规则与坑点

  • enum 类型本身不能当值，必须用具体枚举值。
  • enum 通常只能在模块或 class 级别定义。
  • open enum 即使覆盖当前所有值，也应有 wildcard 或处于 <decides> 上下文。
  • 重复 case 或 wildcard 后 case 会不可达。

典型语法

  • vector2 := struct: X:float = 0.0
  • vector2{X := 100.0}
  • game_state := enum: MainMenu; Playing
  • case (State): game_state.Playing => ...
