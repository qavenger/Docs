模块与路径

模块与路径页说明 Verse 如何用模块、文件夹、路径和限定名组织代码、发布 API、隔离命名空间并保持长期兼容。

源文件：16_modules.md小节数：33生成：2026-06-25

核心提炼

  • 路径形如 /domain/path/to/module，提供全局唯一命名。
  • 文件夹会映射为模块，同一文件夹下 .verse 文件共享模块命名空间。
  • 模块可包含常量、变量、函数、类、接口、结构体、枚举、类型和嵌套模块。
  • using { /Path/To/Module } 是主要导入形式，通常位于文件或模块顶层。
  • 导入有文件作用域，同模块不同文件仍需各自导入外部模块。
  • 命名冲突用 (Qualifier:)Identifier 显式限定。
  • 模块级持久状态常通过 weak_map(session,t) 或 weak_map(player,t) 表达。

规则与坑点

  • 模块体只能包含定义，不能放任意运行时表达式。
  • 模块作用域数据必须显式写类型。
  • 模块不是一等值，不能赋值、传参或放入数组。
  • 路径大小写敏感，导入在编译期解析。
  • 跨模块访问通常需要 <public>。

典型语法

  • MyModule := module:
  • using { /Verse.org/Random }
  • using { ../UI/MainMenu }
  • (GameSystem:)Value
  • (local:)Value
  • weak_map(player, player_data)
