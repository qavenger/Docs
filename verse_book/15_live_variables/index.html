实时变量

实时变量页介绍计划中的响应式编程模型：变量可依赖其他变量自动重算，await、upon、when 和 batch 建立在该机制上。该页明确标注为未发布功能。

源文件：15_live_variables.md小节数：23生成：2026-06-25

核心提炼

  • live expression 将目标变量与 guard 表达式绑定，并动态追踪 guard 实际读取的依赖。
  • 支持 var live、set live 和不可变 live 派生值。
  • 函数类型若带 <reads>，可形成输入过滤和依赖重算。
  • 输入-输出变量保存原始输入与变换后的输出。
  • await 等待条件成功，upon 首次成功触发一次，when 条件成功时持续响应。
  • batch 合并多次更新，延迟通知，观察者看到最终状态。

规则与坑点

  • live guard 不能写状态，因为系统可能反复求值。
  • 常规 set X = ... 可关闭由 guard 建立的 liveness。
  • 循环依赖可能稳定也可能发散，设计时要避免无终止重算。
  • 这是未发布功能，不应直接当当前 UE/UEFN 可用语法。

典型语法

  • var live X:int = Exp
  • set live X = Exp
  • live Y:int = Exp
  • await{Condition}
  • upon(Condition): Body
  • when(Condition): Body
  • batch: ...
