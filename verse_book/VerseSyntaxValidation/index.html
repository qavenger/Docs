语法高亮验证样例

隐藏页用于测试 Verse 语法高亮，不是正式教程章节。它集中展示 class、enum、注释、真实业务代码片段和简化 digest API 片段。

源文件：VerseSyntaxValidation.md小节数：4生成：2026-06-25

核心提炼

  • Basics 展示 class、enum、block、单行/块注释和多行块注释。
  • Real life examples 用物品稀有度、持久化 struct/class 和库存系统展示综合语法。
  • 库存示例覆盖 var、数组更新、失败语义、事务回滚和 failable 方法。
  • 高阶函数示例使用 type{_(:game_item)<decides>:void}。
  • 简化 digest 展示 <native>、<public>、external {}、注解、限定路径、事件和泛型 class。

规则与坑点

  • 该页服务于 syntax highlighting validation，不应把所有代码当最佳实践。
  • 注释标记出现在字符串内只是字符串内容。
  • digest 片段是生成文件风格，不适合手工维护。

典型语法

  • Component := class<final_super>(component) { ... }
  • item_rarity := enum<persistable>:
  • GetRarityMultiplier()<decides>:float
  • (/UnrealEngine.com/Temporary/SpatialMath:)rotation
  • @available {MinUploadedAtFNVersion := 3800}
