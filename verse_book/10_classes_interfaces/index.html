类与接口

类与接口页是对象模型主章，说明 class 的引用语义、字段/方法、初始化、继承、身份、可见性，以及 interface 如何表达契约。

源文件：10_classes_interfaces.md小节数：100生成：2026-06-25

核心提炼

  • class 是引用类型，适合有身份、共享状态或行为的数据。
  • 字段可有默认值、可变性和访问控制；var 字段可被修改，非 var 字段初始化后固定。
  • archetype 构造允许指定字段，block/初始化逻辑可在构造时运行。
  • <unique> class 支持身份相等，普通 class 不能直接按等号比较。
  • 继承允许子类扩展父类，Self 表示当前实例，override 用于重写方法。
  • <abstract>、<concrete>、<final>、<final_super>、<castable> 等 specifier 影响实例化、继承和运行时类型检查。
  • interface 定义字段/方法契约，class 可实现一个或多个接口；接口可用于抽象 API 边界。
  • 构造器、默认值、字段初始化和方法 effects 相互约束，尤其和 <transacts>、<decides> 相关。

规则与坑点

  • 不可变 class 变量仍可通过其 var 字段修改对象状态；变量不可变只是不允许改指向。
  • 没有 <unique> 的 class 不支持身份相等，比较规则要谨慎。
  • final 后不能再派生；abstract 不能直接实例化；concrete 需要可构造默认实例。
  • 字段初始化不能随意调用有副作用或可失败函数，需满足类/构造上下文 effects。
  • 接口要求的成员必须由实现类提供，访问级别和 effects 也要兼容。

典型语法

  • player := class: 定义类。
  • var Health:int = 100 定义可变字段。
  • Method()<transacts>:void = ... 定义方法及效果。
  • child := class(parent): 表示继承。
  • interface_name := interface: 定义接口。
  • MyObj := my_class{Field := Value} 使用 archetype 构造。
