失败系统

失败系统页解释 Verse 的核心控制流：表达式成功并产生值，或失败且不产生值。失败不是异常，而是可组合的语言机制。

源文件：08_failure.md小节数：17生成：2026-06-25

核心提炼

  • 数组索引、map 查找、比较、整数除法、可失败函数都可能失败。
  • 失败表达式只能放在失败上下文，如 if 条件、for header、<decides> 函数体。
  • <decides> 函数体整体是失败上下文，任一步失败会使函数失败。
  • 失败上下文里的 mutation 是推测性的，整体成功才提交，失败则回滚。
  • and 要求两边成功，or 取第一个成功分支，not 反转成功/失败。
  • option 与失败紧密连接，?T 用 false 表示空，Maybe? 解包。

规则与坑点

  • 非失败上下文调用 <decides> 函数必须显式处理失败。
  • not 下绑定的变量不会进入 then 分支作用域。
  • option 必须先 query/unwrap 才能和普通值比较。
  • runtime error Err() 不同于失败，不可恢复。

典型语法

  • if (Value := Array[Index]): ...
  • option{Risky[]}
  • Maybe?
  • Primary? or Secondary? or Default
  • Type[Value] 可失败 cast
