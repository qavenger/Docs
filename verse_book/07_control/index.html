控制流

控制流页说明 block、if、case、loop、for、first、return、defer 和 profiling 都如何作为表达式或控制边界参与求值。

源文件：07_control.md小节数：10生成：2026-06-25

核心提炼

  • block 创建新作用域，值来自最后执行表达式。
  • if 由成功/失败驱动，条件中应包含可失败表达式。
  • case 适合离散值和 enum，可参与穷尽检查。
  • loop 是无限循环，需用 break 退出；break 可适配多种类型上下文。
  • for body 的结果会收集成 array，header 里的失败表达式可作为过滤器。
  • defer 是作用域退出清理机制，多个 defer 后注册先执行。

规则与坑点

  • for 没有 continue，用 header 过滤或内部条件代替。
  • range 只能直接用于迭代，不应保存成变量。
  • return 必须处于 tail position，通常只用于提前退出。
  • first 章节标注为未发布设计。

典型语法

  • if (Value := Items[0]): ... else: ...
  • case(Value): A => ...; _ => ...
  • for (Index -> Item : Items): ...
  • defer: Cleanup()
