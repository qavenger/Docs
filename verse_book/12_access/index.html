访问控制与元数据

访问控制页说明 public、protected、private、internal、scoped 等可见性，以及读写分离、注解、metadata、localization message 和 getter/setter 相关机制。

源文件：12_access.md小节数：39生成：2026-06-25

核心提炼

  • 访问 specifier 控制定义、字段、方法在模块、继承和协作边界中的可见性。
  • public 暴露 API；private 限制本作用域；protected 面向继承层级；internal 面向包/模块内部。
  • scoped 用更精细的作用域限定访问，用于跨模块协作和 API 边界。
  • 读写访问可分离，允许外部读取但限制写入。
  • 内建注解包括 @deprecated、@experimental、@available，用于演化和版本可用性。
  • 自定义 attribute 可限制可应用目标，如函数、字段等。
  • localization 用 <localizes> message 支持参数插值、整数格式、默认参数和继承覆盖。

规则与坑点

  • 同一定义不能叠多个互斥访问级别。
  • 降低已公开 API 的访问性会破坏兼容性。
  • 使用 experimental 功能可能需要显式允许。
  • localizes message 必须满足严格的字面量和类型限制，不能随意拼接表达式。
  • 可本地化消息参数类型有限，optional、复杂自定义类型等可能不被支持。

典型语法

  • Name<public>:int = 1
  • Field<private>:int
  • Thing<scoped{Module}>:int
  • @deprecated
  • @experimental
  • Message<localizes>(Name:string):message = "Hi {Name}"
