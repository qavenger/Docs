!!!警告 这是《诗经》的早期草稿。欢迎提出改进建议。频繁的更新是可以预期的。

本文档深入介绍了 Verse 编程语言、其哲学和核心概念。

Verse 是 Epic Games 开发的一种多范式编程语言，借鉴函数、逻辑和命令式传统，创建了一个用于构建metaverse体验的连贯系统。

Verse 有三个核心原则：

  • **这只是代码** - 复杂的概念被表达为原始的 Verse 结构
  • **只有一种语言** - 编译时和运行时的结构相同
  • **Metaverse 第一** - 专为全球模拟环境而设计

!!!注意 该文档属于 Verse 主要开发分支的负责人，某些功能可能会在正式发布之前进行讨论，因此可能会发生更改。一些 Epic 的内部功能也可以讨论。

Verse Language Documentation

!!! warning This is an early draft of the Book of Verse. Suggestions for improvements are welcome. Frequent updates are to be expected.

This documentation provides an in-depth look at the Verse programming language, its philosophy, and core concepts.

Verse is a multi-paradigm programming language developed by Epic Games, drawing from functional, logic, and imperative traditions to create a coherent system for building metaverse experiences.

Verse has three core principles:

  • It's just code - Complex concepts are expressed as primitive Verse constructs
  • Just one language - Same constructs for compile-time and run-time
  • Metaverse first - Designed for a global simulation environment

!!! note The documentation pertains to the head of the main development branch of Verse, some features may be discussed before they are officially released and are thus subject to change. Some Epic internal features may also be discussed.
