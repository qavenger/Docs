类型系统

类型系统页把 Verse 的类型视为一等值和约束工具，覆盖子类型、顶层/底层类型、comparable、parametric types、variance、casting、where clauses 和 refinement types。

源文件：11_types.md小节数：52生成：2026-06-25

核心提炼

  • 类型本身可出现在表达式和泛型约束中，type 是类型的类型。
  • any 是广义顶层类型，具体值可向上看作更宽类型；部分失败/不可达表达式会落到特殊底部语义。
  • comparable 表示可比较值，是 map key 和 equality 的基础约束。
  • 容器、option、tuple、function、class/interface 之间存在子类型和 variance 规则。
  • 泛型/参数化类型用 where 约束类型参数，可以表达 subtype、comparable、函数类型等关系。
  • 运行时 cast 用可失败语法，把动态值检查为更具体类型。
  • refinement type 用 type{_X:T where 条件} 表达数值范围等细化约束。
  • float refinement 有 IEEE 754 边界，NaN、Inf、字面量精度都会影响可接受范围。

规则与坑点

  • 类型兼容不等同于运行时相等；尤其 class、interface、option 和容器有各自规则。
  • 可比较约束要从元素/字段递归判断，包含不可比较字段的复合类型不能做 key 或 equality。
  • cast 只适用于支持的 class/interface 等类型关系，primitive 不能随意 cast。
  • refinement 约束表达式限制很强，通常只能用字面量和简单比较，不能调用函数或引用变量。
  • overload 不能依赖子类型过近的签名，编译器会判定不够 distinct。

典型语法

  • t:type 声明类型参数。
  • where t:subtype(comparable) 添加约束。
  • type{_X:float where 0.0 <= _X, _X <= 1.0} 定义百分比类型。
  • SomeType[Value] 表示可失败 cast。
  • []t、[k]v、?t 是参数化类型形态。
