函数

函数页覆盖参数、命名参数、tuple 参数、扩展方法、函数类型、泛型、重载和兼容性，是 Verse 行为抽象的主章节。

源文件：06_functions.md小节数：29生成：2026-06-25

核心提炼

  • 函数签名包含参数、effects 和返回类型。
  • 命名参数以 ?Name:type 声明，调用时用 ?Name := Value，可带默认值。
  • tuple 参数可拆解，并在调用时自动 flatten/unflatten。
  • 扩展方法用 (Receiver:type).Method(...) 给已有类型添加点号调用。
  • 函数类型用 type{_(...):Return} 表示，effects 是类型的一部分。
  • 泛型用 where 声明类型参数和约束，重载必须足够 distinct。

规则与坑点

  • 位置参数必须在命名参数前。
  • 函数类型保留命名参数名但不保留默认值。
  • 不能只靠默认值或命名参数顺序形成有效重载。
  • => lambda 和部分嵌套函数能力标注为未发布，不应无条件依赖。

典型语法

  • ProcessData(Name:string, Age:int):string = ...
  • Log(Message:string, ?Level:int = 1)
  • (N:int).IsEven()<decides><computes>:void = ...
  • Identity(X:t where t:type):t
