可变性

可变性页说明 Verse 默认不可变，如何通过 var 和 set 显式引入状态，并区分值语义、引用语义与容器 mutation。

源文件：05_mutability.md小节数：29生成：2026-06-25

核心提炼

  • var 声明可重新赋值变量，set 执行赋值。
  • 局部 var 必须显式类型并初始化，不能用 := 推断。
  • struct、array、map、tuple 偏向值语义；赋值和传参通常得到独立副本。
  • class 是引用语义；变量是否 var 决定引用能否改指向，字段能否改由字段声明决定。
  • array/map 更新看起来像原地改，本质仍是重新绑定新容器。
  • map 新 key 追加到末尾，更新旧 key 保持位置。

规则与坑点

  • 不能 shadow 同名变量。
  • tuple 只能整体替换，不能改单个元素。
  • 嵌套容器更新要求路径上每层都存在，否则失败。
  • 不能通过 class 的不可变字段继续修改深层结构。

典型语法

  • var Health:float = 100.0
  • set Health = 75.0
  • set Stats.Position.X = 100.0
  • set Scores[Key] = Value
