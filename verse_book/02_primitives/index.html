基础数据类型

基础类型页介绍 int、rational、float、logic、char、char32、string、type、any、void 以及数学和转换内建函数。它是数值精度、失败转换和泛型类型参数的基础。

源文件：02_primitives.md小节数：18生成：2026-06-25

核心提炼

  • int 是整数，运行时可任意精度；rational 是精确分数，整数除法可产生它。
  • float 是 64 位浮点，文档讨论 Inf、NaN、负零和特殊数学函数行为。
  • 数学内建覆盖绝对值、上下取整、四舍六入五成双、幂/对数、三角/双曲、取模/商和有限性检查。
  • logic 的 true/false 可通过 query 操作接入失败语义。
  • char 表示 UTF-8 单字节，char32 表示 Unicode code point，string 是字符数组式文本。
  • type 是元类型，类型可作为值参与泛型和约束；any 是顶层超类型，void 表示无有意义结果。

规则与坑点

  • 许多 intrinsic 只能直接调用，不能当一等函数值传递；需要时要包装成普通函数。
  • 整数 / 是可失败操作，除零失败。
  • float 字面量写 0.0，不是 0；int 到 float 没有通用隐式转换。
  • int 是 rational 子类型，不能只靠二者区分 overload。

典型语法

  • X := 7 / 3 得到 rational。
  • if (Flag?): ... 查询 logic。
  • Identity(X:t where t:type):t = X 是泛型基础形态。
