运算符

运算符页整理 prefix、infix、postfix 运算符，说明优先级、结合性、算术/比较/逻辑/赋值语义和特殊构造。

源文件：04_operators.md小节数：23生成：2026-06-25

核心提炼

  • 成员访问、索引、调用、构造和 query 绑定最紧。
  • 算术、比较、and、or、range、赋值有明确优先级，赋值与一元运算右结合。
  • = 既可表示相等比较，也可在 set X = Value 中表示赋值。
  • := 用于定义并初始化新绑定；无类型注解推断时必须用它。
  • 比较运算是可失败表达式；逻辑运算处理成功/失败并短路。
  • [] 同时用于集合索引和可失败函数调用。

规则与坑点

  • 不同类型比较通常失败，例如 int 与 float 不直接相等。
  • not 内部效果不提交，可理解为推测执行。
  • var X := value 不允许，var 需要显式类型。
  • 对象构造不允许尾随逗号；没有通用数字到 string 隐式转换。

典型语法

  • set Score += 50
  • if (IsReady?): ...
  • MyFunction[Arg1] 调用可失败函数。
  • for (I := 0..4): ...
