容器类型

容器页讲 optional、tuple、array、map 和 weak_map。重点是容器如何与失败系统、值语义、索引/查找、持久化和类型协变配合。

源文件：03_containers.md小节数：20生成：2026-06-25

核心提炼

  • ?t 表示 optional，option{...} 包装成功值，false 表示空。
  • tuple 是固定长度、有序、可混合类型的组合，可在函数调用中自动展开。
  • array 是同质、按序、零基索引的不可变容器，索引访问会失败。
  • 数组方法覆盖切片、查找、删除、替换、插入和拼接，越界通常失败。
  • map 用 [key]value 类型和 map{K => V} 字面量表示，键必须可比较。
  • map 保留插入顺序，更新已有 key 不改变位置，相等性也考虑顺序。
  • weak_map 面向持久化和弱引用场景，限制迭代、长度和批量操作。

规则与坑点

  • 数组空字面量需要类型上下文；混合元素会推断共同超类型，可能退到 any。
  • tuple 可转 array，但 array 不能自动转 tuple。
  • map 查找失败表示缺 key，set Map[Key] = Value 可新增或更新。
  • 模块级 var weak_map 不能整体读写，只能操作单个条目。

典型语法

  • A:?int = option{42}
  • Tuple := (1, 2.0, "three")
  • A:[]int = array{1, 2, 3}
  • Scores:[string]int = map{"Alice" => 100}
