如何用平行光校准天光（灰球法）

⚠️ 不要靠关闭平行光来看"纯天光"：物理天空（Sky Atmosphere / PBS Sky）的亮度来自太阳光的大气散射， 关掉太阳会连天空一起变黑——SkyLight 捕捉到的是黑天，Intensity Scale 乘以 0 仍是 0，暗部永远死黑。 只有「HDRI / Cubemap」方案（天空亮度存在贴图里，与太阳无关）可以临时关灯校准；其余方案保持太阳开启，改读灰球的阴影面。

1
先锁定平行光（唯一的绝对基准）：Intensity 填 —、 Pitch = —、色温同表。
2
锁定曝光：Min EV100 = Max EV100 = —，Exposure Compensation = 0。 不锁曝光时任何目视对比都不可靠。
3
放置校准球：18% 灰（BaseColor ≈ 0.18 线性值）、Roughness = 1、Metallic = 0，置于空旷地面。

使用说明与换算约定

  • 「到达地面」与「填入 Intensity」是两个不同的数：表中「到达地面」= 地面高度、垂直于光线方向的照度（DNI），这是物理目标，不是水平地面照度（水平面 = DNI × sin(高度角)）。UE5 Directional Light 的 Intensity 和 HDRP Directional Light 用的是同一个定义，但——见下一条——有大气时填进去的值会被再衰减一次。
  • 大气衰减双重计算（最容易踩的坑）：Directional Light 勾选 Atmosphere Sun Light 后，Sky Atmosphere 会按太阳方向的透射率 T 调制这盏灯，即你填的值被当作大气层顶的量。而表中 DNI 已经含过一次大气衰减，直接填入就衰减了两次，实际只到 DNI × T。用顶部「大气衰减」下拉切换：有大气时表格给出补偿后的填入值（DNI ÷ T）；无大气（取消勾选 / 非物理天空）时表值直接填。低角度时段影响极大（15° 时 T ≈ 0.6，黄金时刻/日落更低），正午几乎无差别。
  • τ 的标定方法：默认 τ = 0.134 标定自 UE5 默认 Sky Atmosphere（15° 高度角实测 T ≈ 0.60），配合 Kasten-Young 大气质量按 Beer-Lambert 计算 T = e−τ·AM。你的大气参数（Rayleigh / Mie / 气溶胶）不同时可自行实测：固定一个高度角，读灰球受光面亮度求出实际 T，再按 τ = −ln(T) ÷ AM 反解填入。高度角低于约 5° 时该模型误差较大，建议改为艺术化调整而非硬套。
  • Pitch 约定：UE 中 Directional Light 的 Rotation Pitch = −太阳高度角（−90° 为正头顶直射）；Unity 中为 Transform 的 X Rotation = 高度角。正午与上午/下午的高度角由上方「纬度 + 季节」计算；清晨/傍晚、黄金时刻、日出日落按定义取固定高度角（15° / 4° / 0.5°），纬度只影响它们出现的时刻和持续时长。月亮高度随月相变化，表中取 45° 作参考。
  • 天光：给出的是天空半球在水平面上产生的照度（lux），平均天空亮度 = 照度 ÷ π（cd/m²）。UE5 推荐 Sky Light 开 Real Time Capture + Sky Atmosphere，天光自动匹配太阳强度；HDRI/Cubemap 方案用上面的灰球流程校准 Intensity Scale。Unity HDRP 的 HDRI Sky 可切 Lux 模式直接填天光照度。
  • Intensity Scale 的含义：SkyLight 最终亮度 = 源（Cubemap/捕获）自身亮度 × Intensity Scale。因此它没有普适值，取决于你的 HDRI 是否带绝对亮度标定——这正是需要灰球校准的原因。用顶部「天光方案」下拉切换：自动捕捉恒为 1.0；HDRI 按 L₀ 算理论初值再微调（L₀ 未知时先按 1 cd/m²）；手动没有初值可算，直接以灰球读数为标尺。
  • 光比与天空可见系数：受光面照度 = 直射 + 0.55 × 天光；阴影面照度 = 0.45 × 天光 + 地面弹射。系数依据是开阔地无遮挡的垂直面只能看到半个天空半球（恰为水平面的 0.5），受光点法线朝太阳取 0.55、阴影点法线背向并略朝下取 0.45。1 档 = 2 倍。
  • 地面弹射（GI）决定暗部能有多亮：晴天时弹射项（约 8% × 直射）往往比阴影面的天光项还大，所以它不是可以忽略的修正。必须有足够大、反照率足够高的地面 + Lumen / GI 开启且质量够；球体浮空、地面很暗、或 GI 关闭时这一项直接归零，暗部会比表值低 2–3 倍、光比从约 6:1 拉到 10:1 以上。用顶部「地面弹射」下拉切换两档对照。另外 SkyLight 的遮蔽（DFAO / Lumen AO）还会再削暗部约 10–20%，属正常范围。
  • EV100：EV = log₂(地面总照度 ÷ 2.5)。锁定曝光时把 UE 的 Min EV100 = Max EV100 = 表中值；自动曝光时保证表中值落在 Min/Max 区间内，Exposure Compensation 保持 0。UE5 默认已启用 Extend Default Luminance Range（物理曝光），UE4 老项目需手动勾选。
  • Unity（URP/内置管线）：非物理单位，不能直接填 lux。可保留表中的比例关系：平行光设 1–8 区间内按 lux 比例缩放，环境光按「天光 ÷ 平行光」比值配置，反差档位与色温仍然通用。
  • 为什么关掉平行光场景会全黑：Sky Atmosphere / PBS Sky 的天空亮度全部来自太阳光的大气散射，太阳一关天空即黑，SkyLight（无论 Real Time Capture 还是重新捕捉）拿到的都是黑天。所以「关灯看纯天光」只对与太阳无关的 HDRI / Specified Cubemap 成立；物理天空方案请改读灰球阴影面，或用光照通道隔离太阳的直接光照。
  • 阴天/雨天仍保留微弱平行光（而非 0）：用大 Source Angle（5–10°）的软方向光维持体积感，这是行业常用做法；物理上对应云层透射的残余方向性。
  • 照度数据基于 CIE 天空模型与实测范围（晴天正午地面约 10–12 万 lux、阴天 1–2.5 万 lux、日落约 400–700 lux、满月约 0.05–0.3 lux），以中纬度（约 35°）为基准做了取整；改纬度只更新 Pitch 几何参考，不重算照度。
