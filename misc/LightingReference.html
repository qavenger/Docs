PBR 光照参考表时段 × 气候 — 平行光 / 天光 / 光比 / EV100（真实物理单位）

适用于 Unreal Engine 5（默认物理光照单位）与 Unity HDRP（同为 lux/EV 体系）。 平行光强度为垂直于光线方向的照度（即引擎 Directional Light 的 Intensity 数值）； EV100 为无曝光补偿时的建议曝光值（入射式，标定常数 C=250）。

基准假设：场景中所有物体（含地面与校准球）BaseColor = 0.18 线性中灰、Roughness = 1、非金属。 照度（lux）、天空亮度、EV100、光比这些量本身与反射率无关——反射率只影响两处：灰球的 cd/m² 读数（按 ρ 线性缩放）， 以及阴影面被地面弹射填亮的程度（下方「地面反照率」下拉）。

如何用平行光校准天光（灰球法）

⚠️ 不要靠关闭平行光来看"纯天光"：物理天空（Sky Atmosphere / PBS Sky）的亮度来自太阳光的大气散射， 关掉太阳会连天空一起变黑——SkyLight 捕捉到的是黑天，Intensity Scale 乘以 0 仍是 0，暗部永远死黑。 只有「HDRI / Cubemap」方案（天空亮度存在贴图里，与太阳无关）可以临时关灯校准；其余方案保持太阳开启，改读灰球的阴影面。

使用说明与换算约定

  • 「到达地面」与「填入 Intensity」是两个不同的数：表中「到达地面」= 地面高度、垂直于光线方向的照度（DNI），这是物理目标，不是水平地面照度（水平面 = DNI × sin(高度角)）。UE5 Directional Light 的 Intensity 和 HDRP Directional Light 用的是同一个定义，但——见下一条——有大气时填进去的值会被再衰减一次。
  • 大气衰减双重计算（最容易踩的坑）：Directional Light 勾选 Atmosphere Sun Light 后，Sky Atmosphere 会按太阳方向的透射率 T 调制这盏灯，即你填的值被当作大气层顶的量。而表中 DNI 已经含过一次大气衰减，直接填入就衰减了两次，实际只到 DNI × T。用顶部「大气衰减」下拉切换：有大气时表格给出补偿后的填入值（DNI ÷ T）；无大气（取消勾选 / 非物理天空）时表值直接填。低角度时段影响极大（15° 时 T ≈ 0.6，黄金时刻/日落更低），正午几乎无差别。
  • τ 的标定方法：默认 τ = 0.134 标定自 UE5 默认 Sky Atmosphere（15° 高度角实测 T ≈ 0.60），配合 Kasten-Young 大气质量按 Beer-Lambert 计算 T = e−τ·AM。你的大气参数（Rayleigh / Mie / 气溶胶）不同时可自行实测：固定一个高度角，读灰球受光面亮度求出实际 T，再按 τ = −ln(T) ÷ AM 反解填入。高度角低于约 5° 时该模型误差较大，建议改为艺术化调整而非硬套。
  • Pitch 约定：UE 中 Directional Light 的 Rotation Pitch = −太阳高度角（−90° 为正头顶直射）；Unity 中为 Transform 的 X Rotation = 高度角。正午与上午/下午的高度角由上方「纬度 + 季节」计算；清晨/傍晚、黄金时刻、日出日落按定义取固定高度角（15° / 4° / 0.5°），纬度只影响它们出现的时刻和持续时长。月亮高度随月相变化，表中取 45° 作参考。
  • 天光：给出的是天空半球在水平面上产生的照度（lux），平均天空亮度 = 照度 ÷ π（cd/m²）。UE5 推荐 Sky Light 开 Real Time Capture + Sky Atmosphere，天光自动匹配太阳强度；HDRI/Cubemap 方案用上面的灰球流程校准 Intensity Scale。Unity HDRP 的 HDRI Sky 可切 Lux 模式直接填天光照度。
  • Intensity Scale 的含义：SkyLight 最终亮度 = 源（Cubemap/捕获）自身亮度 × Intensity Scale。因此它没有普适值，取决于你的 HDRI 是否带绝对亮度标定——这正是需要灰球校准的原因。用顶部「天光方案」下拉切换：自动捕捉恒为 1.0；HDRI 按 L₀ 算理论初值再微调（L₀ 未知时先按 1 cd/m²）；手动没有初值可算，直接以灰球读数为标尺。
  • 光比模型（全部公式）：
    　水平面总照度 Eh = DNI × sin(高度角) + 天光
    　受光面弹射 Eb,亮 = ρ × Eh × 0.5　（0.5 = 垂直面只看到半个地面半球）
    　阴影面弹射 Eb,暗 = ρ × (f × DNI × sin(高度角) + 天光) × 0.5
    　受光面 E = DNI + 0.55 × 天光 + Eb,亮　　阴影面 E = 0.45 × 天光 + Eb,暗
    　灰球读数 L = 反射率 × E ÷ π（cd/m²）
    天空系数依据是开阔地无遮挡的垂直面只能看到半个天空半球（恰为水平面的 0.5），受光点法线朝太阳取 0.55、阴影点法线背向并略朝下取 0.45。1 档 = 2 倍。
  • 日照比例 f 与低角度太阳的自遮挡：物体自身投影长度 = 高度 ÷ tan(高度角)，方向正是背光侧——也就是阴影面朝下看去的那片地面。投影里的地面只被天光照亮，没有直射，所以阴影面拿到的弹射比受光面少。f 表由视角因子数值积分得出（垂直微面元 dF = x·z ÷ (π·r⁴) dA，扣除投影覆盖的窄带）：高度角 15° 时 f ≈ 0.52，55° 时 ≈ 0.70，正头顶时 → 1.0。注意投影只是一条窄带，而垂直面看到的地面在方位上很宽，所以自遮挡最多吃掉约一半（f 的下限是 0.5），不会归零。这解释了为什么「教科书晴天 6:1」只在中午高角度成立，低角度实际会拉到 10:1 以上。
  • 地面反照率决定暗部能有多亮：弹射项往往和阴影面的天光项同量级，所以它不是可忽略的修正。ρ = 0 对应「无地面 / GI 关闭」，此时暗部只剩天光那一半半球。排查暗部偏暗的顺序：先用 r.Lumen.DiffuseIndirect.Allow 0/1 看弹射是否真的在供光（正常情况下切换会有可见但不剧烈的差异，因为弹射只占阴影面照度的一部分）；再确认地面网格真实存在且够大（薄平面的 Mesh Distance Field 退化，Lumen 软件光追可能不参与）；最后核对地面材质的 BaseColor 是否真是 0.18。另外 SkyLight 遮蔽（DFAO / Lumen AO）还会再削暗部约 10–20%，读数请取球的赤道高度、不要贴近接地点（接地处天空被挡掉大半并叠加接触 AO）。
  • 三个层面是三种不同的几何，别互相套用：
    　① 球受光面（法线朝太阳，近似垂直）= 直射 + 0.55×天光 + 全日照地面的弹射
    　② 球暗面（法线背向太阳，近似垂直）= 0.45×天光 + 部分自遮挡地面的弹射。垂直面只看到半个天空半球，所以天光只拿到 45%
    　③ 地面投影（法线朝上，与地面共面）= 1.00×天光，弹射为 0。朝上能看到完整天空半球，但与地面共面的表面互相看不见，所以四周再亮的日照地面也补不进一点光
    因此在中午晴天，投影区反而会比球的暗面略亮（多拿的 55% 天光 > 少拿的弹射），而不是更暗。若实测投影明显低于球暗面，说明有额外遮蔽或地面反照率偏低。
  • 排查「球对得上、投影偏低」的标准做法：用比值 投影区 ÷ 日照地面 = 天光 ÷ 水平面总照度。地面反照率在这个比值里被约掉，所以它不依赖地面材质是否真的 0.18，也不依赖曝光是否精确。比值符合表值 → 投影是对的，只是地面材质比 0.18 暗；比值明显偏低 → 投影里的天光被额外遮蔽，重点查 SkyLight 的 Occlusion Max Distance（DFAO 默认作用半径很大，附近物体会把一大片地面的天光压暗）、Lumen AO、以及校准球本身挡住的那部分天空（球离地越近遮挡越多，抬高球即可减小）。
  • 为什么 0.18 只出现在两个地方：照度（lux）、天空亮度、Intensity Scale、EV100、光比这些量都与物体反射率无关——照度描述入射光，EV100 走的是入射式测光公式（C=250），光比是两个照度之比、同材质时反射率被约掉。反射率只进入：(a) 灰球的 cd/m² 读数（L = ρ × E ÷ π，非 18% 灰按 ρ 线性缩放）；(b) 地面弹射项里的地面反照率。注意这是两个不同的表面，别把校准球的反射率和地面的搞混。
  • EV100：EV = log₂(地面总照度 ÷ 2.5)。锁定曝光时把 UE 的 Min EV100 = Max EV100 = 表中值；自动曝光时保证表中值落在 Min/Max 区间内，Exposure Compensation 保持 0。UE5 默认已启用 Extend Default Luminance Range（物理曝光），UE4 老项目需手动勾选。
  • Unity（URP/内置管线）：非物理单位，不能直接填 lux。可保留表中的比例关系：平行光设 1–8 区间内按 lux 比例缩放，环境光按「天光 ÷ 平行光」比值配置，反差档位与色温仍然通用。
  • 为什么关掉平行光场景会全黑：Sky Atmosphere / PBS Sky 的天空亮度全部来自太阳光的大气散射，太阳一关天空即黑，SkyLight（无论 Real Time Capture 还是重新捕捉）拿到的都是黑天。所以「关灯看纯天光」只对与太阳无关的 HDRI / Specified Cubemap 成立；物理天空方案请改读灰球阴影面，或用光照通道隔离太阳的直接光照。
  • 阴天/雨天仍保留微弱平行光（而非 0）：用大 Source Angle（5–10°）的软方向光维持体积感，这是行业常用做法；物理上对应云层透射的残余方向性。
  • DNI 与天光数据基于 CIE 天空模型与实测范围（晴天正午地面约 10–12 万 lux、阴天 1–2.5 万 lux、日落约 400–700 lux、满月约 0.05–0.3 lux），以中纬度（约 35°）为基准做了取整。改纬度/季节会重算高度角，并连带影响水平面总照度、EV100 与弹射项（这部分是物理正确的），但每个时段的 DNI 与天光是按该时段的典型高度角**手工标定**的常量，不随纬度重算——所以极端纬度/季节组合（例如 60°N 冬至正午，高度角仅 6.6°）下 DNI 会偏乐观，请以表格显示的透射率 T 和大气质量作为合理性判断，必要时降级到相邻时段的数值。
