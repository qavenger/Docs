一、真正的基础单位

国际单位制 SI 有 7 个基本单位。经典力学主要用 m、kg、s；电学加入 A；光学如果涉及光度学，会用 cd。温度 K 常在热辐射、黑体辐射里出现。物质的量 mol 在化学和统计物理更常见。

关于“克”：g 是质量单位，但 SI 的质量基本单位是 kg。所以 1 g = 10^-3 kg。日常记忆可以把 g 当作质量这个基本维度的常用小单位，但严格写复合单位时通常用 kg。

五、几个容易混淆的点

N·m 和 J 形式一样，但语义不同。
做功时 J = N·m，力和位移方向有关；转矩也是 N·m，但表示转动效果，通常不直接写成 J。
Hz 和 rad/s 都像 s^-1。
Hz 是每秒循环次数；rad/s 是每秒转过的弧度。弧度无量纲，但保留 rad 可以提醒你这是角量。
光学里有两套“功率”。
W 是真实辐射能量功率；lm 是按人眼敏感度加权后的可见光通量。
电学单位常从 J 和 C 走。
例如 V = J/C，W = V·A，Ω = V/A。先记住电荷 C = A·s，很多单位会顺起来。
